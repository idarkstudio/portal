# Guía de configuración de DNS

<MarkdownChipRow labels={["Intermedio", "Tutorial"]} />

Esta guía explica cómo configurar los registros DNS de tu dominio para tres
registradores populares: [Namecheap](#namecheap), [GoDaddy](#godaddy) y
[Amazon Route 53](#amazon-route-53).

:::caution

Los pasos en esta guía son requisitos previos para usar un dominio
personalizado. Debes completar esta configuración de DNS antes de seguir la
[guía de uso de dominios personalizados](using-custom-domains.mdx).

:::

:::info

Para ilustrar estas configuraciones requeridas, se utilizan el dominio raíz
`ic-domain.live` y el subdominio `example.ic-domain.live`.

Reemplaza `ic-domain.live` con tu propio dominio, como `mi-sitio.com`.

:::

## Namecheap

A continuación, se describen los pasos para configurar el dominio raíz y un
subdominio en Namecheap para ser utilizados como dominio personalizado en un
canister desplegado en ICP.

- #### Paso 1: Después de comprar tu dominio en Namecheap, abre el panel de administración de tu dominio en el dashboard de Namecheap.

- #### Paso 2: Abre la pestaña **Advanced DNS**.

### Dominio raíz (Apex)

Para configurar el dominio raíz (por ejemplo, `ic-domain.live`), agrega los
siguientes registros haciendo clic en **Add new record**:

- Crea un registro `ALIAS` donde el campo **host** sea `@` y el campo **target**
  sea `ic-domain.live.icp1.io`.

- Crea un registro `CNAME` donde el campo **host** sea `_acme-challenge` y el
  campo **target** sea `_acme-challenge.ic-domain.live.icp2.io`.

- Crea un registro `TXT` donde el campo **host** sea `_canister-id` y el campo
  **value** contenga el ID del canister `y5jqt-wqaaa-aaaam-abcoq-cai`.

La configuración resultante debería verse similar a la siguiente captura de
pantalla:

![Configuración DNS para `ic-domain.live` en Namecheap](namecheap-apex.png)

### Subdominio

Para configurar un subdominio (por ejemplo, `example.ic-domain.live`), agrega
los siguientes registros haciendo clic en **Add new record**:

- Crea un registro `ALIAS` donde el campo **host** sea `example` y el campo
  **target** sea `example.ic-domain.live.icp1.io`.

- Crea un registro `CNAME` donde el campo **host** sea `_acme-challenge.example`
  y el campo **target** sea `_acme-challenge.example.ic-domain.live.icp2.io`.

- Crea un registro `TXT` donde el campo **host** sea `_canister-id.example` y el
  campo **value** contenga el ID del canister `y5jqt-wqaaa-aaaam-abcoq-cai`.

La configuración resultante debería verse similar a la siguiente captura de
pantalla:

![Configuración DNS para `example.ic-domain.live` en Namecheap](namecheap-subdomain.png)

Ahora, ya puedes registrar tu dominio personalizado con los boundary nodes y
continuar con el paso 2 de las
[instrucciones generales para dominios personalizados](./using-custom-domains#custom-domains-on-the-boundary-nodes).

## GoDaddy

A continuación, se describen los pasos para configurar el dominio raíz y un
subdominio en GoDaddy para ser utilizados como dominio personalizado en un
canister desplegado en ICP.

- #### Paso 1: Después de comprar tu dominio en GoDaddy, abre tu cuenta y navega a **Mis productos**.

- #### Paso 2: Haz clic en el botón **DNS** junto al dominio.

![Vista general de la gestión de dominios](godaddy-overview.png)

### Dominio raíz (Apex)

Desafortunadamente, GoDaddy no permite configurar un registro `CNAME` (ni sus
alternativas, `ALIAS` o `ANAME`) para el dominio raíz; por lo que debes usar una
solución alternativa.

Existen dos opciones:

- [**Recomendado**: Usar un proveedor de DNS diferente (por ejemplo, Cloudflare).](#usar-un-proveedor-de-dns-alternativo-recomendado)

- [Configurar directamente las direcciones IP de los boundary nodes.](#configurar-directamente-las-direcciones-ip-no-recomendado-úsalo-bajo-tu-propio-riesgo)

Configurar directamente las direcciones IP es más sencillo en comparación con
usar otro proveedor de DNS, pero es menos resistente y eficiente. Por ello, se
recomienda utilizar un proveedor de DNS alternativo (por ejemplo, Cloudflare o
Route 53).

#### Usar un proveedor de DNS alternativo (_recomendado_)

Este método se explica utilizando Cloudflare como proveedor de DNS. Funciona de
manera similar con cualquier otro proveedor de DNS que admita registros `CNAME`,
`ALIAS` o `ANAME` para el dominio raíz.

- #### Paso 1: Crea una cuenta gratuita en Cloudflare y haz clic en **Add site** en la barra superior del dashboard.

- #### Paso 2: Ingresa tu dominio (por ejemplo, `ic-domain.live`) y haz clic en **Add site**.

- #### Paso 3: Elige el plan gratuito y continúa.

- #### Paso 4: En el siguiente paso, Cloudflare te proporcionará dos nameservers que debes configurar en GoDaddy.

  Toma nota de los dos nameservers (por ejemplo, `brianna.ns.cloudflare.com` y
  `kaiser.ns.cloudflare.com`) que proporciona Cloudflare.

- #### Paso 5: En el panel **Administración de DNS** de GoDaddy, elimina todas las entradas de DNS en GoDaddy.

  Vuelve a la configuración de DNS en GoDaddy y asegúrate de eliminar todas las
  entradas de DNS creadas por GoDaddy.

- #### Paso 6: Haz clic en el botón **Cambiar** en la sección **Servidores de nombres**.

- #### Paso 7: En el cuadro de diálogo que se abre, haz clic en **Ingresar mis propios servidores de nombres (avanzado)** y completa los campos con los servidores de nombres de Cloudflare.

Para finalizar, haz clic en **Guardar**.

![Cuadro de diálogo de GoDaddy para configurar los servidores de nombres](godaddy-ns-dialog.png)

- #### Paso 8: Confirma en el cuadro de diálogo que realmente deseas cambiar los servidores de nombres.
  La configuración resultante debería verse similar a la siguiente captura de
  pantalla:

![Configuración de servidores de nombres alternativa en GoDaddy](godaddy-ns-configured.png)

- #### Paso 9: Vuelve al portal de administración de Cloudflare y haz clic en **Done, check nameservers**.

Este paso puede tardar varias horas, y recibirás una notificación por correo
electrónico cuando se complete con éxito.

- #### Paso 10: En Cloudflare, agrega los siguientes registros para configurar tu dominio:

  - Crea un registro `CNAME` donde el campo **name** sea `@` y el campo
    **target** sea `ic-domain.live.icp1.io`.

  - Crea un registro `CNAME` donde el campo **host** sea `_acme-challenge` y el
    campo **target** sea `_acme-challenge.ic-domain.live.icp2.io`.

  - Crea un registro `TXT` donde el campo **name** sea `_canister-id` y el campo
    **content** contenga el ID del canister `y5jqt-wqaaa-aaaam-abcoq-cai`.

La configuración resultante debería verse similar a la siguiente captura de
pantalla:

![Configuración DNS para `ic-domain.live` en Cloudflare](cloudflare-apex.png)

### Configurar directamente las direcciones IP (no recomendado; úsalo bajo tu propio riesgo)

:::caution

Al configurar directamente las direcciones IP de los nodos de frontera, siempre
debes asegurarte de mantener tus registros DNS actualizados. Si un nodo de
frontera se retira o cambia sus direcciones IP, deberás eliminar o actualizar
tus registros DNS. De lo contrario, corres el riesgo de que tu dapp se vuelva
inaccesible.

:::

- #### Paso 1: Primero, necesitas buscar las direcciones IP de los nodos de frontera (`icp1.io`).
  Para ello, usa un servicio de consulta DNS en línea (por ejemplo,  
  [nslookup.io](https://nslookup.io)) y toma nota de las direcciones IPv4 e
  IPv6,  
  que corresponden a los registros `A` y `AAAA`, respectivamente.

![Registros `A` y `AAAA` resultantes de la consulta a `icp1.io` en nslookup.io](nslookup-results.png)

- #### Paso 2: En el panel de **Gestión de DNS** de tu cuenta de GoDaddy, agrega los siguientes registros DNS:

  - Crea un registro `A` para cada dirección IPv4, estableciendo el campo
    "Nombre" en `"@"`  
    y el campo "Valor" en la dirección IPv4 (por ejemplo, `193.118.63.173`).

  - Crea un registro `AAAA` para cada dirección IPv6, estableciendo el campo
    "Nombre" en `"@"`  
    y el campo "Valor" en la dirección IPv6 (por ejemplo,
    `2a0b:21c0:b002:2:5000:59ff:fead:c233`).

  - Crea un registro `CNAME` en el que establezcas el campo "Nombre" como  
    `_acme-challenge` y el campo "Valor" como
    `_acme-challenge.ic-domain.live.icp2.io`.

  - Crea un registro `TXT` en el que establezcas el campo "Nombre" como
    `_canister-id`  
    y el campo "Valor" como el ID del canister `y5jqt-wqaaa-aaaam-abcoq-cai`.

La configuración resultante debería verse similar a la siguiente captura de
pantalla:

![Configuración DNS para `ic-domain.live` en GoDaddy](godaddy-apex-ips.png)

### Subdominio

Para configurar un subdominio (por ejemplo, `example.ic-domain.live`), agrega
los siguientes  
registros haciendo clic en **Añadir nuevo registro**:

- Crea un registro `CNAME` en el que establezcas el campo "Host" como
  `example`  
  y el campo "Destino" como `example.ic-domain.live.icp1.io`.

- Crea un registro `CNAME` en el que establezcas el campo "Host" como  
  `_acme-challenge.example` y el campo "Destino" como  
  `_acme-challenge.example.ic-domain.live.icp2.io`.

- Crea un registro `TXT` en el que establezcas el campo "Host" como  
  `_canister-id.example` y el campo "Valor" como el ID del canister  
  `y5jqt-wqaaa-aaaam-abcoq-cai`.

La configuración resultante debería verse similar a la siguiente captura de
pantalla:

![Configuración DNS para `example.ic-domain.live` en GoDaddy](godaddy-subdomain.png)

Ahora, ya tienes todo listo para registrar tu dominio personalizado con los
nodos de frontera,  
y puedes continuar con el paso 2 de las  
[instrucciones generales para dominios personalizados](./using-custom-domains#custom-domains-on-the-boundary-nodes).

## Amazon Route 53

A continuación, se detallan los pasos para configurar el dominio raíz y un
subdominio en  
Amazon Route 53 para su uso como dominio personalizado en un canister desplegado
en ICP.

### Dominio raíz (Apex)

Lamentablemente, Amazon Route 53 no permite configurar un registro `CNAME` (o
sus alternativas,  
como `ALIAS` o `ANAME`) para el dominio raíz. Por lo tanto, debes usar una
solución alternativa.  
Para obtener instrucciones, consulta los pasos explicados en la sección de
GoDaddy sobre  
["Usar un proveedor de DNS alternativo"](#rely-on-an-alternative-dns-provider-recommended).

### Subdominio

- #### Paso 1: Después de comprar tu dominio en Route 53, ve a **Zonas alojadas**

  y haz clic en tu dominio.

- #### Paso 2: Haz clic en el dominio para abrir la configuración de DNS.

- #### Paso 3: Configura tus registros DNS.

  Para configurar un subdominio (por ejemplo, `example.ic-domain.live`), agrega
  los  
  siguientes registros haciendo clic en **Añadir nuevo registro**:

  - Crea un registro `CNAME` en el que establezcas el campo "Host" como
    `example`  
    y el campo "Destino" como `example.ic-domain.live.icp1.io`.

  - Crea un registro `CNAME` en el que establezcas el campo "Host" como  
    `_acme-challenge.example` y el campo "Destino" como  
    `_acme-challenge.example.ic-domain.live.icp2.io`.

  - Crea un registro `TXT` en el que establezcas el campo "Host" como  
    `_canister-id.example` y el campo "Valor" como el ID del canister  
    `y5jqt-wqaaa-aaaam-abcoq-cai`.

La configuración resultante debería verse similar a la siguiente captura de
pantalla:

![Configuración DNS para `example.ic-domain.live` en Amazon Route 53](route53-subdomain.png)

Ahora, ya tienes todo listo para registrar tu dominio personalizado con los
nodos de frontera,  
y puedes continuar con el paso 2 de las  
[instrucciones generales para dominios personalizados](./using-custom-domains#custom-domains-on-the-boundary-nodes).
