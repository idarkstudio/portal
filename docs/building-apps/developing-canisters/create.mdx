# Crear

<MarkdownChipRow labels={["Principiante", "Desarrollando canisters"]} />

Antes de que un canister pueda ser desplegado, debe ser creado y registrado en
ICP, ya sea localmente, en el playground o en la mainnet. Cuando un canister es
creado inicialmente, está vacío y no contiene código ni estado; solo contiene la
configuración del canister, el ID del canister, el saldo de ciclos y los
controladores. Luego, el código fuente del canister debe ser compilado en
WebAssembly e instalado en el canister.

Una vez que tengas un proyecto que contenga un archivo `dfx.json` que defina los
canisters del proyecto, puedes crear uno de esos canisters usando el comando
`dfx canister create`.

:::info

La creación de canisters se realiza automáticamente en segundo plano cuando se
ejecuta el comando `dfx deploy`. Sin embargo, puede haber ciertos flujos de
trabajo en los que sea necesario crear un canister vacío.

:::

Los canisters se crean con el comando
[`dfx canister create`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-create).
Inicialmente están vacíos y no contienen código de programa. El código debe ser
[compilado](/docs/building-apps/developing-canisters/what-are-canisters) en Wasm
e [instalado](/docs/building-apps/developing-canisters/what-are-canisters) en el
canister vacío antes de que pueda ser desplegado.

Crea tus canisters desde el directorio del proyecto:

```
dfx canister create <canister-name> --network=<NETWORK>
```

Se pueden configurar ajustes durante la creación de un canister utilizando
banderas opcionales.
[Consulta la lista completa de configuraciones](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-create).

Cuando se crea un canister, ocurren los siguientes pasos:

- Un ID de canister es registrado con el replicador local o la mainnet para cada
  canister en el archivo `dfx.json` del proyecto.

- Se crean los siguientes componentes del canister:

  - Lista de controladores.
  - Saldo de ciclos.
  - Saldo de ciclos reservado.
  - Estado del canister.
  - Reservas de recursos.

- El ID de cada canister es devuelto en la línea de comandos.

### Errores relacionados con la creación de canisters

Los errores comunes relacionados con la creación de canisters incluyen:

- [Canister no encontrado](/docs/references/execution-errors#canister-not-found).
- [Se alcanzó el número máximo de canisters](/docs/references/execution-errors#maximum-number-of-canisters-reached).
