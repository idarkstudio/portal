# Instalar

<MarkdownChipRow labels={["Principiante", "Desarrollando canisters"]} />

Los módulos Wasm compilados deben ser instalados en un canister utilizando el
comando
[`dfx canister install`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-install)
desde el directorio del proyecto:

```
dfx canister install <canister-name> --network=<NETWORK>
```

Cuando el código de un canister es instalado, se crean los siguientes
componentes:

- El código del canister en forma de un módulo de canister.

- El estado del canister, incluyendo la memoria y los valores globales del
  canister.

- Información adicional específica de ICP, como las colas de entrada y salida
  del canister.

:::info

La instalación del canister se realiza automáticamente en segundo plano cuando
se ejecuta el comando `dfx deploy`. Sin embargo, puede haber ciertos flujos de
trabajo en los que sea necesario instalar manualmente el Wasm en un canister.

:::

### Instalación de un módulo WebAssembly comprimido con gzip

El tamaño de los programas que se pueden instalar en ICP está actualmente
limitado a 10 MiB. Los módulos WebAssembly que son (ligeramente) más grandes que
10 MiB aún pueden ser instalados en ICP utilizando compresión de archivos gzip
antes de cargarlos. ICP descomprimirá el archivo y luego instalará el módulo
WebAssembly contenido.

El módulo WebAssembly se comprime utilizando `gzip` y luego se carga con
`dfx canister install`. Es posible que necesites agregar `--mode reinstall` o
`--mode upgrade` cuando cargues el módulo en un canister existente.

```bash
gzip my-canister.wasm
dfx canister install my-canister --wasm my-canister.wasm.gz
```

Actualmente, la compresión no es compatible con `dfx deploy`.
