# Herramientas de Candid

<MarkdownChipRow labels={["Beginner", "Tutorial"]} />

Candid es un **lenguaje de descripción de interfaces** que puede ser utilizado
por los canisters de ICP para definir la interfaz pública de un servicio. Candid
es independiente del lenguaje y permite la interoperabilidad entre servicios y
frontends escritos en diferentes lenguajes de programación, incluyendo Motoko,
Rust y JavaScript.

Existen varias herramientas para facilitar la escritura, prueba e interacción
con Candid. A continuación se describen algunas de estas herramientas.

## didc

El CLI de Candid, conocido como `didc`, es una herramienta multipropósito que se
puede utilizar para ejecutar varias funciones de Candid, tales como comprobar la
validez de un archivo Candid, generar suites de pruebas para diferentes
lenguajes, codificar y decodificar datos binarios de Candid, y generar valores
Candid aleatorios.

Para usar `didc`, primero descarga el
[binario preconstruido](https://github.com/dfinity/candid/releases).

Los siguientes comandos de `didc` están disponibles:

| Comando                               | Descripción                                        | Ejemplo                                        | Respuesta de ejemplo                                                                                               |
| ------------------------------------- | -------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `didc check <INPUT> [PREVIOUS]`       | Verificar el tipo de un archivo Candid             | `didc check test_file.did`                     | Devuelve un error de analizador si es inválido; no devuelve nada si es válido.                                     |
| `didc bind --target <TARGET> <INPUT>` | Vinculación para diferentes lenguajes              | `didc bind hello.did -t js`                    | `export const idlFactory = ({ IDL }) => { return IDL.Service({ 'greet' : IDL.Func([IDL.Text] [IDL.Text], []) });}` |
| `didc test [OPTIONS] <INPUT>`         | Generar suites de prueba para diferentes lenguajes | `didc test -t did test_file.test.did`          | Devuelve un error de analizador si es inválido; no devuelve nada si es válido.                                     |
| `didc encode [OPTIONS] [ARGS]`        | Codificar valor Candid                             | `didc encode '(42, vec {1;2;-3})'`             | `4449444c016d7c027c002a0301027d`                                                                                   |
| `didc decode [OPTIONS] [BLOB]`        | Decodificar datos binarios Candid                  | `didc decode '4449444c016d7c027c002a0301027d'` |
| `didc random [OPTIONS]`               | Generar valores Candid aleatorios                  | `didc random -t '(int, text)'`                 | `(-72_594_379_354_493_140_610_202_928_640_651_761_468, "_J:t7^>")`                                                 |
| `didc hash <INPUT>`                   | Calcular el hash de un nombre de campo             | `didc hash '(int, text)'`                      | `2392326401`                                                                                                       |
| `didc subtype [OPTIONS] <TY1> <TY2>`  | Verificar subtipos                                 | `didc subtype func () -> (t1)`                 | El resultado es `reference` o `null`                                                                               |

## Candid UI

Candid UI es una herramienta basada en la web que se utiliza para interactuar
con la interfaz Candid de un canister. Se genera automáticamente para cada
canister con una definición Candid cuando el canister es desplegado. Sin
embargo, también puede ser utilizada a través del
[canister UI de Candid](https://a4gq6-oaaaa-aaaab-qaa4q-cai.raw.ic0.app/) en la
red principal, lo que permite proporcionar un ID de canister o cargar un archivo
`.did` para interactuar con la interfaz Candid del canister.

Puedes aprender más sobre cómo utilizar Candid en
[interactuar con un servicio desde un navegador](/docs/building-apps/interact-with-canisters/candid/using-candid#interact-with-a-service-from-a-browser).

## ic-repl

`ic-repl` es un entorno REPL que se puede utilizar para comunicarse con
canisters utilizando Candid. La documentación de `ic-repl` se puede encontrar
[en el repositorio de GitHub de ic-repl](https://github.com/dfinity/ic-repl).

## Suite de pruebas de Candid

Para realizar pruebas adicionales de Candid, puedes utilizar la
[Suite de pruebas de Candid](https://github.com/dfinity/candid/blob/master/test),
que utiliza datos de prueba Candid para verificar el cumplimiento de la
implementación. La suite de pruebas cubre:

- Análisis de descripciones de servicios Candid.

- Decodificación de datos binarios Candid para un tipo Candid dado y
  comprobación de éxito o fallo.

- Análisis de datos Candid en formato textual para un tipo Candid dado y
  comprobación de éxito o fallo.

- Comparación de valores decodificados/analizados utilizando el concepto de
  igualdad del lenguaje host.

Actualmente, la suite de pruebas de Candid no incluye pruebas para la
codificación, ya que el formato binario Candid no es canónico. Se recomienda que
las implementaciones de esta suite de pruebas sean extendidas con pruebas de ida
y vuelta aleatorias (valor host → candid → valor host) para cubrir la
codificación.
