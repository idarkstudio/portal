# Agente Rust de ICP

<MarkdownChipRow labels={["Intermedio", "Agentes"]} />

El [agente Rust de ICP](https://docs.rs/ic-agent/latest/ic_agent/) de DFINITY es
una biblioteca simple que te permite construir aplicaciones e interactuar con
ICP, sirviendo como un backend de bajo nivel en Rust para el SDK de IC.

El agente está diseñado para ser compatible con múltiples versiones de la API
del réplica, exponiendo tanto APIs de bajo nivel para comunicarse con
componentes como el réplica, como APIs de nivel superior para comunicarse con
aplicaciones de software desplegadas como canisters.

Un ejemplo de implementación del agente Rust de ICP es
[`dfx`](https://github.com/dfinity/sdk).

## Agregar el agente como dependencia

Para agregar el crate del agente Rust de ICP como dependencia en tu proyecto,
usa el comando:

```
cargo add ic-agent
```

## Inicializando el agente

Antes de usar el agente en tu proyecto, debe ser inicializado usando la función
`Agent::builder()`. Aquí tienes un ejemplo de cómo inicializar el agente Rust:

```rust
use anyhow::Result;
use ic_agent::Agent;

pub async fn create_agent(url: &str, is_mainnet: bool) -> Result<Agent> {
    let agent = Agent::builder().with_url(url).build()?;
    if !is_mainnet {
        agent.fetch_root_key().await?;
    }
    Ok(agent)
}
```

### Usando enrutamiento dinámico

El agente Rust de ICP proporciona funcionalidad de enrutamiento dinámico
incorporada, permitiendo que una aplicación se comunique sin problemas a través
de nodos de frontera de API descentralizados para un rendimiento óptimo. Para
habilitar el enrutamiento dinámico, el agente debe ser inicializado con una URL
de inicio. Usando esta URL inicial, el agente:

- Obtiene la lista de nodos de frontera de API disponibles.
- Monitorea continuamente la salud de estos nodos.
- Rutea automáticamente las solicitudes al nodo más cercano y saludable.

Aquí tienes un ejemplo de cómo configurar tu agente con enrutamiento dinámico:

```rust
let agent = Agent::builder()
    .with_url(URL)
    .with_background_dynamic_routing()
    .await
    .build()
    .expect("failed to build ic-agent");
```

## Autenticación

El objeto `Identity` del agente Rust proporciona firmas que se pueden usar para
solicitudes HTTP o delegaciones de identidad. Representa el ID principal del
remitente. `Identity` representa una única identidad y no puede contener
múltiples valores de identidad.

```rust
async fn create_a_canister() -> Result<Principal, Box<dyn std::error::Error>> {
  let agent = Agent::builder()
    .with_url(URL)
    .with_identity(create_identity())
    .build()?;
```

Las identidades pueden tener diferentes tipos, tales como:

- `AnonymousIdentity`: Un tipo de unidad usado a través de
  `with_identity(AnonymousIdentity)`.

- `BasicIdentity`, `Secp256k1Identity` y `Prime256v1Identity`: Creado a partir
  de claves preexistentes mediante alguna de las funciones:
  - `BasicIdentity::from_pem_file("path/to/identity.pem")`
  - `BasicIdentity::from_key_pair(key_material)`

Existen ligeras
[variaciones en el nombre de las funciones](https://docs.rs/ic-agent/latest/ic_agent/identity/index.html).

- `ic-identity-hsm` crate: Usado para módulos de seguridad hardware (HSM) como
  Yubikey o Nitrokey a través de
  `HardwareIdentity::new(pkcs11_module_path, slot_index, key_id, || get_pin())`.

## Realizando llamadas

El agente Rust puede ser usado para hacer llamadas a otros canisters. Para hacer
una llamada a un canister, usa el método `agent.update` para una llamada de
actualización o `agent.query` para una llamada de consulta. Luego, pasa el ID
del canister y el método del canister que te gustaría llamar.

El siguiente ejemplo llama al libro mayor de ICP y retorna el saldo de una
cuenta:

```rust
let icp_ledger = Principal::from_text("ryjl3-tyaaa-aaaaa-aaaba-cai").unwrap();
let response = agent.update(&icp_ledger, "account_balance")
    .with_arg(Encode!(&AccountBalanceArgs { account: some_account_id })?)
    .call_and_wait()
    .await?;
let tokens = Decode!(&response, Tokens)?;
```

## `ic-utils`

El crate [`ic-utils`](https://crates.io/crates/ic-utils) proporciona una
interfaz de alto nivel diseñada para estar orientada a canisters y consciente de
la interfaz Candid del canister. Los objetos de canister con `ic-utils` se
parecen a lo siguiente:

```rust
let canister = Canister::builder()
    .with_agent(&agent)
    .with_canister_id(principal)
    .build()?;
canister.query("account_balance")
    .with_arg(&AccountBalanceArg { user_id })
    .build()
    .await
```

`ic-utils` proporciona varias interfaces, incluyendo el canister de gestión, el
canister de billetera de ciclos, y el canister de integración con Bitcoin. Por
ejemplo, el canister de gestión puede ser utilizado con una llamada como
`ManagementCanister::create(&agent).canister_status(&canister_id).await`.

[Aprende más en la documentación de ic-utils](https://docs.rs/ic-utils/latest/ic_utils/).

## Verificación de respuesta

Al usar la
[funcionalidad de consultas certificadas](/docs/building-apps/interact-with-canisters/advanced-calls/)
el agente debe verificar que el certificado devuelto con la respuesta de la
consulta sea válido. Un certificado consiste en un árbol, una firma en el hash
raíz del árbol que es válida bajo una clave pública, y una delegación opcional
que vincula la clave pública con la clave raíz pública. Para validar el hash
raíz, el agente usa el módulo `HashTree`.

A continuación se muestra un ejemplo anotado con notas que explican cómo
verificar respuestas usando el módulo `HashTree`:

```rust
// Define una función que inicializa el agente y construye una llamada de consulta certificada para obtener la tasa de conversión XDR e ICP desde el canister minter de ciclos:
pub async fn xdr_permyriad_per_icp(agent: &Agent) -> DfxResult<u64> {
    let canister = Canister::builder()
        .with_agent(agent)
        .with_canister_id(MAINNET_CYCLE_MINTER_CANISTER_ID)
        .build()?;
    let (certified_rate,): (IcpXdrConversionRateCertifiedResponse,) = canister
        .query("get_icp_xdr_conversion_rate")
        .build()
        .call()
        .await?;
    // Verifica el certificado con una llamada de consulta
    let cert = serde_cbor::from_slice(&certified_rate.certificate)?;
    agent
        .verify(&cert, MAINNET_CYCLE_MINTER_CANISTER_ID)
        .context(
            "No se pudo verificar el origen del certificado para la tasa de cambio XDR <> ICP",
        )?;
    // Verifica que el certificado sea confiable:
    let witness = lookup_value(
        &cert,
        [
            b"canister",
            MAINNET_CYCLE_MINTER_CANISTER_ID.as_slice(),
            b"certified_data",
        ],
    )
    .context("No se pudo verificar el certificado del IC para la tasa de cambio XDR <> ICP")?;
    // Llama a HashTree para la llamada de certified_rate:
    let tree = serde_cbor::from_slice::<HashTree<Vec<u8>>>(&certified_rate.hash_tree)?;
    ensure!(
        tree.digest() == witness,
        "El certificado del CMC para la tasa de cambio XDR <> ICP no coincidió con el certificado del IC"
    );
    // Verifica que HashTree sea confiable:
    let lookup = tree.lookup_path([b"ICP_XDR_CONVERSION_RATE"]);
    let certified_data = if let LookupResult::Found(content) = lookup {
        content
    } else {
        bail!("El certificado del CMC no contenía la tasa de cambio XDR <> ICP");
    };
    let encoded_data = Encode!(&certified_rate.data)?;
    ensure!(
        certified_data == encoded_data,
        "El certificado del CMC para la tasa de cambio XDR <> ICP no coincidió con la tasa proporcionada"
    );
    // Si las verificaciones anteriores son exitosas, puedes confiar en la tasa de cambio devuelta:
    Ok(certified_rate.data.xdr_permyriad_per_icp)
}
```

Otra aplicación de `HashTree` se puede encontrar en el
[código de ic-certified-assets](https://github.com/dfinity/sdk/blob/master/src/canisters/frontend/ic-certified-assets/src/asset_certification/tree.rs).

## Ejemplo

A continuación se muestra un ejemplo de cómo usar la interfaz del agente para
hacer una llamada a un canister (en este ejemplo, el libro mayor de ICP)
desplegado en la red principal:

```rust
use ic_agent::{Agent, export::Principal};
use candid::{Encode, Decode, CandidType, Nat};
use serde::Deserialize;

#[derive(CandidType)]
struct AccountBalanceArgs {
    account: Vec<u8>,
}
#[derive(CandidType, Deserialize)]
struct Tokens {
    e8s: u64,
}
let icp_ledger = Principal::from_text("ryjl3-tyaaa-aaaaa-aaaba-cai").unwrap();
let response = agent.update(&icp_ledger, "account_balance")
    .with_arg(Encode!(&AccountBalanceArgs { account: some_account_id })?)
    .call_and_wait()
    .await?;
let tokens = Decode!(&response, Tokens)?;
```
