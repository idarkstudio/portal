# Tokens & cycles

<MarkdownChipRow labels={["Principiante", "Primeros pasos"]} />

Para los desarrolladores de ICP, hay dos tokens importantes:

1. El **token ICP** es el token de utilidad nativo del protocolo, que puede
   comprarse y negociarse en varios exchanges. Juega un papel clave en la
   gobernanza y economía de la red.

2. Los **cycles** (ciclos) se utilizan para pagar el consumo de recursos y
   servicios, comparables al gas en Ethereum. El precio de los cycles está
   vinculado al
   [XDR](https://es.wikipedia.org/wiki/Derechos_especiales_de_giro), un grupo de
   monedas fiduciarias, donde **1 billón (T) de cycles equivale a 1 XDR** (1 XDR
   equivale aproximadamente a 1.3 USD a principios de 2025).

Los tokens ICP pueden convertirse en cycles, que luego se utilizan para cubrir
el costo de ejecutar una aplicación.

Nota: ICP permite crear e implementar tokens fungibles o no fungibles
personalizados a través de los [estándares ICRC](/docs/defi/token-standards/).

## Consumo de recursos de los canisters

Los canisters requieren recursos como almacenamiento, capacidad de cómputo y
ancho de banda de red. Cuando un canister se implementa en la red principal,
utiliza los recursos proporcionados por los nodos de la red. Los canisters pagan
por los recursos que usan, las llamadas que envían y cualquier operación que
realicen utilizando funciones especializadas como llamadas externas HTTPS,
firmas de umbral y la API de integración de Bitcoin. Cada tipo de operación y
recurso del canister tiene un costo diferente asociado, y los costos escalan
linealmente con el número de nodos en el subred.

Un canister paga por los recursos consumidos quemando cycles. Es responsabilidad
del desarrollador cargar cada uno de sus canisters con cantidades adecuadas de
cycles, aunque cualquiera puede enviar cycles a cualquier canister. Este modelo
de costos se conoce como **modelo de gas inverso** de ICP.

### Implementaciones locales y en playground

Los canisters implementados localmente están limitados a los recursos
proporcionados por tu máquina local. Las implementaciones locales utilizan
cycles fabricados generados por `dfx`.

Los canisters implementados con la opción de playground
([ver guía rápida](/docs/building-apps/getting-started/quickstart)) se
implementan en un grupo de canisters administrados por DFINITY que se reciclan
cada 20 minutos. Similar a una testnet, esto permite a los desarrolladores
implementar rápidamente su primer contrato inteligente de canister sin necesidad
de adquirir tokens ICP y convertirlos en cycles. Dado que la implementación en
el playground es gratuita, existen limitaciones en los recursos que se pueden
utilizar y en las funciones disponibles para los canisters.

## ¿Qué es un ledger?

Un [**ledger**](/docs/defi/overview) es un canister del sistema que almacena
saldos y transacciones de tokens para un conjunto de cuentas. Cada token tiene
su propio ledger, como el ledger del token ICP y el ledger de cycles.

[Aprende más sobre ledgers](/docs/defi/overview).

## Obtención de cycles

Necesitas obtener [tokens ICP](https://internetcomputer.org/icp-tokens) y luego
convertirlos en cycles usando `dfx`. Sin embargo, cuando participas en eventos
de DFINITY como [hackathones](https://dfinity.org/hackathons), puedes recibir un
cupón que puedes canjear para reclamar cycles gratis del
[faucet de cycles](https://anv4y-qiaaa-aaaal-qaqxq-cai.ic0.app/).

Antes de obtener cycles, necesitas una
[identity de desarrollador](identities.mdx). Cada identity de desarrollador
tiene un principal y un identificador de cuenta en el ledger.

Un principal tiene el formato
`itk7v-ihlxk-ktdrh-fcnst-vkoou-orj77-52ogl-jqwj5-zpfdv-az3lr-xqe` y se utiliza
para la propiedad y gestión de canisters, así como para mantener cycles.

Un identificador de cuenta en el ledger tiene el formato
`e213184a548871a47fb526f3cba24e2ee2fbbc8129c4ab497ef2ce535130a0a4` y se utiliza
para enviar y recibir tokens como ICP.

### Paso 1: Obtén el ID de cuenta del ledger (account id).

```
dfx ledger account-id
```

<summary>Salida</summary>

```
b0d7beee54be8679a42e999218a16a0d396f223d7e44d259ac089848c1b820bf
```

</details>

### Paso 2: Enviar tokens ICP a este account-id del ledger

Puedes obtener [tokens ICP](https://internetcomputer.org/icp-tokens) desde un
[exchange](https://coinmarketcap.com/currencies/internet-computer/markets). Si
estás usando un exchange, inicia una transacción de retiro e ingresa el ID de
cuenta del ledger como dirección de "destino" para enviar los tokens ICP.

### Paso 3: Verificar el balance de ICP.

```
dfx ledger balance --network=ic
```

<details>
<summary>Salida</summary>

```
2.00000000 ICP
```

</details>

### Paso 4: Convertir ICP en cycles

Debido a que el consumo de recursos se contabiliza a un nivel muy detallado, un
solo ciclo corresponde a una cantidad muy pequeña de dinero. Como resultado, los
desarrolladores manejan grandes cantidades de cycles al recargar sus canisters,
normalmente operando con billones (T) de ciclos. Dado que los ciclos están
vinculados al XDR, 1T de ciclos se mantendrá estable en aproximadamente 1.3 USD.

Reemplaza `AMOUNT` con el número de tokens ICP que deseas convertir en ciclos.:

```
dfx cycles convert --amount AMOUNT --network=ic
```

<details>
<summary>Salida</summary>

```
Transfer sent at block height 16146446
Using transfer at block height 16146446
Account was topped up with 6_229_700_000_000 cycles! New balance is 6_229_600_000_000 cycles.
```

</details>

Este comando debe ejecutarse con la bandera `--network=ic` porque los cycles se
fabrican durante el desarrollo local.

### Calculando cuántos cycles necesitas

Los cycles se cobran por almacenamiento, cómputo, mensajes de actualización,
características especiales y más. Para obtener una aproximación, puedes ver la
[tabla detallada de costos de cycles](/docs/building-apps/essentials/gas-cost) o
utilizar la
[calculadora de precios de cycles](/docs/building-apps/essentials/cost-estimations-and-examples).

### Paso 5: Confirmar el saldo de cycles.

```
dfx cycles balance --network=ic
```

<details>
<summary>Salida</summary>

```
6.230 TC (trillion cycles).
```

</details>
