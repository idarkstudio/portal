# Identidades de desarrollador

<MarkdownChipRow labels={["Principiante", "Comenzando"]} />

Una **identity** de desarrollador es esencial para desarrollar canisters. Las
identities de desarrollador son básicamente un par de claves pública/privada. En
lugar de utilizar la clave pública como identificador de la identity, se deriva
un llamado principal a partir de la clave pública. Los términos **identity** y
**principal** se utilizan a menudo indistintamente. Para una mejor
memorabilidad, cada identity de desarrollador en `dfx` tiene un nombre. La clave
pública de una identity se puede distribuir abiertamente, ya que se utilizará
para cifrar mensajes. La clave privada debe mantenerse en secreto y almacenarse
de forma segura.

## ¿Para qué se utilizan las identities de desarrollador?

Cuando se crea y despliega un canister, la identity/principal del desarrollador
que creó el canister se establece automáticamente como **controlador** de ese
canister. Un controlador tiene permiso para administrar el canister, lo que
incluye:

- Iniciar y detener el canister.

- Instalar y actualizar el código del canister.

- Ver el estado y los registros del canister.

- Configurar la configuración del canister, como establecer la asignación de
  recursos o agregar controladores adicionales.

Si estás trabajando en un proyecto de forma colaborativa con otros, la identity
principal de tu identity se puede agregar como controlador de los canisters de
ese proyecto.

Una vez que se despliega un canister, consumirá recursos como almacenamiento y
cómputo. Los canisters deben pagar por estos recursos utilizando **ciclos**. Tu
identity de desarrollador se utiliza para acuñar y transferir ciclos a tus
canisters.

## Crear una identidad

De forma predeterminada, `dfx` creará y utilizará la identidad `default`. Esta
identidad no se almacena de forma segura. Se recomienda que crees tu propia
identidad personal.

Primero, utiliza `dfx` para listar todas las identidades actuales. Si no existe
ninguna, se creará automáticamente la identidad `default`.

```
dfx identity list
```

Crea una nueva identity de desarrollador con el comando:

```
dfx identity new IDENTITY_NAME
```

Las identidades creadas con `dfx` son globales; no están limitadas al contexto
de un proyecto específico.

Los nombres de las identidades deben utilizar los caracteres
`ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz.-_@0123456789`.

### Almacenamiento de la clave privada de la identity de desarrollador

La clave privada de una identity se almacena en
`~/.config/dfx/identity/IDENTITY_NAME/identity.pem`. Este archivo debe ser
respaldado en un lugar seguro.

De forma predeterminada, `dfx` almacenará tu identity en el keyring/keychain
local. Si no está disponible un keyring/keychain, te pedirá que elijas una
contraseña y luego almacenará tu clave privada localmente en un archivo PEM
protegido por contraseña en
`~/.config/dfx/identity/IDENTITY_NAME/identity.pem.encrypted`.

Asegúrate de cambiar a la identity recién creada como se explica a continuación.

### Copia de seguridad y recuperación

Cuando creas una nueva identity con `dfx identity new`, se devolverá una frase
de semilla en la salida del comando. Esta frase de semilla solo se muestra una
vez y se puede utilizar para recuperar tu identity si es necesario. Por lo
tanto, esta frase de semilla debe ser respaldada en un lugar seguro, como un
administrador de contraseñas como 1Password o en un lugar sin conexión, como
escrita en un papel.

Para recuperar una identity, utiliza
`dfx identity import --seed-file seedphrase.txt`, donde `seedphrase.txt`
contiene la frase de semilla mostrada al crear tu identity.

Si no guardaste la frase de semilla, puedes utilizar `dfx identity export` para
mostrar la clave privada. No hay forma de obtener la frase de semilla a partir
de una clave privada; por lo tanto, debes respaldar este archivo de la misma
manera que cualquier otro archivo importante y seguro.

## Uso de tu identity de desarrollador

En cualquier momento, una identity está activa y es utilizada por `dfx`. Obtén
el nombre de la identity actualmente activa ejecutando:

```
dfx identity whoami
```

Para obtener el principal de la identity actualmente activa, ejecuta:

```
dfx identity get-principal
```

Tu identity de desarrollador tendrá un identificador principal en el formato
`itk7v-ihlxk-ktdrh-fcnst-vkoou-orj77-52ogl-jqwj5-zpfdv-az3lr-xqe`.

La lista de todas las identidades disponibles se puede obtener ejecutando:

```
dfx identity list
```

Para utilizar activamente otra identity de desarrollador, ejecuta:

```
dfx identity use IDENTITY_NAME
```
