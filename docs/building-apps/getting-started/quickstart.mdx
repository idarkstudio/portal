# Inicio rápido

<MarkdownChipRow labels={["Principiante"]} />

Construye aplicaciones Web3, DeFi, redes sociales completamente residentes en la
red, juegos, aplicaciones empresariales y prácticamente cualquier otra cosa que
puedas imaginar. Tus proyectos son inmunes a los ciberataques e imparables.

**Abre tu terminal y despliega en minutos siguiendo estos pasos.**

<AdornedTabs defaultValue={useOs().current}>
<TabItem value={OsType.Linux} label="Linux">

#### Prerrequisitos

<input type="checkbox" /> Descargar e <a href="https://nodejs.org/en/download/package-manager">
  instalar Node.js
</a>
.<div></div>
<input type="checkbox" /> Instalar el paquete <a href="https://github.com/libunwind/libunwind">
  libunwind
</a>. En Debian/Ubuntu: <code>sudo apt install libunwind-dev</code>.

---

#### 1. Instala el IC SDK.

```bash
sh -ci "$(curl -fsSL https://internetcomputer.org/install.sh)"
```

Confirma que el IC SDK se haya instalado (es posible que necesites abrir una
nueva ventana de terminal):

```bash
dfx --version
```

#### 2. Crea un nuevo proyecto.

```
dfx new hello --type motoko --frontend react
```

Esto genera una aplicación simple "Hola, [nombre]!" que utiliza
[Motoko](/docs/motoko/main/getting-started/motoko-introduction), React y
TypeScript.

#### 3. Despliega el proyecto.

```
cd hello
dfx deploy --playground
```

#### 4. Interactúa con la aplicación.

Abre la URL `frontend` en un navegador web. Verás la interfaz frontal de React
del template.

_¡Felicidades, acabas de crear tu primera aplicación nativa de Internet!_

:::info

Puedes probar otros templates. Ejecuta `dfx new -h` para obtener más información
sobre las opciones de backend y frontend admitidas.

:::
