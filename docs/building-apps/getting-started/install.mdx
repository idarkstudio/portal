# Instalar el IC SDK

<MarkdownChipRow labels={["Principiante", "Empezando"]} />

El IC SDK es un kit de desarrollo de software utilizado para desarrollar
aplicaciones en tu máquina local y desplegarlas en ICP. Es compatible de forma
nativa en Linux o macOS 12.\* Monterey y versiones más recientes. Los usuarios
de Windows pueden utilizar el IC SDK con Windows Subsystem for Linux (WSL 2).

:::danger

Si has seguido una
[guía de inicio rápido](/docs/building-apps/getting-started/quickstart), puedes
omitir este paso.

:::

```bash
sh -ci "$(curl -fsSL https://internetcomputer.org/install.sh)"
```

Para personalizar tu instalación del IC SDK, puedes usar el mensaje interactivo
de instalación o configurar
[variables de entorno](/docs/building-apps/developer-tools/dfx/dfx-envars) para

Verifica que el IC SDK se haya instalado correctamente (puede que necesites
abrir una nueva ventana de terminal):

```bash
dfx --version
```

La última versión del [IC SDK](https://github.com/dfinity/sdk) (v0.25.0) está
compuesta por:

- `dfx`: Una herramienta de línea de comandos utilizada para crear y administrar
  proyectos, identidades de desarrollador y

  <GlossaryTooltip>ciclos</GlossaryTooltip>.

- [`dfxvm`](/docs/building-apps/developer-tools/dev-tools-overview#dfxvm): Un
  administrador de versiones para `dfx` utilizado para descargar una versión
  específica de `dfx`, establecer una versión predeterminada y actualizar a la
  última versión.

- `moc` (v0.14.3): El compilador
  [Motoko](/docs/motoko/main/getting-started/motoko-introduction) para admitir
  el desarrollo de canisters de Motoko.

:::info Otros lenguajes como Rust son compatibles mediante la instalación de un
[kit de desarrollo de canisters (CDK) por separado](/docs/building-apps/developer-tools/cdks/rust/intro-to-rust).
:::

- `replica`: Una instancia local del software que se ejecuta en cada nodo de la
  red principal. Se utiliza para implementar y alojar tu aplicación localmente
  para pruebas y desarrollo.

Para solucionar problemas comunes de `dfx`, consulta
[Solución de problemas del IC SDK](troubleshooting.mdx).
