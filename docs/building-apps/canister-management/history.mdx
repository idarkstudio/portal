# Historial de Canister

<MarkdownChipRow labels={["Principiante", "Administración"]} />

Internet Computer rastrea el historial de un

<GlossaryTooltip>canister</GlossaryTooltip> desplegado a través de los hashes del
módulo Wasm del canister y los cambios en sus controladores. Este seguimiento proporciona
información sobre el historial del canister, como qué código se ha utilizado para
ejecutarlo y qué controlador desplegó dicho código.

Ver el historial de un canister puede ser importante en casos como:

- Verificar que el controlador de un canister no haya modificado maliciosamente
  el código.

- Verificar que el controlador de un canister no cambie maliciosamente la lista
  de controladores. Por ejemplo, si la lista de controladores de un canister
  solo muestra el canister de gobernanza como controlador actual, los usuarios
  pueden confiar en que el código del canister no ha sido alterado de manera
  maliciosa.

## Cómo funciona el historial de canister

El historial de canister fue introducido y publicado a través de la propuesta de
la NNS DAO  
[122617](https://dashboard.internetcomputer.org/proposal/122617).

La información del historial de un canister está disponible a través de llamadas
inter-canister al método `canister_info` del canister de administración,
utilizando el ID del canister como argumento. Un historial de canister almacena
los 20 cambios más recientes en el canister, incluyendo su creación,
instalaciones del módulo Wasm, reinstalaciones, actualizaciones y cambios en la
lista de controladores. Es importante tener en cuenta que, dado que solo se
almacenan los 20 cambios más recientes, esta función no puede utilizarse para
auditar canisters que cambian con frecuencia en un corto período de tiempo.

:::danger

El historial de canister solo está disponible para los cambios ocurridos desde
que esta función se implementó el 5 de junio de 2023 a las 9:47:46 AM UTC, en
todas las <GlossaryTooltip>subnets</GlossaryTooltip>.

:::

Puedes obtener más información sobre esta función en el  
[foro de desarrolladores](https://forum.dfinity.org/t/canister-history-on-the-ic/21745).

## Obtener el historial de un canister

Para obtener el historial de un canister, realiza una llamada al método
`canister_info` del canister de administración de IC:

<AdornedTabs groupId="language">
<TabItem value="motoko" label="Motoko" default>

```motoko
import Principal "mo:base/Principal";

actor Info {
  type canister_info_args = {
    canister_id : Principal;
    num_requested_changes : ?Nat64
  };

  type canister_info_result = {
    total_num_changes : Nat64;
    module_hash : ?Blob;
    controllers : [Principal]
  };

  let IC = actor "aaaaa-aa" : actor {
    canister_info : {canister_id : Principal} -> async canister_info_result
  };

  public func getInfo() : async canister_info_result {
    await IC.canister_info {canister_id = Principal.fromActor(Info)}
  }

}
```
