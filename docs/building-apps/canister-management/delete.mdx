# Eliminando un canister

<MarkdownChipRow labels={["Principiante", "Gestión"]} />

Si deseas eliminar permanentemente un canister específico o todos los canisters
de un proyecto, puedes utilizar el comando
[`dfx canister delete <nombre-del-canister>`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-delete).

Eliminar un canister elimina permanentemente su código y estado. Esta acción no
se puede deshacer y una vez que el canister se elimina, su ID no se puede
reutilizar. Antes de poder eliminar un canister, debes detenerlo primero
utilizando el comando
[`dfx canister stop <nombre-del-canister>`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-stop)
para eliminar cualquier solicitud o respuesta de mensaje pendiente.
