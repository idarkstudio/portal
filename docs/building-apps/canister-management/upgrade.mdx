# Upgrading a canister

<MarkdownChipRow labels={["Principiante", "Gestión"]} />

A diferencia de una reinstalación de

<GlossaryTooltip>canister</GlossaryTooltip>, que conserva el identificador del
canister pero no su estado, una actualización de canister permite preservar el
estado del canister desplegado mientras se modifica su código.

Por ejemplo, supongamos que tienes una dapp que gestiona perfiles profesionales
y conexiones sociales. Si deseas agregar una nueva funcionalidad a la dapp,
necesitas poder actualizar el código del canister sin perder los datos
almacenados previamente. Una actualización de canister te permite modificar el
código manteniendo el estado del programa.

:::tip

Para preservar el estado al actualizar un canister escrito en Motoko, asegúrate
de usar la palabra clave `stable` para identificar las variables que deseas
conservar. Para más información sobre cómo preservar el estado de variables en
Motoko, consulta la sección sobre  
[variables estables y métodos de actualización](/docs/motoko/main/canister-maintenance/upgrades).

:::

## Pasos para actualizar un canister

Para actualizar un canister, primero debes:

1. Editar el código del canister y guardar los cambios.
2. Compilar el código en un nuevo módulo Wasm usando:  
   [`dfx build <canister-name>`](/docs/building-apps/developer-tools/dfx/dfx-build).
3. Instalar el nuevo módulo Wasm con el modo de actualización usando:  
   [`dfx canister install <canister-name> --mode upgrade`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-install).
