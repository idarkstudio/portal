# Instantáneas de canister

<MarkdownChipRow labels={["Beginner", "Gestión"]} />

Un <GlossaryTooltip>canister</GlossaryTooltip> es gestionado y mantenido por
**controladores**. Un controlador puede ser una única identidad de
desarrollador, una lista de identidades de desarrollador o incluso otro
canister. Si un canister no tiene un controlador, no puede ser actualizado,
eliminado o mantenido de otra manera. Esto también aplica si se pierde el acceso
a todas las identidades de los controladores del canister. Si el código de un
canister falla con un error irrecuperable y no puede ser actualizado, el
canister puede ser recuperado potencialmente utilizando instantáneas del
canister o mediante una propuesta de NNS.

Una forma de recuperar un canister es volver a una instantánea si existe una.

Un <GlossaryTooltip>canister</GlossaryTooltip> contiene código Wasm compilado y
datos, tales como el ID del canister, configuraciones y memoria Wasm. Si un
canister deja de funcionar como se espera, falla o simplemente necesita ser
revertido a una versión anterior, el desarrollador puede usar instantáneas de
canister. Los desarrolladores pueden tomar una instantánea de un canister
detenido para guardar la memoria estable, memoria heap, datos y el módulo Wasm
del canister. Esta instantánea puede ser cargada en una fecha posterior,
volviendo el canister al código y datos guardados en esa instantánea.

Las instantáneas de canister son compatibles con la versión `dfx` 0.23.0 y
versiones posteriores.

## Creando una instantánea

Para crear una instantánea, primero el canister debe ser detenido. Luego, usa el
comando
[`dfx canister snapshot create <nombre-canister>`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-snapshot-create):

```
dfx canister stop <canister-name>
dfx canister snapshot create <canister-name>
```

<details>
<summary>Salida</summary>

```
Created a new snapshot of canister <canister-name>. Snapshot ID: 0000000000000000800000000010000a0101
```

</details>

Solo un controlador de un canister puede crear una instantánea o devolver un
canister a una instantánea.

Actualmente, solo se puede guardar una instantánea por canister. Tomar otra
instantánea de un canister que ya tenga una instantánea guardada sobrescribirá
la instantánea anterior.

Para tomar una instantánea de un canister en la red principal, incluye el flag
`--network ic` en los dos comandos mencionados anteriormente.

El ID de la instantánea se puede usar para cargar la instantánea más tarde. Para
listar todas las instantáneas guardadas de un canister, usa el comando
[`dfx canister snapshot list <nombre-canister>`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-snapshot-list):

```
dfx canister snapshot list <canister-name>
```

```

```

</details>

## Cargando una instantánea

Para cargar una instantánea guardada, primero el canister debe ser detenido.
Luego, usa el comando
[`dfx canister snapshot load <nombre-canister> <id-instantánea>`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-snapshot-load):

```
dfx canister stop <canister-name>
dfx canister snapshot load <canister-name> <snapshot-id>
```

Cargar una instantánea reemplazará el código y los datos actuales del canister
con el código y los datos de la instantánea. Cualquier dato nuevo que se haya
añadido al canister después de que se tomó la instantánea será eliminado.

## Eliminando instantáneas

Para eliminar una instantánea guardada, usa el comando
[`dfx canister snapshot delete <nombre-canister> <id-instantánea>`](/docs/building-apps/developer-tools/dfx/dfx-canister#dfx-canister-snapshot-delete):

```
dfx canister snapshot delete <canister-name> <snapshot-id>
```

## Recuperando un canister que no tiene controladores

Si un canister no puede ser actualizado a través de los controladores existentes
del canister, ya sea porque el canister no tiene controladores o por la pérdida
de acceso a los controladores del canister, no existe un método soportado para
recuperar ese canister.
