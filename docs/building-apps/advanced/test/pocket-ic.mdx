# PocketIC

<MarkdownChipRow labels={["Intermedio", "Desarrollando canisters"]} />

PocketIC es una solución de prueba ligera y determinista para pruebas
programáticas de <GlossaryTooltip>canisters</GlossaryTooltip>. Se integra sin
problemas con la infraestructura de prueba existente, como `cargo test`, y se
ejecuta como un binario independiente que no requiere contenedores adicionales
ni máquinas virtuales. Actualmente, PocketIC es compatible con sistemas host
macOS y Linux.

Si bien existen otras opciones para probar canisters, pueden presentar
inconvenientes como:

- Instalar y probar canisters en la mainnet proporciona la experiencia de flujo
  de trabajo "real", pero costará ciclos reales a los desarrolladores.

- Probar con la <GlossaryTooltip>réplica</GlossaryTooltip> local proporcionada
  por `dfx` permite realizar pruebas en un solo nodo del IC, pero no tiene
  funcionalidad cross-net ni multi-subnet. Las pruebas con la réplica local no
  son deterministas y son bastante pesadas. Además, probar con `dfx` puede ser
  complejo, lento y requerir código adicional para funcionar.

PocketIC está diseñado para solucionar estos inconvenientes, proporcionando un
entorno de prueba con los siguientes beneficios:

- **Determinista**: Control síncrono sobre el entorno de ejecución local del
  canister. PocketIC elimina las partes no deterministas de la réplica para
  hacer que las pruebas sean completamente reproducibles.

- **Ligero**: Solo proporciona los componentes necesarios y elimina las capas de
  consenso y red.

- **Instancias IC concurrentes e independientes**: Permite ejecutar pruebas en
  paralelo.

- **Soporte para múltiples lenguajes**: Actualmente compatible con Rust, Python
  y JavaScript/TypeScript, pero permite integración con cualquier lenguaje que
  utilice la API REST de PocketIC.

- **Versátil**: Proporciona control detallado sobre el canister, permitiendo
  establecer memoria estable, controlar el paso del tiempo y modificar otras
  variables del entorno de prueba.

- **Compatibilidad con llamadas Xnet y múltiples subnets.**

## PocketIC Rust

Para usar PocketIC, se debe descargar el binario más reciente del servidor
PocketIC desde el repositorio de PocketIC.  
[Descargar la última versión para sistemas macOS o Linux](https://github.com/dfinity/pocketic?tab=readme-ov-file#download-the-pocketic-server).

:::info

PocketIC actualmente no es compatible de forma nativa con sistemas Windows.

:::

El binario de PocketIC se puede dejar en el directorio de trabajo o se puede
especificar su ruta estableciendo la variable de entorno `POCKET_IC_BIN`.

Añadir PocketIC Rust al proyecto con el siguiente comando:

```bash
cargo add pocket-ic --dev
```

Importar PocketIC en el proyecto con el código:

```rust
use pocket_ic::PocketIc;
```

Luego, en el código, se puede crear una nueva instancia de PocketIC con:

```rust
let pic = PocketIc::new();
```

### Pruebas de un solo canister en una sola subnet

[Ver un ejemplo de prueba de un canister en una sola subnet](https://crates.io/crates/pocket-ic).

### Pruebas multi-subnet

Las versiones de PocketIC `v2.0.0` y posteriores admiten pruebas multi-subnet.  
Las pruebas multi-subnet permiten simular múltiples tipos de subnets
localmente.  
Por ejemplo, para crear una instancia de IC con una subnet NNS y dos subnets de
aplicación, se usa el siguiente código:

```rust
let pic = PocketIcBuilder::new()
    .with_nns_subnet()
    .with_application_subnet()
    .with_application_subnet()
    .build();
```

Luego, para apuntar a la subnet NNS y crear un canister:

```rust
let nns_sub = pic.topology().get_nns_subnet().unwrap();
let nns_can_id = pic.create_canister_on_subnet(..., nns_sub);
```

Para probar una de las subnets de aplicación e instalar un canister:

```rust
let app_sub_2 = pic.topology().get_app_subnets()[1];
let app_can_id = pic.create_canister_on_subnet(..., app_sub_2);
pic.install_canister(app_can_id, ...);
```

Para crear un canister con un `canister_id` específico en una subnet
determinada,  
por ejemplo, en la subnet NNS:

```rust
let ledger_canister_id = Principal::from_text("ryjl3-tyaaa-aaaaa-aaaba-cai").unwrap();
pic.create_canister_with_id(..., ledger_canister_id).unwrap();
pic.install_canister(ledger_canister_id, ...);
```

Los tipos posibles de subnets incluyen:

- Subnets genéricas del sistema.

- Subnets genéricas de aplicación.

- Subnets con nombres específicos y rangos de ID de canister similares a la
  mainnet,  
  como las subnets NNS, SNS, II, Bitcoin y Fiduciaria.

Ver un ejemplo más grande y complejo que utiliza  
[llamadas entre canisters en dos subnets diferentes](https://github.com/dfinity/ic/blob/HEAD/packages/pocket-ic/tests/tests.rs#L57).

## PocketIC Python

Para usar PocketIC, se debe descargar el binario más reciente del servidor
PocketIC  
desde el repositorio de PocketIC.  
[Descargar la última versión para sistemas macOS o Linux](https://github.com/dfinity/pocketic#download-the-pocketic-server).

El binario de PocketIC se puede dejar en el directorio de trabajo  
o se puede especificar su ruta estableciendo la variable de entorno
`POCKET_IC_BIN`.

Luego, ejecutar el siguiente comando para instalar PocketIC:

```bash
pip3 install pocket-ic
```

Para importar PocketIC en código Python, usar:

```python
from pocket_ic import PocketIC
```

### Crear un canister con <GlossaryTooltip>cycles</GlossaryTooltip> y llamarlo

[Ver un ejemplo de cómo crear un canister con cycles y luego llamarlo](https://pypi.org/project/pocket-ic/).

### Hacer una llamada directamente con un objeto canister

```python
my_canister = pic.create_and_install_canister_with_candid(...)
```

### Llamar métodos del canister usando sintaxis nativa de Python

```python
response = my_canister.greeting()
assert(response == 'Hello, PocketIC!')
```

### Pruebas de un solo canister en una sola subnet

[Ver un ejemplo completo de prueba de un canister en una sola subnet](https://github.com/dfinity/pocketic-py/blob/main/examples/counter_canister/counter_canister_test.py).

Para ver más ejemplos y ejecutarlos localmente, clonar el  
[repositorio de PocketIC Python](https://github.com/dfinity/pocketic-py),  
luego ejecutar el siguiente comando, reemplazando el nombre del ejemplo con el
que se desea ejecutar.  
Por ejemplo, para ejecutar el ejemplo `counter_canister`:

```bash
python3 examples/counter_canister/counter_canister_test.py
```
