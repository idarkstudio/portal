# Benchmarking de Canisters

<MarkdownChipRow labels={["Intermedio"]} />

Los canisters desplegados en ICP utilizan recursos como memoria y cómputo. Estos
recursos son finitos y existen límites configurados que restringen cuánto puede
consumir un canister. El crate de Rust `canbench` permite evaluar el uso de
recursos de un canister para que los desarrolladores puedan obtener información
sobre su consumo de memoria, instrucciones y otros recursos.

`canbench` proporciona información como:

- Análisis del consumo de memoria estable, memoria en heap e instrucciones.
- Detección de posibles regresiones de rendimiento, tanto localmente como en la
  mainnet.
- Identificación de cuellos de botella en el rendimiento.

Las características de `canbench` incluyen:

- Soporte para pruebas de rendimiento que ejecutan hasta 10 billones de
  instrucciones.
- Reporte del número de instrucciones consumidas, junto con cambios en la
  memoria estable y en heap.
- Persistencia de los resultados de benchmarking en el repositorio del canister.
- Independencia del lenguaje, aunque inicialmente solo hay soporte para Rust.

## Instalación

Puedes instalar `canbench` utilizando [cargo](https://crates.io/).

```bash
cargo install canbench
```

Agrega una dependencia opcional para `canbench` en tu archivo `Cargo.toml`:

```title="Cargo.toml"
canbench_rs = { version = "0.1.1", optional = true }
```

Luego, edita el archivo `canbench.yml` para apuntar al archivo Wasm de tu
canister:

```yml title="canbench.yml"
build_cmd:
  cargo build --release --target wasm32-unknown-unknown --features canbench-rs

wasm_path: ./target/wasm32-unknown-unknown/release/<YOUR_CANISTER>.wasm
```

## Ejemplo de prueba de benchmarking

A continuación, se muestra un canister con una función `query` que calcula y
devuelve la secuencia de Fibonacci de un número dado:

```rust title="src/example_backend/src/lib.rs"
#[ic_cdk::query]
fn fibonacci(n: u32) -> u32 {
    if n == 0 {
        return 0;
    } else if n == 1 {
        return 1;
    }

    let mut a = 0;
    let mut b = 1;
    let mut result = 0;

    for _ in 2..=n {
        result = a + b;
        a = b;
        b = result;
    }

    result
}
```

A continuación, un ejemplo de prueba de benchmarking utilizando `canbench` para
este canister:

```rust
#[cfg(feature = "canbench-rs")]
mod benches {
    use super::*;
    use canbench_rs::bench;

    #[bench]
    fn fibonacci_20() {
        // NOTA: el resultado se imprime para evitar que el compilador optimice la llamada.
        println!("{:?}", fibonacci(20));
    }
}
```

La salida del benchmark se vería así:

```
canbench

---------------------------------------------------

Benchmark: fibonacci_20 (new)
  total:
    instructions: 2301 (new)
    heap_increase: 0 pages (new)
    stable_memory_increase: 0 pages (new)

---------------------------------------------------

Executed 1 of 1 benchmarks.
```

Para más ejemplos e información, consulta la
[documentación del crate](https://docs.rs/canbench-rs) o el
[repositorio de GitHub](https://github.com/dfinity/canbench/tree/main).
