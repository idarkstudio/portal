# Especificando la versión del replica en dfx

<MarkdownChipRow labels={["Avanzado", "dfx workflow"]} />

La versión del replica incluida en la versión más reciente de `dfx` puede no
reflejar la versión más actual del replica. En algunos flujos de trabajo, como
probar nuevas características del replica, puede ser deseable tener la versión
más reciente del replica.

## Usar una versión específica del replica

Para usar una versión específica del replica, hay dos opciones:

1. Establecer la variable de entorno local `DFX_REPLICA_PATH` para reflejar
   `DFX_REPLICA_PATH=<ruta al nuevo replica>`. Si se usa esta opción, también es
   necesario que `canister_sandbox` y `sandbox_launcher` estén en el mismo
   directorio con la versión deseada del replica.

2. Usar los comandos
   `dfx cache install && cp <ruta al nuevo replica> "$(dfx cache show)/replica"`
   para copiar la versión del replica en la caché de `dfx`.
