# Verificación del almacenamiento de fragmentos de un canister

<MarkdownChipRow labels={["Avanzado", "Flujo de trabajo dfx"]} />

El almacenamiento de fragmentos de un canister debe estar vacío antes de que se
pueda instalar un módulo Wasm en el canister.

## Verificación del almacenamiento de fragmentos

Puedes verificar si el almacenamiento de fragmentos de un canister está vacío
utilizando el siguiente comando:

```bash
dfx canister call --ic aaaaa-aa stored_chunks '(record { canister_id = principal "PRINCIPAL_ID" })'
```

Reemplaza `PRINCIPAL_ID` con un ID de canister como
`bkyz2-fmaaa-aaaaa-qaaaq-cai`.

Si el resultado devuelve un valor `vec`, significa que el almacenamiento de
fragmentos no está vacío.

```
(
  vec {
    record {
      1_158_164_430 = blob "\96\a2\96\d2\24\f2\85\c6\7b\ee\93\c3\0f\8a\30\91\57\f0\da\a3\5d\c5\b8\7e\41\0b\78\63\0a\09\cf\c7";
    };
  },
)
```

## Resolviendo errores de instalación relacionados con el almacenamiento de fragmentos

Si intentas instalar un módulo Wasm en un canister que tiene un almacenamiento
de fragmentos existente, la instalación fallará con un error como:

```
Failed during wasm installation call: Candid returned an error: input: 4449444c036d016c01cedfa0a804026d7b010003_204b7cb7e28621a6f1110913a33e11455d407f584d3cfe91edf6c12c75b6bd00a2204f7deaf907cea359eda7caa340b204e1558cf451da3fe7582a4cb010a57290d020f52735197797ef2a9e1d2b5d7ed8c13bcd1f41fc65a4731742c12b87f2346bc3
table: type table0 = vec table1
type table1 = record { 1_158_164_430 : table2 }
type table2 = vec nat8
wire_type: record { 1_158_164_430 : table2 }, expect_type: vec nat8
```

Para verificar que el almacenamiento de fragmentos es la causa de este error,
verifica que el almacenamiento de fragmentos tenga un valor `vec` existente
ejecutando el
[comando mostrado arriba](#verificación-del-almacenamiento-de-fragmentos-de-un-canister).

Luego, limpia el almacenamiento de fragmentos con el comando:

```
dfx canister call --ic aaaaa-aa clear_chunk_store '(record { canister_id = principal "bkyz2-fmaaa-aaaaa-qaaaq-cai" })'
```

Luego, vuelve a ejecutar el comando de instalación del canister.
