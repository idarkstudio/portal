# dfxvm self uninstall

<MarkdownChipRow labels={["Referencia"]} />

Desinstala dfxvm y todas las versiones de dfx.

## Uso

```bash
dfxvm self uninstall [--yes]
```

### Opciones

| Opción  | Descripción         |
| ------- | ------------------- |
| `--yes` | Omitir confirmación |

## Ejemplos

Desinstala dfxvm y todas las versiones de dfx, con la posibilidad de confirmar o
cancelar.

```bash
dfxvm self uninstall
```
