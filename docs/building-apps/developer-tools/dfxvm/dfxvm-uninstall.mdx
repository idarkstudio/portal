# dfxvm uninstall

<MarkdownChipRow labels={["Referencia"]} />

Desinstala una version de dfx.

## Uso

```bash
dfxvm uninstall <version>
```

## Ejemplos

Desinstala una beta que ya no deseas.

```bash
dfxvm uninstall 0.15.1-beta.0
```
