# dfxvm default

Establece o muestra la versión predeterminada de `dfx` que se usará.

Si se establece una versión predeterminada y esta no está instalada, el comando
la instalará automáticamente.

## Uso

Para establecer la versión de `dfx` que se usará por defecto:

```bash
dfxvm default <version>
```

Para mostrar la versión predeterminada de `dfx`:

```bash
dfxvm default
```

## Ejemplos

Para establecer la versión predeterminada de `dfx` en `0.7.2`:

```bash
$ dfxvm default 0.7.2
...
info: installed dfx 0.7.2
info: set default version to dfx 0.7.2
```

Para mostrar la versión predeterminada actual de `dfx`:

```bash
$ dfxvm default
0.15.1
```
