# dfx cache

<MarkdownChipRow labels={["Referencia"]} />

Utiliza el comando `dfx cache` con banderas y subcomandos para gestionar la
caché de versiones de `dfx`.

La sintaxis básica para ejecutar comandos `dfx cache` es:

```bash
dfx cache [subcommand] [flag]
```

Dependiendo del subcomando `dfx cache` que especifiques, pueden aplicarse
argumentos, opciones y banderas adicionales. Para obtener información de
referencia y ejemplos que ilustren el uso de los comandos `dfx cache`,
selecciona un comando apropiado.

| Comando                    | Descripción                                                                             |
| -------------------------- | --------------------------------------------------------------------------------------- |
| [`delete`](#delete)        | Elimina la versión especificada de `dfx` de la caché local.                             |
| `help`                     | Muestra un mensaje con información de uso para un subcomando especificado.              |
| [`install`](#install)      | Instala la versión especificada de `dfx` desde la caché local.                          |
| [`list`](#_dfx_cache_list) | Lista las versiones de `dfx` actualmente instaladas y utilizadas en proyectos actuales. |
| [`show`](#_dfx_cache_show) | Muestra la ruta de la caché utilizada por esta versión del ejecutable `dfx`.            |

Para ver información de uso de un subcomando específico, especifica el
subcomando y la bandera `--help`. Por ejemplo, para ver información de uso de
`dfx cache delete`, puedes ejecutar el siguiente comando:

```bash
dfx cache delete --help
```

## dfx cache delete

Utiliza el comando `dfx cache delete` para eliminar una versión especificada del
IC SDK de la caché de versiones en el equipo local.

### Uso básico

```bash
dfx cache delete [version] [flag]
```

### Argumentos

Puedes especificar el siguiente argumento para el comando `dfx cache delete`.

| Comando   | Descripción                                                           |
| --------- | --------------------------------------------------------------------- |
| `version` | Especifica la versión de `dfx` que deseas eliminar de la caché local. |

### Ejemplos

Puedes utilizar el comando `dfx cache delete` para eliminar de forma permanente
versiones del IC SDK que ya no deseas utilizar. Por ejemplo, puedes ejecutar el
siguiente comando para eliminar la versión `0.6.2` del IC SDK:

```bash
dfx cache delete 0.6.2
```

## dfx cache install

Utiliza el comando `dfx cache install` para instalar el IC SDK utilizando la
versión actualmente encontrada en la caché de `dfx`.

### Uso básico

```bash
dfx cache install [flag]
```

### Ejemplos

Puedes utilizar el comando `dfx cache install` para forzar la instalación de
`dfx` desde la versión en la caché. Por ejemplo, puedes ejecutar el siguiente
comando para instalar `dfx`:

```bash
dfx cache install
```

## dfx cache list

Utiliza el comando `dfx cache list` para listar las versiones del IC SDK que
tienes actualmente instaladas y utilizadas en proyectos.

Si tienes múltiples versiones del IC SDK instaladas, la lista de caché muestra
un asterisco (\*) para indicar la versión actualmente activa.

### Uso básico

```bash
dfx cache list [flag]
```

### Ejemplos

Puedes utilizar el comando `dfx cache list` para listar las versiones del IC SDK
que tienes actualmente instaladas y utilizadas en proyectos. Por ejemplo, puedes
ejecutar el siguiente comando para listar las versiones del IC SDK encontradas
en la caché:

```bash
dfx cache list
```

Este comano muestra la lista de versiones del IC SDK encontradas similar a la
siguiente:

```bash
0.6.4 *
0.6.3
0.6.0
```

## dfx cache show

Utiliza el comando `dfx cache show` para mostrar la ruta completa de la caché
utilizada por la versión del IC SDK que estás utilizando actualmente.

### Uso básico

```bash
dfx cache show [flag]
```

### Ejemplos

Puedes utilizar el comando `dfx cache show` para mostrar la ruta completa de la
caché utilizada por la versión del IC SDK que estás utilizando actualmente:

```bash
dfx cache show
```

Este comando muestra la ruta de la caché utilizada por la versión del IC SDK que
estás utilizando actualmente:

```bash
/Users/pubs/.cache/dfinity/versions/0.6.4
```
