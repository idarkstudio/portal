# dfx deps

<MarkdownChipRow labels={["Referencia"]} />

Use el comando `dfx deps` con banderas y subcomandos para obtener dependencias
de la red principal y desplegar localmente.

[Aprende cómo configurar un canister como `pullable`](/docs/building-apps/interact-with-canisters/using-third-party-canisterss/using-third-party-canisters).

La sintaxis básica para ejecutar comandos `dfx deps` es:

```bash
dfx deps [subcommand] [options]
```

Dependiendo del subcomando `dfx deps` que especifiques, pueden aplicarse
argumentos, opciones y banderas adicionales. Para obtener información de
referencia y ejemplos que ilustren el uso de los comandos `dfx deps`, selecciona
el comando adecuado.

| Comando                      | Descripción                                                                   |
| ---------------------------- | ----------------------------------------------------------------------------- |
| [`pull`](#dfx-deps-pull)     | Descarga los canisters de los cuales depende el proyecto.                     |
| [`init`](#dfx-deps-init)     | Establece los argumentos de inicialización para las dependencias descargadas. |
| [`deploy`](#dfx-deps-deploy) | Despliega las dependencias descargadas.                                       |

Para ver la información de uso de un subcomando específico, especifica el
subcomando y la bandera `--help`. Por ejemplo, para ver la información de uso de
`dfx deps pull`, puedes ejecutar el siguiente comando:

```bash
dfx deps pull --help
```

## dfx deps pull

Use el comando `dfx deps pull` para obtener las dependencias definidas en
`dfx.json`.

### Uso básico

```bash
dfx deps pull [options]
```

### Argumentos

Puedes especificar el siguiente argumento para el comando `dfx deps delete`.

| Comando   | Descripción                                                                                |
| --------- | ------------------------------------------------------------------------------------------ |
| `network` | Especifica la red desde la cual obtener las dependencias, el valor predeterminado es "ic". |

### Ejemplos

Puedes usar el comando `dfx deps pull` para obtener las dependencias definidas
en `dfx.json` desde la red principal. Resolverá todas las dependencias
indirectas.

```bash
dfx deps pull
```

Para pruebas, es posible que desees obtener las dependencias de la réplica
local,

```bash
dfx deps pull --network local
```

## dfx deps init

Use el comando `dfx deps init` para establecer argumentos de inicialización para
las dependencias descargadas.

### Uso básico

```bash
dfx deps init [options] [canister]
```

### Ejemplos

Puedes usar el comando `dfx deps init` para establecer argumentos de
inicialización vacíos para todas las dependencias descargadas.

```bash
dfx deps init
```

Si alguna de las dependencias requiere argumentos de inicialización, el comando
anterior te alertará con su ID y nombres de canister si existen. Luego puedes
especificar el ID o nombre del canister para establecer el argumento de
inicialización para cada dependencia individual.

```bash
`dfx deps init <CANISTER_ID/NAME> --argument <ARGUMENT> [--argument-type <TYPE>]`
```

El comando a continuación establece el número `1` para el canister `dep_a` ya
que el tipo de argumento es el predeterminado `idl` (candid).

```bash
dfx deps init dep_a --argument 1
```

El comando a continuación establece los bytes en bruto codificados en
hexadecimal para el canister `dep_b`.

```bash
dfx deps init dep_b --argument "4449444c00017103616263" --argument-type raw
```

El comando a continuación establece el argumento de inicialización para el
canister `dep_c` con el contenido del archivo `init_c.txt`.

```bash
dfx deps init dep_c --argument-file init_c.txt
```

## dfx deps deploy

Use el comando `dfx deps deploy` para desplegar todas las dependencias.

### Uso básico

```bash
dfx deps deploy [flag]
```

### Ejemplos

Puedes usar el comando `dfx deps deploy` para desplegar dependencias en la
réplica local.

```bash
dfx deps deploy
```

Si algunas de las dependencias no se han descargado o no se han establecido los
argumentos de inicialización, el comando fallará. El mensaje de error te ayudará
a solucionarlo.
