# dfx help

<MarkdownChipRow labels={["Referencia"]} />

Utiliza este comando para ver la información de uso del comando principal `dfx`
o de cualquier subcomando especificado.

## Uso básico

```bash
dfx help [subcommand]
```

## Argumentos

Puedes especificar cualquier subcomando de `dfx` como argumento para ver la
información de uso de ese subcomando utilizando el comando `dfx help`.

| Argumento    | Descripción                                                         |
| ------------ | ------------------------------------------------------------------- |
| `subcommand` | Especifica la información de uso del subcomando que deseas mostrar. |

## Ejemplos

Para mostrar la información de uso de `dfx`, ejecuta el siguiente comando: :

```bash
dfx help
```

Para mostrar la información de uso de `dfx new`, ejecuta el siguiente comando:

```bash
dfx help new
```
