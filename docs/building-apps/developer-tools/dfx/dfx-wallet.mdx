# dfx wallet

<MarkdownChipRow labels={["Referencia"]} />

Usa el comando `dfx wallet` con subcomandos y flags para gestionar las
billeteras de cycles de tus identidades y enviar cycles a las billeteras de
otros canisters de cuenta de cycles.

La sintaxis básica para ejecutar los comandos `dfx wallet` es:

```bash
dfx wallet [option] <subcommand> [flag]
```

Dependiendo del subcomando de `dfx wallet` que especifiques, pueden aplicarse o
requerirse argumentos, opciones y flags adicionales. Para ver la información de
uso de un subcomando específico de `dfx wallet`, especifica el subcomando y el
flag `--help`. Por ejemplo, para ver la información de uso de `dfx wallet send`,
puedes ejecutar el siguiente comando:

```bash
dfx wallet send --help
```

Para obtener información de referencia y ejemplos que ilustren el uso de los
comandos `dfx wallet`, selecciona un comando adecuado.

| Comando                                              | Descripción                                                                                                     |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| [`add-controller`](#dfx-wallet-add-controller)       | Agrega un controlador utilizando el principal de la identidad seleccionada.                                     |
| [`addresses`](#dfx-wallet-addresses)                 | Muestra el libro de direcciones de la wallet de cycles.                                                         |
| [`authorize`](#dfx-wallet-authorize)                 | Autoriza a un custodio mediante su principal para la wallet de cycles de la identidad.                          |
| [`balance`](#dfx-wallet-balance)                     | Muestra el saldo de la wallet de cycles de la identidad seleccionada.                                           |
| [`controllers`](#dfx-wallet-controllers)             | Muestra una lista de los controladores de la wallet de cycles de la identidad seleccionada.                     |
| [`custodians`](#dfx-wallet-custodians)               | Muestra una lista de los custodios de la wallet de cycles de la identidad seleccionada.                         |
| [`deauthorize`](#dfx-wallet-deauthorize)             | Desautoriza a un custodio de la wallet de cycles utilizando su principal.                                       |
| `help`                                               | Muestra un mensaje de uso y la ayuda del subcomando dado.                                                       |
| [`name`](#dfx-wallet-name)                           | Devuelve el nombre de la wallet de cycles si se ha usado el comando `dfx wallet set-name`.                      |
| [`redeem-faucet-coupon`](#redeem-faucet-coupon)      | Canjea un código en el faucet de cycles.                                                                        |
| [`remove-controller`](#dfx-wallet-remove-controller) | Elimina un controlador especificado de la wallet de cycles de la identidad seleccionada.                        |
| [`send`](#dfx-wallet-send)                           | Envía una cantidad específica de cycles desde la wallet de cycles de la identidad seleccionada a otro canister. |
| [`set-name`](#dfx-wallet-set-name)                   | Especifica un nombre para tu wallet de cycles.                                                                  |
| [`upgrade`](#dfx-wallet-upgrade)                     | Actualiza el módulo Wasm de la wallet de cycles al Wasm actual incluido en DFX.                                 |

## Usando tu wallet

Después de haber usado el comando `dfx identity deploy-wallet` para crear un
canister de wallet de cycles vinculado a una identidad, puedes usar los comandos
`dfx wallet` para modificar la configuración de tu wallet de cycles, enviar
cycles a otras billeteras de cycles y agregar o eliminar controladores y
custodios.

## dfx wallet add-controller

Usa `dfx wallet add-controller` para agregar un controlador a la wallet. Una
identidad asignada como Controlador tiene los privilegios más altos y puede
realizar las siguientes acciones en la wallet de cycles de la identidad
seleccionada:

- Cambiar el nombre de la wallet de cycles.
- Agregar entradas al libro de direcciones.
- Agregar y eliminar controladores.
- Autorizar y desautorizar custodios.

Un controlador también es un custodio y puede realizar las siguientes acciones
asociadas con ese rol:

- Acceder a la información de la wallet.
- Enviar cycles.
- Reenviar llamadas.
- Crear canisters.

### Uso básico

```
dfx wallet add-controller [option] <controller> [flag]
```

### Opciones

Puedes usar las siguientes opciones con el comando `dfx canister call`.

| Opción                | Descripción                                                                                          |
| --------------------- | ---------------------------------------------------------------------------------------------------- |
| `--network <network>` | Especifica el entorno (por ejemplo, Internet Computer o testnet) del controlador que deseas agregar. |

### Argumentos

Puedes especificar los siguientes argumentos para el comando
`dfx wallet add-controller`.

| Argumento    | Descripción                                                    |
| ------------ | -------------------------------------------------------------- |
| `controller` | Especifica el principal del controlador a agregar a la wallet. |

### Ejemplos

Puedes usar el comando `dfx wallet add-controller` para agregar un controlador a
tu wallet. Si el controlador que deseas agregar está en un entorno diferente,
especifícalo usando la opción `--network`. Por ejemplo:

```
dfx wallet add-controller b5quc-npdph-l6qp4-kur4u-oxljq-7uddl-vfdo6-x2uo5-6y4a6-4pt6v-7qe
```

El comando muestra una salida similar a la siguiente:

```
Added b5quc-npdph-l6qp4-kur4u-oxljq-7uddl-vfdo6-x2uo5-6y4a6-4pt6v-7qe as a controller.
```

## dfx wallet addresses

Usa el comando `dfx wallet addresses` para mostrar el libro de direcciones de la
wallet. Las entradas de dirección contienen el principal y el `rol` (`Contact`,
`Custodian` o `Controller`), y pueden incluir un `nombre` y `tipo` (`Unknown`,
`User` o `Canister`) asociado con la dirección.

### Uso básico

```
dfx wallet addresses
```

### Ejemplos

Puedes usar el comando `dfx wallet addresses` para obtener información sobre las
direcciones en el libro de direcciones de tu wallet. Por ejemplo:

```
dfx wallet addresses --network ic
```

El comando muestra los controladores y custodios de la wallet de cycles con una
salida similar a la siguiente:

```
dfx wallet addresses
Id: hpff-grjfd-tg7cj-hfeuj-olrjd-vbego-lpcax-ou5ld-oh7kr-kl9kt-yae, Kind: Unknown, Role: Controller, Name: ic_admin.
Id: e7ptl-4x43t-zxcvh-n6s6c-k2dre-doy7l-bbo6h-ok8ik-msiz3-eoxhl-6qe, Kind: Unknown, Role: Custodian, Name: alice_auth.
```

## dfx wallet authorize

Usa el comando `dfx wallet authorize` para autorizar a un custodio en la wallet.
Una identidad autorizada como custodio puede realizar las siguientes acciones en
la wallet de cycles:

- Acceder a la información de la wallet.
- Enviar cycles.
- Reenviar llamadas.
- Crear canisters.

### Uso básico

```
dfx wallet authorize <custodian> [flag]
```

### Argumentos

Usa el siguiente argumento necesario con el comando `dfx wallet authorize`.

| Argumento     | Descripción                                                                           |
| ------------- | ------------------------------------------------------------------------------------- |
| `<custodian>` | Especifica el principal de la identidad que deseas agregar como custodio a la wallet. |

### Ejemplo

Por ejemplo, para agregar `alice_auth` como custodio, especifica su principal en
el siguiente comando:

```
dfx wallet authorize dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae
```

Este comando muestra una salida similar a la siguiente:

```
Authorized dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae as a custodian.
```

## dfx wallet balance

Usa el comando `dfx wallet balance` para mostrar el saldo de la wallet de cycles
de la identidad seleccionada.

### Uso básico

```
dfx wallet balance
```

### Flags

Puedes usar las siguientes flags opcionales con el comando `dfx wallet balance`.

| Flag        | Descripción                                                |
| ----------- | ---------------------------------------------------------- |
| `--precise` | Muestra el saldo exacto, sin escalar a billones de cycles. |

### Ejemplos

Verifica el saldo de la wallet de cycles de la identidad seleccionada.

```
dfx wallet balance
```

Este comando muestra la cantidad de cycles en tu wallet de cycles. Por ejemplo:

```
89.000 TC (trillion cycles).
```

## dfx wallet controllers

Usa el comando `dfx wallet controllers` para listar los principales de las
identidades que son controladores de la wallet de cycles de la identidad
seleccionada.

### Uso básico

```
dfx wallet controllers
```

### Ejemplos

Lista los controladores de la wallet de cycles de tu identidad seleccionada.

```
dfx wallet controllers
```

La información devuelta debería ser similar a la siguiente si hay dos
controladores:

```
dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae
hpnmi-qgxsv-tgecj-hmjyn-gmfft-vbego-lpcax-ou4ld-oh7kr-l3nu2-yae
```

## dfx wallet custodians

Usa el comando `dfx wallet custodians` para listar los principales de las
identidades que son custodios de la wallet de cycles de la identidad
seleccionada. Las identidades agregadas como controladores también se listan
como custodios.

### Uso básico

```
dfx wallet custodians
```

### Ejemplos

Lista los custodios de la wallet de cycles de tu identidad seleccionada.

```
dfx wallet custodians
```

La información devuelta debería ser similar a la siguiente si hay dos custodios:

```
dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae
hpnmi-qgxsv-tgecj-hmjyn-gmfft-vbego-lpcax-ou4ld-oh7kr-l3nu2-yae
```

## dfx wallet deauthorize

Usa el comando `dfx wallet deauthorize` para eliminar un custodio de la wallet
de cycles.

**NOTA:** Esto también eliminará el rol de controlador si el custodio también es
un controlador.

### Uso básico

```
dfx wallet deauthorize <custodian> [flag]
```

### Argumentos

Debes usar el siguiente argumento obligatorio con el comando
`dfx wallet deauthorize`.

| Argumento     | Descripción                                               |
| ------------- | --------------------------------------------------------- |
| `<custodian>` | Especifica el principal del custodio que deseas eliminar. |

### Ejemplo

Por ejemplo, para eliminar a "alice_auth" como custodio, especifica su principal
en el siguiente comando:

```
dfx wallet deauthorize dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae
```

Este comando mostrará una salida similar a:

```
Deauthorized dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae as a custodian.
```

## dfx wallet name

Usa el comando `dfx wallet name` para mostrar el nombre de la wallet de cycles
de la identidad seleccionada si se ha establecido mediante el comando
`dfx wallet set-name`.

### Uso básico

```
dfx wallet name [flag]
```

### Ejemplo

Si has nombrado tu wallet de cycles como "Terrances_wallet", el comando
devolvería lo siguiente:

```
Terrances_wallet
```

## dfx wallet redeem-faucet-coupon

Usa el comando `dfx wallet redeem-faucet-coupon` para canjear un cupón de la
fuente de cycles. Si no tienes una wallet configurada, esto creará una para ti.
Si ya tienes una wallet configurada, esto añadirá los cycles del cupón a tu
wallet existente.

### Uso básico

```
dfx wallet redeem-faucet-coupon <your faucet coupon>
```

### Argumentos

Debes usar el siguiente argumento obligatorio con el comando
`dfx wallet redeem-faucet-coupon`.

| Argumento              | Descripción                                           |
| ---------------------- | ----------------------------------------------------- |
| `<your faucet coupon>` | El código del cupón a canjear en la fuente de cycles. |

### Flags

Puedes usar las siguientes flags opcionales con el comando
`dfx wallet redeem-faucet-coupon`.

| Flag       | Descripción                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------- |
| `--faucet` | Dirección alternativa de la fuente de cycles. Si no se establece, usa la fuente de DFINITY. |
| `--yes`    | Omite las comprobaciones de sí/no respondiendo 'sí'. No recomendado fuera de CI.            |

### Ejemplo

Si aún no tienes una wallet y un código de cupón `ABCDE-ABCDE-ABCDE`, puedes
canjearlo así:

```bash
dfx wallet redeem-faucet-coupon 'ABCDE-ABCDE-ABCDE'
```

Esto imprimirá algo similar a:

```
Redeemed coupon ABCDE-ABCDE-ABCDE for a new wallet: rdmx6-jaaaa-aaaaa-aaadq-cai
New wallet set.
```

Si ya tienes una wallet y un código de cupón `ABCDE-ABCDE-ABCDE`, puedes
canjearlo así:

```bash
dfx wallet redeem-faucet-coupon 'ABCDE-ABCDE-ABCDE'
```

Esto imprimirá algo similar a:

```
Redeemed coupon code ABCDE-ABCDE-ABCDE for 20.000 TC (trillion cycles).
```

de la wallet de cycles de la identidad seleccionada.

### Uso básico

```
dfx wallet remove-controller <controller> [flag]

### Argumentos

Debes especificar el siguiente argumento para el comando
`dfx wallet remove-controller`.

| Argumento      | Descripción                                                  |
| -------------- | ------------------------------------------------------------ |
| `<controller>` | Especifica el principal del controlador que deseas eliminar. |

### Ejemplo

Por ejemplo, para eliminar a `alice_auth` como controlador, especifica su
principal en el siguiente comando:

```
dfx wallet remove-controller
dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae

El comando mostrará una salida similar a la siguiente:

```
Removed dheus-mqf6t-xafkj-d3tuo-gh4ng-7t2kn-7ikxy-vvwad-dfpgu-em25m-2ae as a
controller.
```

## dfx wallet send

Utiliza el comando `dfx wallet send` para enviar cycles desde la wallet de
cycles de la identidad seleccionada a un canister.

### Uso básico

```
dfx wallet [network] send [flag] <destination> <amount>
```

### Opciones

Puedes utilizar la siguiente opción con el comando `dfx wallet send`.

| Opción      | Descripción                                                                                                                                                                                                                                         |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--network` | Sobrescribe el entorno al que se conecta. Por defecto, se usa el entorno de ejecución local del canister. Se puede especificar una URL válida (que comience con `http:` o `https:`). Ejemplo: "http://localhost:12345/" es un nombre de red válido. |

### Argumentos

Debes especificar los siguientes argumentos para el comando `dfx wallet send`.

| Argumento       | Descripción                                |
| --------------- | ------------------------------------------ |
| `<destination>` | Especifica el ID del canister de destino.  |
| `<amount>`      | Especifica la cantidad de cycles a enviar. |

### Ejemplo

Envía cycles desde la wallet de cycles de la identidad seleccionada a otra
wallet de cycles.

Por ejemplo, para enviar 2,000,000,000 cycles desde la wallet de cycles de la
identidad seleccionada, `<ic_admin>`, a la wallet de cycles de la identidad de
destino, `<buffy_standard>`, con la dirección de wallet
`r7inp-6aaaa-aaaaa-aaabq-cai`, ejecuta el siguiente comando:

```
dfx wallet send r7inp-6aaaa-aaaaa-aaabq-cai 2000000000
```

Si la transferencia es exitosa, el comando no mostrará ninguna salida.

## dfx wallet set-name

Utiliza el comando `dfx wallet set-name` para asignar un nombre a la wallet de
cycles de la identidad seleccionada.

### Uso básico

```
dfx wallet set-name [flag] <name>
```

### Argumentos

Debes especificar el siguiente argumento para el comando `dfx wallet set-name`.

| Argumento | Descripción                                    |
| --------- | ---------------------------------------------- |
| `<name>`  | Especifica un nombre para la wallet de cycles. |

### Ejemplo

Si deseas establecer el nombre de la wallet de cycles de la identidad actual
como `"Terrances_wallet"`, puedes ejecutar el siguiente comando:

```
dfx wallet set-name Terrances_wallet
```

## dfx wallet upgrade

Utiliza el comando `dfx wallet upgrade` para actualizar el módulo Wasm de la
wallet de cycles a la versión actual incluida con DFX.

### Uso básico

```
dfx wallet upgrade [flag]
```

### Ejemplo

Para actualizar el módulo Wasm a la última versión, ejecuta el siguiente
comando:

```
dfx wallet upgrade
```
