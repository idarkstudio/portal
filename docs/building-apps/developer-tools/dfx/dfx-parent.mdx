# dfx

<MarkdownChipRow labels={["Referencia"]} />

El entorno de ejecución de línea de comandos de DFINITY (`dfx`) es la
herramienta principal para crear, implementar y administrar las dapps que
desarrollas para el IC.

Utiliza el comando principal `dfx` con banderas y subcomandos para especificar
las operaciones que deseas realizar con o sin argumentos opcionales.

## Uso básico

```bash
dfx [subcommand] [flag]
```

## Flags (banderas)

Puedes usar los siguientes flags opcionales con el comando principal `dfx` o con
cualquiera de sus subcomandos.

| Bandera           | Descripción                                   |
| ----------------- | --------------------------------------------- |
| `-h`, `--help`    | Muestra información de uso.                   |
| `-q`, `--quiet`   | Suprime mensajes informativos.                |
| `-v`, `--verbose` | Muestra información detallada de operaciones. |
| `-V`, `--version` | Muestra información de versión.               |

## Opciones

Puedes usar los siguientes opciones con el comando `dfx`.

| Opción                  | Descripción                                                                                                                                                                                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--identity <identity>` | Especifica la identidad de usuario a usar al ejecutar un comando.                                                                                                                                                                                                                                                  |
| `--logfile <logfile>`   | Escribe mensajes de registro en el archivo especificado si usas la opción `--log file`.                                                                                                                                                                                                                            |
| `--log <logmode>`       | Especifica el modo de registro. Puedes configurarlo como:<br />- `stderr` para registrar mensajes en la salida de error estándar.<br />- `tee` para escribir mensajes tanto en salida estándar como en un archivo.<br />- `file` para escribir mensajes solo en un archivo.<br />El modo predeterminado es stderr. |

## Ejemplos

Puedes usar el comando principal `dfx` para mostrar información sobre su uso o
la versión instalada.  
Por ejemplo, para mostrar la versión de `dfx` que tienes instalada actualmente,
puedes ejecutar el siguiente comando:

```bash
dfx --version
```

Para ver información de uso para un subcomando específico, especifique el
subcomando y el flag `--help`. Por ejemplo, para ver información de uso para
`dfx build`, puedes ejecutar el siguiente comando:

```bash
dfx build --help
```

### Uso de opciones de registro (logging)

Puedes usar las opciones `--verbose` y `--quiet` para incrementar o reducir el
nivel de registro.  
Si no especificas ningún nivel de registro, por defecto se registran mensajes de
nivel CRITICAL, ERROR, WARNING e INFO.

Si especificas una bandera `-v`, el nivel de registro se incrementa para incluir
mensajes DEBUG.  
Si especificas dos banderas `-vv`, el nivel de registro se incrementa aún más
para incluir mensajes DEBUG y TRACE.

Agregar la opción `--quiet` reduce el nivel de registro.  
Por ejemplo, para eliminar todos los mensajes, puedes ejecutar un comando
similar al siguiente:

```bash
dfx build -qqqq
```

Ten en cuenta que usar el nivel de registro TRACE (`--vv`) genera una gran
cantidad de mensajes de registro, lo que puede afectar el rendimiento.  
Se recomienda utilizarlo solo cuando sea necesario para la solución de problemas
o análisis.

Para guardar los mensajes de registro en un archivo llamado `newlog.txt` y
mostrarlos en la terminal al crear un nuevo proyecto, puedes ejecutar un comando
similar al siguiente:

```bash
dfx new hello_world --log tee --logfile newlog.txt
```

### Especificar una identidad de usuario

Si creas identidades de usuario con el comando `dfx identity new`, puedes usar
la opción de línea de comandos `--identity` para cambiar el contexto del usuario
al ejecutar otros comandos de `dfx`.

El caso de uso más común es utilizar la opción `--identity` para llamar
funciones específicas de un canister y probar los controles de acceso para
ciertas operaciones.

Por ejemplo, podrías querer probar si la identidad de usuario `devops` puede
llamar a la función `modify_profile` en el canister `accounts` ejecutando el
siguiente comando:

    dfx canister call accounts modify_profile '("Kris Smith")' --identity devops
