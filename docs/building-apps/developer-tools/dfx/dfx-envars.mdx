# Environment variables

<MarkdownChipRow labels={["Referencia"]} />

Puedes configurar ciertas propiedades para tu entorno de ejecución del SDK
usando variables de entorno.

Esta sección lista las variables de entorno que son soportadas actualmente con
ejemplos de cómo usarlas. En la mayoría de los casos, puedes establecer
variables de entorno para una sesión ejecutando un comando en la terminal o
añadiendo una línea similar a la siguiente en tu archivo `.profile`:

```shell
export DFX_NETWORK=ic
```

## CANISTER_CANDID_PATH\_\{canister.name\}

Usa variables de entorno con el prefijo `CANISTER_CANDID_PATH` para hacer
referencia a la ruta del archivo de descripción Candid de los canisters que
están listados como dependencias en el archivo `dfx.json` de tu proyecto.

Por ejemplo, si tienes un canister `whoami_frontend` que lista `whoami` bajo la
clave `dependencies`, podrías usar la variable de entorno
`CANISTER_CANDID_PATH_whoami_frontend` para referenciar la ubicación del archivo
`whoami.did`, que para el desarrollo local podría ser:

    $PROJECT_ROOT/.dfx/local/canisters/whoami/whoami.did

## CANISTER_ID\_\{canister.name\}

Usa variables de entorno con el prefijo `CANISTER_ID` para hacer referencia al
identificador de canister de cada canister en el archivo `dfx.json` de tu
proyecto. Los guiones (`-`) no son válidos en variables de entorno y se
reemplazan por guiones bajos (`_`). Los caracteres en minúscula se convierten en
mayúscula.

Por ejemplo, si tienes un proyecto `linkedup` que consta de los canisters
`linkedup` y `connect-d`, podrías usar las variables de entorno
`CANISTER_ID_LINKEDUP` y `CANISTER_ID_CONNECT_D` para referenciar los
identificadores de canister—por ejemplo, `ryjl3-tyaaa-aaaaa-aaaba-cai` y
`rrkah-fqaaa-aaaaa-aaaaq-cai`—creados para tu proyecto.

## DFX_CONFIG_ROOT

Usa la variable de entorno `DFX_CONFIG_ROOT` para especificar una ubicación
diferente para almacenar los subdirectorios `.cache` y `.config` de `dfx`.

Por defecto, los directorios `.cache` y `.config` se encuentran en el directorio
home de tu entorno de desarrollo. Por ejemplo, en macOS la ubicación
predeterminada es el directorio `/Users/<YOUR-USER-NAME>`. Usa la variable de
entorno `DFX_CONFIG_ROOT` para especificar una ubicación diferente para estos
directorios.

    DFX_CONFIG_ROOT=~/ic-root

## DFX_INSTALLATION_ROOT

Usa la variable de entorno `DFX_INSTALLATION_ROOT` para especificar una
ubicación diferente para el binario de `dfx` si no estás usando la ubicación
predeterminada para tu sistema operativo.

El script `.cache/dfinity/uninstall.sh` usa esta variable de entorno para
identificar el directorio raíz de la instalación de tu SDK.

## DFX_NETWORK

Usa la variable de entorno `DFX_NETWORK` para especificar la red que deseas usar
cuando ejecutas comandos `dfx`. Si pasas la opción `--network` a un comando
`dfx`, el valor de la variable de entorno `DFX_NETWORK` se ignorará.

## DFX_VERSION

Usa la variable de entorno `DFX_VERSION` para identificar una versión específica
del SDK que deseas instalar.

    DFX_VERSION=0.10.0 sh -ci "$(curl -fsSL https://internetcomputer.org/install.sh)"

## DFX_MOC_PATH

Usa la variable de entorno `DFX_MOC_PATH` para utilizar una versión diferente
del compilador Motoko en lugar de la versión incluida con una versión específica
de `dfx`.

## DFX_WARNING

Usa la variable de entorno `DFX_WARNING` para deshabilitar una o más
advertencias que `dfx` pueda mostrar. El valor es una lista separada por comas
de nombres de advertencias, cada uno con un prefijo `-` para deshabilitarlo.
Actualmente, se admiten los siguientes nombres de advertencias:

- `mainnet_plaintext_identity`: Deshabilita el mensaje de advertencia que se
  muestra cuando usas una identidad no segura en la red principal de Internet
  Computer.

```bash
export DFX_WARNING="-mainnet_plaintext_identity"
dfx deploy --network ic

# disable multiple warnings, though dfx 0.13.1 does not know about the mainnet_plaintext_identity warning and version_check no longer exists
export DFX_WARNING="-version_check,-mainnet_plaintext_identity"
DFX_VERSION=0.13.1 dfx deploy --network ic
```

## DFX_DISABLE_QUERY_VERIFICATION

Establece esta variable con un valor no vacío para deshabilitar la verificación
de consultas firmadas por la réplica.

## DFX_REPLICA_PATH

Usa la variable de entorno `DFX_REPLICA_PATH` para especificar una ruta de
archivo a una versión local de la réplica. Si se usa esta opción,
`canister_sandbox` y `sandbox_launcher` deben estar en el mismo directorio que
la versión deseada de la réplica.

## DFX_IC_STARTER_PATH

Usa la variable de entorno `DFX_IC_STARTER_PATH` para especificar una ruta de
archivo a una versión local de `ic-starter`.
