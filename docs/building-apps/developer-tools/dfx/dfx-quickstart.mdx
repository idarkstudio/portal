# dfx quickstart

<MarkdownChipRow labels={["Referencia"]} />

Utiliza el comando `dfx quickstart` para realizar la configuración inicial única
para tu identidad y/o billetera. Este comando se puede ejecutar en cualquier
momento para repetir el proceso de configuración o para utilizarlo como un
comando informativo, que muestra información sobre el saldo de tu ICP, la tasa
de conversión actual de ICP a XDR y más.

## Uso básico

```bash
dfx quickstart
```

## Flags

Puedes usar las siguientes flags opcionales con el comando `dfx quickstart`:

| Flag         | Descripción                                                                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `--identity` | La identidad de usuario con la que ejecutar este comando. Contiene tu principal y otros elementos que DFX asocia con él, como la billetera. |

## Opciones

Puedes especificar las siguientes opciones para el comando `dfx quickstart`:

| Opción                | Descripción                                                                                                                                               |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--log <LOGMODE>`     | El modo de registro a utilizar. Puedes registrar en `stderr`, en un archivo o en ambos. [Por defecto: stderr]. Valores posibles: `stderr`, `tee`, `file`. |
| `--logfile <LOGFILE>` | El archivo en el que registrar los logs, si se elige la opción de registrar en un archivo (ver `--log`).                                                  |

