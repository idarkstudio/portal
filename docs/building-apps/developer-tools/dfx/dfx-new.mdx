# dfx new

<MarkdownChipRow labels={["Referencia"]} />

Utiliza el comando `dfx new` para crear un nuevo proyecto para el IC. Este
comando crea una estructura de proyecto predeterminada con archivos de plantilla
que puedes modificar para adaptarlos a tu dapp. Debes especificar el nombre del
proyecto que deseas crear.

Puedes usar la opción `--dry-run` para obtener una vista previa de los
directorios y archivos que se crearán sin agregarlos al sistema de archivos.

Si se llama sin ningún argumento además del nombre del proyecto, te pedirá
interactivamente los valores de `--type`, `--frontend` y `--extras`.

## Uso básico

```bash
dfx new _project_name_ [flag]
```

## Banderas

Puedes usar las siguientes banderas opcionales con el comando `dfx new`:

| Bandera                 | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--dry-run`             | Genera una vista previa de los directorios y archivos que se crearán para un nuevo proyecto sin agregarlos al sistema de archivos.                                                                                                                                                                                                                                                                                                                                                                                                  |
| `--extras <EXTRAS>`     | Lista separada por comas de características adicionales para agregar a la plantilla del proyecto. `bitcoin` e `internet-identity` insertarán el código base correspondiente en `dfx.json`, y `frontend-tests` agrega un esqueleto de `vitest` al proyecto frontend.                                                                                                                                                                                                                                                                 |
| `--frontend <FRONTEND>` | Instala el código base del frontend para el canister del proyecto por defecto. El valor por defecto para esta bandera es `vanilla` si `node.js` está instalado en tu computadora local. Si `node.js` no está instalado, puedes configurar esta bandera para intentar instalar `node.js` y el archivo plantilla al crear el proyecto o puedes configurar la bandera como `none` para omitir la instalación del código base del frontend por completo. Posibles valores: `svelte`, `react`, `vue`, `vanilla`, `plain-assets`, `none`. |
| `--no-frontend`         | Omite la instalación del código base del frontend. Este es el comportamiento por defecto si `node.js` no está instalado en tu computadora. Equivalente a `--frontend none`.                                                                                                                                                                                                                                                                                                                                                         |
| `--type <TYPE>`         | Selecciona el código base del backend para el canister del proyecto por defecto. El valor por defecto para esta bandera es `motoko`. Valores posibles: `motoko`, `rust`, `azle`, `kybra`.                                                                                                                                                                                                                                                                                                                                           |

## Argumentos

Puedes especificar el siguiente argumento para el comando `dfx new`:

| Argumento      | Descripción                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `project_name` | Especifica el nombre del proyecto a crear. Este argumento es obligatorio.                                                |
| `--type`       | Elige el tipo de canister en el proyecto inicial. `motoko` y `rust` están disponibles. El valor por defecto es `motoko`. |

## Ejemplos

Puedes usar `dfx new` para crear un nuevo proyecto llamado `my_social_network`
ejecutando el siguiente comando:

```bash
dfx new my_social_network
```

El comando crea un nuevo proyecto, incluyendo una estructura de directorio de
proyecto predeterminada bajo el nuevo nombre de proyecto y un repositorio Git
para tu proyecto.

Si deseas obtener una vista previa de los directorios y archivos que se crearán
sin agregarlos al sistema de archivos, puedes ejecutar el siguiente comando:

```bash
dfx new my_social_network --dry-run
```
