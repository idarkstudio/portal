# dfx cycles

<MarkdownChipRow labels={["Referencia"]} />

Usa el comando `dfx cycles` para administrar los cycles asociados con el
principal de una identity.

La sintaxis básica para ejecutar comandos `dfx cycles` es:

```bash
dfx cycles [subcommand] [options]
```

Los siguientes subcomandos están disponibles:

| Comando                            | Descripción                                                               |
| ---------------------------------- | ------------------------------------------------------------------------- |
| [`approve`](#dfx-cycles-approve)   | Aprueba un principal para gastar cycles en tu nombre.                     |
| [`balance`](#dfx-cycles-balance)   | Muestra el saldo de la cuenta del usuario.                                |
| [`convert`](#dfx-cycles-convert)   | Convierte parte del saldo ICP del usuario en cycles.                      |
| [`top-up`](#dfx-cycles-top-up)     | Deposita cycles en un canister.                                           |
| [`transfer`](#dfx-cycles-transfer) | Envía cycles a otra cuenta.                                               |
| `help`                             | Muestra el mensaje de información de uso para un subcomando especificado. |

Para ver la información de uso de un subcomando específico, especifica el
subcomando y el flag `--help`. Por ejemplo, para ver la información de uso para
`dfx cycles balance`, puedes ejecutar el siguiente comando:

`dfx cycles balance --help`

## dfx cycles approve

Usa el comando `dfx cycles approve` para aprobar un principal para gastar cycles
en tu nombre.

### Uso básico

```bash
dfx cycles approve [options] <spender> <amount>
```

### Argumentos

Debes especificar los siguientes argumentos para el comando
`dfx cycles approve`:

| Argumento   | Descripción                             |
| ----------- | --------------------------------------- |
| `<spender>` | Permite a este principal gastar cycles. |
| `<amount>`  | El número de cycles que se aprueban.    |

### Opciones

Puedes especificar las siguientes opciones para el comando `dfx cycles approve`:

| Opción                              | Descripción                                                                                                                                                                                                                                                      |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--created-at-time <timestamp>`     | Especifica el timestamp-en-nanosegundos para el campo `created_at_time` en la solicitud de transferencia. Útil para controlar [deduplicación de transacciones.](https://internetcomputer.org/docs/developer-docs/integrations/icrc-1/#transaction-deduplication) |
| `--expected-allowance <cycles>`     | El número de cycles previamente aprobados. Consulta la [especificación de ICRC-2](https://github.com/dfinity/ICRC-1/blob/main/standards/ICRC-2/README.md) para más detalles.                                                                                     |
| `--expires-at <timestamp>`          | Timestamp-en-nanosegundos hasta el cual la aprobación es válida. Ninguno significa que la aprobación es válida indefinidamente.                                                                                                                                  |
| `--from-subaccount <subaccount>`    | Aprobar cycles para ser gastados desde esta subcuenta.                                                                                                                                                                                                           |
| `--memo <memo>`                     | Especifica un memo numérico para esta transacción.                                                                                                                                                                                                               |
| `--spender-subaccount <subaccount>` | Permite a esta subcuenta gastar cycles.                                                                                                                                                                                                                          |

### Ejemplos

Aprueba al principal
`raxcz-bidhr-evrzj-qyivt-nht5a-eltcc-24qfc-o6cvi-hfw7j-dcecz-kae` para gastar 1
mil millones de cycles:

```bash
dfx cycles approve raxcz-bidhr-evrzj-qyivt-nht5a-eltcc-24qfc-o6cvi-hfw7j-dcecz-kae 1000000000 --network ic
```

Aprueba desde una subaccount:

```bash
dfx cycles approve raxcz-bidhr-evrzj-qyivt-nht5a-eltcc-24qfc-o6cvi-hfw7j-dcecz-kae 1000000000 --from-subaccount 000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f --network ic
```

## dfx cycles balance

Usa el comando `dfx cycles balance` para imprimir el saldo de tu cuenta o la de
otro usuario.

### Uso básico

```bash
dfx cycles balance [flag] --network ic
```

### Opciones

Puedes especificar los siguientes argumentos para el comando
`dfx cycles balance`.

| Opción                      | Descripción                                                |
| --------------------------- | ---------------------------------------------------------- |
| `--owner <principal>`       | Muestra el saldo de este principal                         |
| `--subaccount <subaccount>` | Muestra el saldo de esta subcuenta                         |
| `--precise`                 | Muestra el saldo exacto, sin escalar a billones de cycles. |

### Ejemplos

Verifica el saldo de cycles de la identidad seleccionada.

```
$ dfx cycles balance --network ic
89.000 TC (trillion cycles).
```

Para ver la cantidad exacta de cycles, puedes usar la opción `--precise`:

```
$ dfx cycles balance --network ic --precise
89000000000000 cycles.
```

Puedes usar el comando `dfx cycles balance` para verificar el saldo de otro
principal:

```bash
dfx cycles balance --owner raxcz-bidhr-evrzj-qyivt-nht5a-eltcc-24qfc-o6cvi-hfw7j-dcecz-kae --network ic
```

## dfx cycles convert

Usa el comando `dfx cycles convert` para convertir ICP en cycles que se
almacenan en el ledger de cycles.

### Uso básico

```bash
dfx cycles convert [flag] --network ic
```

### Opciones

Puedes especificar los siguientes argumentos para el comando
`dfx cycles convert`:

| Opción                          | Descripción                                                                                                                                                                                                                                                               |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--amount <amount>`             | Especifica el número de tokens ICP para convertir a cycles y depositar en tu cuenta de cycles. Puedes especificar una cantidad como un número con hasta ocho (8) decimales.                                                                                               |
| `--created-at-time <timestamp>` | Especifica el timestamp-en-nanosegundos para el campo `created_at_time` en la solicitud de transferencia en el libro mayor. Útil para la deduplicación de transacciones. https://internetcomputer.org/docs/developer-docs/integrations/icrc-1/#transaction-deduplication- |
| `--e8s <e8s>`                   | Especifica las unidades fraccionarias del token ICP, llamadas e8s, como un número entero, donde un e8 es la fracción más pequeña de un token ICP. Por ejemplo, 1.05000000 es 1 ICP y 5000000 e8s. Puedes usar esta opción por sí sola o junto con la opción `--icp`.      |
| `--fee <fee>`                   | Especifica una tarifa de transacción. El valor predeterminado es 10000 e8s.                                                                                                                                                                                               |
| `--icp <icp>`                   | Especifica los tokens ICP como un número entero. Puedes usar esta opción por sí sola o junto con `--e8s`.                                                                                                                                                                 |
| `--deposit-memo <memo>`         | Memo utilizado al depositar los cycles generados.                                                                                                                                                                                                                         |
| `--to-subaccount <subaccount>`  | Subcuenta en la que se depositan los cycles.                                                                                                                                                                                                                              |

### Ejemplos

Convierte 10 ICP en cycles:

```
$ dfx cycles convert --network ic --amount 10
Account was topped up with 1_234_567_000_000_000 cycles! New balance is 1_234_567_000_000_000 cycles.
```

Para depositar los cycles en una subcuenta diferente, usa la opción
`--to-subaccount`.

```
$ dfx cycles convert --network ic --amount 10 --to-subaccount 000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f
Account was topped up with 1_234_567_000_000_000 cycles! New balance is 1_234_567_000_000_000 cycles.
```

## dfx cycles transfer

Usa el comando `dfx cycles transfer` para transferir cycles de tu cuenta a otra
cuenta.

### Uso básico

```bash
dfx cycles transfer [options] <to> <amount>
```

### Argumentos

Debes especificar los siguientes argumentos para el comando
`dfx cycles transfer`:

| Argumento  | Descripción                                                  |
| ---------- | ------------------------------------------------------------ |
| `<to>`     | El principal de la cuenta a la que deseas transferir ciclos. |
| `<amount>` | El número de ciclos a transferir.                            |

### Opciones

Puedes especificar las siguientes opciones para el comando
`dfx cycles transfer`:

| Opción                              | Descripción                                                                                                                                                                                                                                                       |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--from <principal>`                | Transfiere ciclos desde este principal. Requiere la aprobación de ese principal.                                                                                                                                                                                  |
| `--to-subaccount <subaccount>`      | La subcuenta a la que deseas transferir ciclos.                                                                                                                                                                                                                   |
| `--from-subaccount <subaccount>`    | La subcuenta desde la que deseas transferir ciclos.                                                                                                                                                                                                               |
| `--spender-subaccount <subaccount>` | Deduce la asignación de esta subcuenta. Requiere que se especifique `--from`.                                                                                                                                                                                     |
| `--memo <memo>`                     | Especifica un memo numérico para esta transacción.                                                                                                                                                                                                                |
| `--created-at-time <timestamp>`     | Especifica el timestamp-en-nanosegundos para el campo `created_at_time` en la solicitud de transferencia. Útil para controlar la deduplicación de transacciones. https://internetcomputer.org/docs/developer-docs/integrations/icrc-1/#transaction-deduplication- |

### Ejemplos

Transfiere 1 billón de ciclos a otra cuenta:

```bash
dfx cycles transfer raxcz-bidhr-evrzj-qyivt-nht5a-eltcc-24qfc-o6cvi-hfw7j-dcecz-kae 1000000000 --network ic
```

Transfiere desde una subaccount:

```bash
dfx cycles transfer raxcz-bidhr-evrzj-qyivt-nht5a-eltcc-24qfc-o6cvi-hfw7j-dcecz-kae 1000000000 --from-subaccount 000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f --network ic
```

## dfx cycles top-up

Usa el comando `dfx cycles top-up` para enviar ciclos a un canister.

### Uso básico

```bash
dfx cycles top-up [options] <to> <amount>
```

### Argumentos

Debes especificar los siguientes argumentos para el comando
`dfx cycles transfer`:

| Argumento  | Descripción                                                                 |
| ---------- | --------------------------------------------------------------------------- |
| `<to>`     | El nombre de un canister en el proyecto actual, o un principal de canister. |
| `<amount>` | El número de ciclos a transferir.                                           |

### Opciones

Puedes especificar las siguientes opciones para el comando `dfx cycles top-up`:

| Opción                           | Descripción                                                                                                                                                                                                                                                       |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--from-subaccount <subaccount>` | La subcuenta desde la que deseas transferir ciclos.                                                                                                                                                                                                               |
| `--created-at-time <timestamp>`  | Especifica el timestamp-en-nanosegundos para el campo `created_at_time` en la solicitud de transferencia. Útil para controlar la deduplicación de transacciones. https://internetcomputer.org/docs/developer-docs/integrations/icrc-1/#transaction-deduplication- |

### Ejemplos

Envía ciclos a un canister en tu proyecto:

```bash
dfx cycles top-up my_backend 1000000000 --network ic
```

Envía ciclos a un canister por principal:

```bash
dfx cycles top-up bkyz2-fmaaa-aaaaa-qaaaq-cai 1000000000 --network ic
```
