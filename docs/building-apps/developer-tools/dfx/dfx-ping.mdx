# dfx ping

<MarkdownChipRow labels={["Referencia"]} />

Utiliza el comando `dfx ping` para verificar la conectividad con el IC o un
testnet. Este comando te permite verificar que puedes conectarte al entorno
donde deseas implementar.

Para hacer ping a tu servidor local, ten en cuenta que solo puedes ejecutar este
comando desde la estructura de directorios del proyecto. Por ejemplo, si el
nombre de tu proyecto es `hello_world`, tu directorio de trabajo actual debe ser
el directorio principal del proyecto `hello_world` o uno de sus subdirectorios.

Para hacer ping a la mainnet, puedes ejecutar `dfx ping ic` desde cualquier
directorio.

## Uso básico

```bash
dfx ping [provider] [flag]
```

## Argumentos

Puedes especificar el siguiente argumento para el comando `dfx ping`.

| Argumento | Descripción                                             |
| --------- | ------------------------------------------------------- |
| provider  | Especifica la URL del IC o testnet que deseas utilizar. |

## Ejemplos

Puedes utilizar el comando `dfx ping` para verificar si el IC está disponible
actualmente en una dirección de red específica ejecutando un comando similar al
siguiente:

```bash
dfx ping https://icp-api.io
```

Si el IC se está ejecutando en la dirección del proveedor de red especificada,
el comando devuelve una salida similar a la siguiente:

```json
{
  "ic_api_version": "0.8"
}
```
