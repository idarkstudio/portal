# dfx identity

<MarkdownChipRow labels={["Referencia"]} />

Utiliza el comando `dfx identity` con subcomandos y flags para gestionar las
identidades utilizadas para ejecutar comandos y comunicarte con el IC o el
entorno de ejecución de canisters local. Crear múltiples identidades de usuario
te permite probar controles de acceso basados en el usuario.

La sintaxis básica para ejecutar comandos `dfx identity` es:

```bash
dfx identity [subcommand] [flag]
```

Dependiendo del subcomando `dfx identity` que especifiques, pueden aplicarse o
ser requeridos argumentos, opciones y flags adicionales. Para ver información de
uso para un subcomando específico de `dfx identity`, especifica el subcomando y
la bandera `--help`. Por ejemplo, para ver la información de uso para
`dfx identity new`, puedes ejecutar el siguiente comando:

```bash
dfx identity new --help
```

Para información de referencia y ejemplos que ilustren el uso de los comandos
`dfx identity`, selecciona el comando apropiado.

| Comando                                        | Descripción                                                                                                                           |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| [`deploy-wallet`](#dfx-identity-deploy-wallet) | Instala el Wasm del wallet en el canister proporcionado.                                                                              |
| [`get-principal`](#dfx-identity-get-principal) | Muestra la representación textual del principal asociado con la identidad actual.                                                     |
| [`get-wallet`](#dfx-identity-get-wallet)       | Muestra el identificador del canister para el wallet asociado con el principal de tu identidad actual.                                |
| `help`                                         | Muestra este mensaje de uso o la ayuda de los subcomandos dados.                                                                      |
| [`export`](#dfx-identity-export)               | Exporta la definición PEM de una identidad.                                                                                           |
| [`import`](#dfx-identity-import)               | Crea una nueva identidad importando un archivo PEM que contiene la información de clave o certificado de seguridad para un principal. |
| [`list`](#dfx-identity-list)                   | Lista las identidades existentes.                                                                                                     |
| [`new`](#dfx-identity-new)                     | Crea una nueva identidad.                                                                                                             |
| [`remove`](#dfx-identity-remove)               | Elimina una identidad existente.                                                                                                      |
| [`rename`](#dfx-identity-rename)               | Cambia el nombre de una identidad existente.                                                                                          |
| [`set-wallet`](#dfx-identity-set-wallet)       | Establece el identificador del canister wallet para usar con el principal de tu identidad actual.                                     |
| [`use`](#dfx-identity-use)                     | Especifica la identidad a utilizar.                                                                                                   |
| [`whoami`](#dfx-identity-whoami)               | Muestra el nombre del contexto de usuario actual de la identidad.                                                                     |

## Crear una identidad por defecto

La primera vez que ejecutas el comando `dfx canister create` para registrar un
identificador, se utilizan tus credenciales de clave pública/privada para crear
una identidad de usuario `default`. Las credenciales de la identidad `default`
se migran de `$HOME/.dfinity/identity/creds.pem` a
`$HOME/.config/dfx/identity/default/identity.pem`.

Luego puedes usar `dfx identity new` para crear nuevas identidades de usuario y
guardar las credenciales de esas identidades en archivos
`$HOME/.config/dfx/identity/<identity_name>/identity.pem`. Por ejemplo, puedes
crear una identidad llamada `ic_admin` ejecutando el siguiente comando:

    dfx identity new ic_admin

Este comando agrega una clave privada para la identidad de usuario `ic_admin` en
el archivo `~/.config/dfx/identity/ic_admin/identity.pem`.

## dfx identity deploy-wallet

Usa el comando `dfx identity deploy-wallet` para convertir un canister en un
wallet canister instalando el Wasm del wallet en él.

Ten en cuenta que debes estar conectado al IC o al entorno de ejecución local de
canisters para ejecutar este comando. Además, debes ser un controlador del
canister al que deseas desplegar el wallet.

### Uso básico

```bash
dfx identity deploy-wallet [flag] <canister id>
```

### Argumentos

Debes especificar el siguiente argumento para el comando
`dfx identity deploy-wallet`:

| Argumento       | Descripción                                                |
| --------------- | ---------------------------------------------------------- |
| `<canister id>` | El ID del canister donde se desplegará el Wasm del wallet. |

## dfx identity get-principal

Usa el comando `dfx identity get-principal` para mostrar la representación
textual de un principal asociado con el contexto de la identidad de usuario
actual.

Si no has creado ninguna identidad de usuario, puedes usar este comando para
mostrar el principal de la identidad `default`. La representación textual de un
principal puede ser útil para establecer y probar escenarios de autorización
basados en roles.

### Uso básico

```bash
dfx identity get-principal [flag]
```

### Ejemplo

Si deseas mostrar la representación textual de un principal asociado con un
contexto de identidad de usuario específico, puedes ejecutar comandos similares
a los siguientes:

```bash
dfx identity use ic_admin
dfx identity get-principal
```

En este ejemplo, el primer comando establece el contexto de usuario para usar la
identidad `ic_admin`. El segundo comando devuelve el principal asociado con la
identidad `ic_admin`.

## dfx identity get-wallet

Usa el comando `dfx identity get-wallet` para mostrar el identificador del
canister para el wallet asociado con tu principal de identidad actual.

Ten en cuenta que debes estar conectado al IC o al entorno de ejecución local de
canisters para ejecutar este comando. Además, debes estar en un directorio de
proyecto para ejecutar el comando. Por ejemplo, si el nombre de tu proyecto es
`hello_world`, tu directorio de trabajo actual debe ser el directorio principal
de proyecto `hello_world` o uno de sus subdirectorios para ejecutar el comando
`dfx identity get-wallet`.

### Uso básico

```bash
dfx identity get-wallet [flag]
```

### Ejemplo

Si deseas mostrar el identificador del canister para el wallet asociado con tu
identidad, puedes ejecutar el siguiente comando:

```bash
dfx identity get-wallet
```

Para mostrar el identificador del canister para el wallet asociado con tu
identidad en una testnet específica, puedes ejecutar un comando similar al
siguiente:

```bash
dfx identity get-wallet --network=https://192.168.74.4
```

## dfx identity export

Usa el comando `dfx identity export` para exportar la definición PEM de una
identidad existente. Puedes importar esta definición en otro lugar usando
[`dfx identity import`](#dfx-identity-import).

### Uso básico

```bash
dfx identity export identity-name
```

### Ejemplos

El siguiente comando exportará un archivo PEM para una identidad existente. Si
trasladas este archivo a otra computadora, el siguiente ejemplo de
`dfx identity import` lo importaría.

```bash
dfx identity export alice >generated-id.pem
```

## dfx identity import

Usa el comando `dfx identity import` para crear una identidad de usuario
importando la información de clave o certificado de seguridad desde un archivo
PEM o un archivo de frase semilla.

_Política de contraseñas_: Si una identidad es importada usando
`--storage-mode password-protected`, se aplican los siguientes requisitos a la
contraseña:

- La contraseña debe tener más de 8 caracteres.

### Uso básico

```bash
dfx identity import [options] identity-name pem_file-name
```

### Opciones

Puedes especificar las siguientes opciones para el comando
`dfx identity import`:

| Opción           | Descripción                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--storage-mode` | Por defecto, los archivos PEM se almacenan en el keyring proporcionado por el SO. Si no está disponible, se cifran con una contraseña al escribirlos en disco. Los archivos PEM en texto plano siguen estando disponibles (por ejemplo, para usarlos en situaciones no interactivas como CI), pero no se recomienda su uso ya que ponen en riesgo las claves. Para forzar el uso de un modo específico de almacenamiento, usa la bandera `--storage-mode` con `--storage-mode password-protected` o `--storage-mode plaintext`. |
| `--force`        | Si la identidad ya existe, elimina y vuelve a importarla.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

### Ejemplos

Puedes usar el comando `dfx identity import` para importar un archivo PEM que
contiene el certificado de seguridad para usarlo en una identidad. Por ejemplo,
puedes ejecutar el siguiente comando para importar el archivo `generated-id.pem`
para crear la identidad de usuario `alice`:

```bash
dfx identity import alice generated-id.pem
```

El comando agrega el archivo `generated-id.pem` al directorio
`~/.config/dfx/identity/alice`.

## dfx identity list

Usa el comando `dfx identity list` para mostrar la lista de identidades de
usuario disponibles. Cuando ejecutes este comando, la lista mostrará un
asterisco (\*) para indicar el contexto de usuario activo actualmente. Debes
tener en cuenta que las identidades son globales. No están confinadas a un
contexto de proyecto específico. Por lo tanto, puedes usar cualquier identidad
listada por el comando `dfx identity list` en cualquier proyecto.

### Uso básico

```bash
dfx identity list [flag]
```

### Ejemplos

Puedes usar el comando `dfx identity list` para listar todas las identidades que
tienes disponibles actualmente y determinar qué identidad está siendo usada como
el contexto de usuario activo para ejecutar los comandos `dfx`. Por ejemplo,
puedes ejecutar el siguiente comando para listar las identidades disponibles:

```bash
dfx identity list
```

Este comando muestra la lista de identidades encontradas similar a lo siguiente:

```bash
alice_auth
anonymous
bob_standard *
default
ic_admin
```

El comando muestra las identidades `alice_auth`, `anonymous`, `bob_standard`,
`default` e `ic_admin` en un sistema con identidades configuradas. Un asterisco
(`*`) marca la identidad activa actualmente para ejecutar comandos.

## dfx identity remove

Usa el comando `dfx identity remove` para eliminar una identidad de usuario
existente. Debes tener en cuenta que las identidades que agregues son globales.
No están confinadas a un contexto de proyecto específico. Por lo tanto,
cualquier identidad que elimines usando el comando `dfx identity remove` ya no
estará disponible en ningún proyecto.

### Uso básico

```bash
dfx identity remove [flag] _identity-name_
```

### Flags

Puedes usar las siguientes flags opcionales con el comando
`dfx identity remove`:

| Flag             | Descripción                                                                                                          |
| ---------------- | -------------------------------------------------------------------------------------------------------------------- |
| `--drop-wallets` | Requerida si la identidad tiene carteras configuradas para evitar que los usuarios pierdan el acceso a las carteras. |

### Argumentos

Debes especificar el siguiente argumento para el comando `dfx identity remove`:

| Argumento         | Descripción                                                                     |
| ----------------- | ------------------------------------------------------------------------------- |
| `<identity_name>` | Especifica el nombre de la identidad a eliminar. Este argumento es obligatorio. |

### Ejemplos

Puedes usar el comando `dfx identity remove` para eliminar cualquier identidad
previamente creada, incluida la identidad `default`. Por ejemplo, si has
agregado identidades de usuario con nombre y deseas eliminar la identidad
`default`, puedes ejecutar el siguiente comando:

```bash
dfx identity remove default
```

El comando muestra una confirmación de que la identidad ha sido eliminada:

```bash
Removing identity "default".
Removed identity "default".
```

Aunque puedes eliminar la identidad `default` si has creado otras identidades
para reemplazarla, siempre debes tener al menos una identidad disponible. Si
intentas eliminar la última identidad, el comando `dfx identity remove` mostrará
un error similar al siguiente:

```bash
Identity error:
  Cannot delete the default identity
```

Si tienes una identidad con una o más carteras configuradas, solo se eliminará
si la llamas con `--drop-wallets`. Esto se hace para evitar que los usuarios
pierdan accidentalmente el acceso a sus carteras de ciclos. Si intentas eliminar
una identidad con al menos una cartera configurada, se mostrarán las carteras
adjuntas de esta forma:

```bash
This identity is connected to the following wallets:
    identity 'mainnet' on network 'ic' has wallet rwlgt-iiaaa-aaaaa-aaaaa-cai
```

## dfx identity rename

Usa el comando `dfx identity rename` para cambiar el nombre de una identidad de
usuario existente. Debes tener en cuenta que las identidades que agregues son
globales. No están confinadas a un contexto de proyecto específico. Por lo
tanto, cualquier identidad que renombres usando el comando `dfx identity rename`
estará disponible con el nuevo nombre en cualquier proyecto.

### Uso básico

```bash
dfx identity rename [flag] _from_identity-name_ _to_identity-name_
```

### Argumentos

Debes especificar los siguientes argumentos para el comando
`dfx identity rename`:

| Argumento              | Descripción                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------ |
| `<from_identity_name>` | Especifica el nombre actual de la identidad que deseas renombrar. Este argumento es obligatorio. |
| `<to_identity_name>`   | Especifica el nuevo nombre que deseas asignar a la identidad. Este argumento es obligatorio.     |

### Ejemplo

Puedes cambiar el nombre de la identidad `default` o de cualquier otra identidad
que hayas creado previamente usando el comando `dfx identity rename`. Por
ejemplo, si deseas renombrar una identidad `test_admin` que creaste
anteriormente, debes especificar el nombre de la identidad actual (de donde) y
el nuevo nombre (a donde) ejecutando un comando similar al siguiente:

```bash
dfx identity rename test_admin devops
```

## dfx identity set-wallet

Usa el comando `dfx identity set-wallet` para especificar el identificador de la
cartera canister que usarás para tu identidad.

### Uso básico

```bash
dfx identity set-wallet [flag] [--canister-name canister-name]
```

### Flags

Puedes usar las siguientes flags opcionales con el comando
`dfx identity set-wallet`:

| Flag      | Descripción                                                                                                                                             |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--force` | Omite la verificación de que el canister que especificas es un canister de cartera válido. Esta opción solo es útil si te conectas a IC de forma local. |

### Ejemplo

Si usas más de un principal para tu identidad, podrías tener acceso a más de un
identificador de cartera canister. Puedes usar el comando
`dfx identity set-wallet` para especificar qué identificador de cartera usar
para una identidad dada.

Por ejemplo, puedes almacenar el identificador de la cartera canister en una
variable de entorno y luego invocar el comando `dfx identity set-wallet` para
usar esa cartera canister en operaciones adicionales ejecutando lo siguiente:

```shell
export WALLET_CANISTER_ID=$(dfx identity get-wallet)
dfx identity set-wallet --canister-name ${WALLET_CANISTER_ID} --network=https://192.168.74.4
```

## dfx identity use

Usa el comando `dfx identity use` para especificar la identidad de usuario que
deseas activar. Debes tener en cuenta que las identidades que tienes disponibles
son globales. No están confinadas a un contexto de proyecto específico. Por lo
tanto, puedes usar cualquier identidad que hayas creado previamente en cualquier
proyecto.

La identidad utilizada por un comando es:

- La identidad especificada en el comando con `--identity <NOMBRE>`, si está
  definida.
- Si no, la identidad especificada por la variable de entorno
  `export DFX_IDENTITY=<NAME>`, si está definida.
- La identidad especificada por `dfx identity use <NAME>`.

### Uso básico

```bash
dfx identity use [flag] _identity-name_
```

### Argumentos

Debes especificar el siguiente argumento para el comando `dfx identity use`:

| Argumento         | Descripción                                                                                                           |
| ----------------- | --------------------------------------------------------------------------------------------------------------------- |
| `<identity_name>` | Especifica el nombre de la identidad que deseas activar para los comandos posteriores. Este argumento es obligatorio. |

### Ejemplos

Si deseas ejecutar múltiples comandos con el mismo contexto de identidad de
usuario, puedes ejecutar un comando similar al siguiente:

```bash
dfx identity use ops
```

Después de ejecutar este comando, los comandos posteriores utilizarán las
credenciales y controles de acceso asociados con la identidad `ops`.

## dfx identity whoami

Usa el comando `dfx identity whoami` para mostrar el nombre de la identidad de
usuario activa actualmente.

### Uso básico

```bash
dfx identity whoami [flag]
```

### Ejemplo

Si deseas mostrar el nombre de la identidad de usuario activa actualmente,
puedes ejecutar el siguiente comando:

```bash
dfx identity whoami
```

El comando muestra el nombre de la identidad de usuario. Por ejemplo, si
ejecutaste previamente el comando `dfx identity use bob_standard`, el comando
mostraría:

```
bob_standard
```
