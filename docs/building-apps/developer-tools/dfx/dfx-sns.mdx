# dfx sns

<MarkdownChipRow labels={["Referencia"]} />

:::caution

El comando `dfx sns` ya no es parte de dfx, y ahora se ha convertido en dfx
extension. Para obtenerlo, ejecute `dfx extension install sns`.

:::

Usa el subcomando `dfx sns` para simular la descentralización de una dapp.

La sintaxis básica para ejecutar comandos `dfx sns` es:

```bash
dfx sns [subcommand] [flag]
```

Dependiendo del subcomando `dfx sns` que especifiques, pueden aplicarse
argumentos, opciones y flags adicionales. Para obtener información de referencia
y ejemplos sobre cómo usar los comandos `dfx sns`, selecciona el comando
adecuado.

| Comando                          | Descripción                                                                |
| -------------------------------- | -------------------------------------------------------------------------- |
| [`create`](#_dfx_sns_create)     | Crea una plantilla de configuración para SNS.                              |
| [`validate`](#_dfx_sns_validate) | Verifica si el archivo de configuración de SNS es válido.                  |
| [`deploy`](#_dfx_sns_deploy)     | Despliega los canisters de SNS según la configuración local.               |
| `help`                           | Muestra un mensaje con información de uso para un subcomando especificado. |

Para ver la información de uso de un subcomando específico, especifica el
subcomando junto con el flag `--help`. Por ejemplo, para ver la información de
uso de `dfx sns validate`, puedes ejecutar el siguiente comando:

```bash
dfx sns validate --help
```

## dfx sns create

Utiliza el comando `dfx sns create` para crear un archivo de configuración de
SNS. El archivo de configuración especifica detalles importantes, legales y
financieramente relevantes sobre la descentralización de la dapp. El archivo
deja parámetros en blanco, como el nombre del token; deberás completar estos.

### Uso básico

```bash
dfx sns create
```

### Ejemplos

Puedes usar el comando `dfx sns create` para crear y ver un archivo de
configuración:

```bash
dfx sns create
less sns.yml
```

## dfx sns validate

Utiliza el comando `dfx sns validate` para verificar que un archivo de
configuración de SNS esté bien formado.

### Uso básico

```bash
dfx sns validate
```

### Ejemplos

Puedes usar el comando `dfx sns validate` para verificar que una plantilla de
configuración sea válida. No lo es; necesita detalles como el nombre del token:

```bash
dfx sns config create
```

Completa los campos en blanco y luego:

```bash
dfx sns config validate
```

## dfx sns deploy

Usa el comando `dfx sns deploy` para crear los canisters de SNS según el archivo
de configuración local.

Nota: Desplegar los canisters de SNS no requiere una propuesta, sin embargo
tiene una tarifa considerable. Por favor, no crees canisters en la red principal
hasta que hayas probado tu configuración local y estés seguro de que estás
satisfecho con ella.

### Uso básico

```bash
dfx sns deploy
```

### Ejemplos

Crea un SNS en la red de prueba local:

```bash
dfx sns config create
```

Completa los campos en blanco y luego:

```bash
dfx sns config validate
dfx sns deploy
```

Puedes verificar que los canisters de sns se hayan creado. Por ejemplo:

```
dfx canister info sns_root
dfx canister info sns_ledger
```
