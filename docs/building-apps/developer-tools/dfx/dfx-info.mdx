# dfx info

<MarkdownChipRow labels={["Referencia"]} />

## Uso básico

```bash
dfx info [type] [flag]
```

## Tipos de Información

Estos son los tipos de información que el comando `dfx info` puede mostrar.

| Información        | Descripción                                                                                                                 |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| candid-ui-url      | La URL del canister de Candid UI.                                                                                           |
| networks-json-path | Ruta al archivo de definición de redes `networks.json`.                                                                     |
| replica-port       | El puerto de escucha del replicador.                                                                                        |
| replica-rev        | La revisión del replicador empaquetado.                                                                                     |
| security-policy    | Muestra los encabezados que se aplican a los activos en `.ic-assets.json5` si "security_policy" es "standard" o "hardened". |
| webserver-port     | El puerto del servidor web local.                                                                                           |

## Opciones

Puedes usar las siguientes opciones con el comando `dfx info`.

| Opción                | Descripción                                                                                                   |
| --------------------- | ------------------------------------------------------------------------------------------------------------- |
| `--network <network>` | Sobrescribe el entorno al que conectarse. Por defecto, se utiliza el entorno de ejecución de canisters local. |

## Ejemplos

Puedes mostrar el puerto del servidor web ejecutando el siguiente comando:

```bash
$ dfx info webserver-port
4943
```

Puedes mostrar la URL de Candid UI en mainnet ejecutando el siguiente comando:

```bash
$ dfx info candid-ui-url --network ic
https://a4gq6-oaaaa-aaaab-qaa4q-cai.raw.icp0.io
```
