# dfx stop

<MarkdownChipRow labels={["Referencia"]} />

Usa el comando `dfx killall` para matar forzosamente todos los procesos
relacionados con DFX.

## Uso básico

```bash
dfx killall [flag]
```

## Ejemplos

Puedes matar un proceso atascado que no responde a `dfx stop` con este comando:

```bash
dfx killall
```

Esto puede afectar a los plugins de IDE, incluidos los de otras versiones de
DFX. Para un uso normal, se recomienda `dfx stop`.
