# dfx stop

<MarkdownChipRow labels={["Referencia"]} />

Utiliza el comando `dfx stop` para detener los procesos del entorno de ejecución
local de los canisters que actualmente tienes en ejecución en tu computadora. En
la mayoría de los casos, ejecutas el entorno de ejecución de los canisters
localmente para poder implementar canisters y probar tus dapps durante el
desarrollo. Para simular la conexión a la IC, estos procesos se ejecutan
continuamente ya sea en una terminal donde los iniciaste o en segundo plano
hasta que los detengas o los termines.

Puedes ejecutar este comando desde cualquier directorio a menos que estés
trabajando con un proyecto dfx.json que define una red local específica del
proyecto. Consulta
[Configuración del servidor local](dfx-start.mdx#configuración-del-servidor-local)
para obtener más detalles.

## Uso básico

```bash
dfx stop [flag]
```

## Ejemplos

Puedes detener los procesos del entorno de ejecución local de los canisters que
están en ejecución en segundo plano cambiando al directorio del proyecto y luego
ejecutando el siguiente comando:

```bash
dfx stop
```

Si el entorno de ejecución de canisters local se está ejecutando en la shell
actual en lugar de en segundo plano, abre una nueva terminal, cambia al
directorio del proyecto y ejecuta el comando `dfx stop`.

El identificador de proceso actual (`pid`) para el proceso del entorno de
ejecución de canisters iniciado por `dfx` se registra en un archivo llamado
`pid`. Puedes ver el identificador de proceso antes de ejecutar el comando
`dfx stop` ejecutando uno de los siguientes comandos:

Para una red local específica de un proyecto:

```bash
cat .dfx/network/local/pid
```

Para la red local compartida, en Linux:

```bash
cat $HOME/.local/share/dfx/network/local/pid
```

Para la red local compartida, en MacOS:

```bash
cat '$HOME/Library/Application Support/org.dfinity.dfx/network/local/pid'
```

Este comando muestra un identificador de proceso similar al siguiente:

```bash
1896
```

Si sigues teniendo problemas con un servicio persistente que se ejecuta después
de intentar detenerlo, puedes terminar todos los trabajos en ejecución con:

```bash
dfx killall
```
