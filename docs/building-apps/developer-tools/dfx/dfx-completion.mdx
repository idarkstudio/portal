# dfx completion

<MarkdownChipRow labels={["Referencia"]} />

Genera un script de completado de shell para `dfx`.

## Uso básico

```bash
dfx completion [option] SHELL
```

El comando tiene en cuenta las extensiones instaladas al generar el script de
completado, por lo que debes regenerarlo después de instalar o eliminar
extensiones.

Los valores admitidos para SHELL son `bash`, `elvish`, `fish`, `powershell` y
`zsh`. El valor predeterminado es `bash`.

## Opciones

Puedes usar la siguiente opción con el comando `dfx completion`.

| Opción              | Descripción                                                                                                          |
| ------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `--bin-name <name>` | Nombre del comando. Solo es necesario si te refieres a dfx con otro nombre, como con un alias. Predeterminado `dfx`. |

## Ejemplos

Generar un script de completado para bash:

```bash
dfx completion
```

Genera un script de completado para zsh:

```bash
dfx completion zsh
```

Habilitar el completado en zsh:

```bash
source <(dfx completion zsh)
```

Habilitar el completado en bash:

```bash
source <(dfx completion)
```
