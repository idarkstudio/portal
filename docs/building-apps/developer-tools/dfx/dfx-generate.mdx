# dfx generate

<MarkdownChipRow labels={["Referencia"]} />

Utiliza el comando `dfx generate` para generar declaraciones de tipo de canister
para los lenguajes de programación admitidos. Actualmente, `dfx generate` admite
cuatro lenguajes: Motoko, Candid, JavaScript y TypeScript.

Puedes utilizar este comando para generar declaraciones de tipo para todos los
canisters que están definidos en el archivo de configuración `dfx.json` del
proyecto o para un canister específico.

Ten en cuenta que solo puedes ejecutar este comando desde el directorio del
proyecto. Por ejemplo, si el nombre de tu proyecto es `hello_world`, tu
directorio de trabajo actual debe ser el directorio principal del proyecto
`hello_world` o uno de sus subdirectorios.

El comando `dfx generate` busca la configuración en la sección `declarations` de
un canister en el archivo de configuración `dfx.json`.

## Uso básico

```bash
dfx generate [canister_name]
```

## Argumentos

Puedes especificar los siguientes argumentos para el comando `dfx generate`.

| Argumento       | Descripción                                                                                                                                                                                                                                                                                                                                                                                   |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `canister_name` | Especifica el nombre del canister para el cual generar las declaraciones de tipo. El nombre del canister debe coincidir con al menos un nombre que hayas configurado en la sección `canisters` del archivo de configuración `dfx.json` de tu proyecto. Si no especificas este argumento, `dfx generate` generará las declaraciones de tipo para todos los canisters declarados en `dfx.json`. |

## Configuración

El comportamiento de `dfx generate` está controlado por el archivo de
configuración `dfx.json`. Bajo `dfx.json` → `canisters` → `<canister_name>`,
puedes agregar una sección `declarations`. En esta sección, puedes especificar
los siguientes campos:

| Campo          | Descripción                                                                                                                                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `output`       | Directorio donde colocar las declaraciones para el canister. El valor por defecto es `src/declarations/<canister_name>`.                                     |
| `bindings`     | Lista de lenguajes para los cuales generar declaraciones de tipo. Las opciones son `"js", "ts", "did", "mo"`. El valor por defecto es `["js", "ts", "did"]`. |
| `env_override` | Cadena que reemplazará `process.env.CANISTER_ID_{canister_name_uppercase}` en la plantilla `src/dfx/assets/language_bindings/canister.js`.                   |

Salidas de `dfx generate`:

| Lenguaje         | Archivo                                 |
| ---------------- | --------------------------------------- |
| `JavaScript(js)` | `index.js` y `<canister_name>.did.js`   |
| `TypeScript(ts)` | `index.d.ts` y `<canister_name>.did.ts` |
| `Candid(did)`    | `<canister_name>.did`                   |
| `Motoko(mo)`     | `<canister_name>.mo`                    |

## Ejemplos

Ten en cuenta que el nombre del archivo y la ruta a los programas en tu sistema
de archivos deben coincidir con la información especificada en el archivo de
configuración `dfx.json`.

En este ejemplo, el canister `hello_world` está escrito en Motoko. La sección
`declarations` especifica que se generarán declaraciones de tipo para los cuatro
lenguajes y se almacenarán en `src/declarations/`.

```bash
dfx generate hello_world
```

Dado que solo hay un canister en `dfx.json`, llamar a `dfx generate` sin un
argumento tendrá el mismo efecto que el comando anterior. Si hubiera múltiples
canisters definidos en `dfx.json`, esto generaría declaraciones de tipo para
todos los canisters definidos.

```bash
dfx generate
```
