# dfx ledger

<MarkdownChipRow labels={["Referencia"]} />

Usa el comando `dfx ledger` para interactuar con el canister del ledger.

Este comando se puede usar para realizar transacciones de tokens de utilidad ICP
de un canister a otro, o recargar canisters con cycles de ICP.

La sintaxis básica para ejecutar los comandos `dfx ledger` es:

```bash
dfx ledger [subcommand] [options]
```

Dependiendo del subcomando `dfx ledger` que especifiques, pueden aplicarse
argumentos, opciones y flags adicionales. Para obtener información de referencia
y ejemplos sobre cómo usar los comandos `dfx ledger`, selecciona el comando
adecuado.

| Comando                                            | Descripción                                                                                            |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [`account-id`](#dfx-ledger-account-id)             | Imprime el identificador de cuenta de la identidad seleccionada.                                       |
| [`balance`](#dfx-ledger-balance)                   | Imprime el saldo de la cuenta del usuario.                                                             |
| [`create-canister`](#dfx-ledger-create-canister)   | Crea un canister a partir de ICP.                                                                      |
| [`fabricate-cycles`](#dfx-ledger-fabricate-cycles) | Solo para desarrollo local: Fabrica cycles de la nada y deposítalos en el/los canisters especificados. |
| `help`                                             | Muestra el mensaje de información de uso para un subcomando específico.                                |
| [`notify`](#dfx-ledger-notify)                     | Notifica al ledger cuando se realiza una transacción de envío al canister de creación de cycles.       |
| [`top-up`](#dfx-ledger-top-up)                     | Recarga un canister con cycles emitidos a partir de ICP.                                               |
| [`transfer`](#dfx-ledger-transfer)                 | Transfiere ICP desde el usuario hacia el identificador de cuenta de destino.                           |

Para ver información de uso de un subcomando específico, especifica el
subcomando y la flag `--help`. Por ejemplo, para ver la información de uso para
`dfx ledger transfer`, puedes ejecutar el siguiente comando:

`dfx ledger transfer --help`

## dfx ledger account-id

Usa el comando `dfx ledger account-id` para mostrar el identificador de cuenta
asociado con la identidad actualmente activa. Al igual que la representación
textual de tu identidad de desarrollador, el identificador de cuenta se deriva
de tu clave privada y se usa para representar tu identidad en el canister
ledger. Este comando también se puede usar para calcular y mostrar los
identificadores de cuenta de otros principios, alias de canisters y subcuentas
de tu cuenta (también subcuentas derivadas de principios).

### Uso básico

```bash
dfx ledger account-id [flag]
```

### Flags

Puedes usar las siguientes flags opcionales con el comando
`dfx ledger account-id`:

| Flag                                    | Descripción                                                 |
| --------------------------------------- | ----------------------------------------------------------- |
| `-h`, `--help`                          | Muestra la información de uso.                              |
| `-V`, `--version`                       | Muestra la información de la versión.                       |
| `--of-canister <ALIAS>`                 | Alias o principal del canister que controla la cuenta       |
| `--of-principal <PRINCIPAL>`            | Principal que controla la cuenta                            |
| `--subaccount <SUBACCOUNT>`             | Identificador de subcuenta (cadena hex de 64 caracteres)    |
| `--subaccount-of-principal <PRINCIPAL>` | Principal del cual se deriva el identificador de subcuenta. |

### Ejemplos

Si has creado más de una identidad, verifica cuál estás utilizando actualmente
ejecutando el comando `dfx identity whoami` o el comando
`dfx identity get-principal`. Luego puedes verificar el identificador de cuenta
para la identidad de desarrollador seleccionada ejecutando el siguiente comando:

```bash
dfx ledger account-id
```

El siguiente comando calcula el identificador de cuenta controlado por el
Canister de Alquiler de Subred y para la subcuenta derivada del principal de
Alice:

```bash
dfx ledger account-id --of-canister qvhpv-4qaaa-aaaaa-aaagq-cai --subaccount-from-principal fdsgv-62ihb-nbiqv-xgic5-iefsv-3cscz-tmbzv-63qd5-vh43v-dqfrt-pae
```

Los comandos mostrarán una salida similar a la siguiente:

    03e3d86f29a069c6f2c5c48e01bc084e4ea18ad02b0eec8fccadf4487183c223

## dfx ledger balance

Usa el comando `dfx ledger balance` para imprimir el saldo de tu cuenta o de la
de otro usuario.

### Uso básico

```bash
dfx ledger balance [of] [flag] --network ic
```

### Argumentos

Puedes especificar el siguiente argumento para el comando `dfx ledger balance`:

| Argumento | Descripción                                                                                                                                                                 |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<of>`    | Especifica un Identificador de Cuenta para obtener el saldo. Si este comando no se especifica, se devuelve el saldo de los tokens ICP para la identidad del usuario actual. |

### Ejemplos

Puedes usar el comando `dfx ledger balance` para revisar el saldo de otro
usuario. Por ejemplo, puedes ejecutar el siguiente comando para ver los tokens
de utilidad ICP asociados con un Identificador de Cuenta conocido:

```bash
dfx ledger balance 03e3d86f29a069c6f2c5c48e01bc084e4ea18ad02b0eec8fccadf4487183c223 --network ic
```

Este comando mostrará una cantidad de ICP similar a la siguiente:

    2.49798000 ICP

## dfx ledger create-canister

Usa el comando `dfx ledger create-canister` para convertir tokens ICP en cycles
y registrar un nuevo identificador de canister en el IC.

### Uso básico

```bash
dfx ledger create-canister <controller> [options]  [flag] --network ic
```

### Argumentos

Puedes especificar el siguiente argumento para el comando
`dfx ledger create-canister`:

| Argumento      | Descripción                                                                                     |
| -------------- | ----------------------------------------------------------------------------------------------- |
| `<controller>` | Especifica el identificador principal para establecerlo como el controlador del nuevo canister. |

### Opciones

Puedes especificar los siguientes argumentos para el comando
`dfx ledger create-canister`:

| Opción                           | Descripción                                                                                                                                                                 |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--amount <amount>`              | Especifica el número de tokens ICP para convertir en cycles y depositarlos en el canister de destino. Puedes especificar una cantidad con hasta ocho (8) decimales.         |
| `--e8s <e8s>`                    | Especifica las unidades fraccionarias de los tokens ICP llamadas e8s como un número entero, donde un e8 es la partición más pequeña de un token ICP.                        |
| `--fee <fee>`                    | Especifica una tarifa de transacción. El valor por defecto es 10000 e8s.                                                                                                    |
| `--icp <icp>`                    | Especifica tokens ICP como un número entero. Puedes usar esta opción sola o junto con la opción `--e8s`.                                                                    |
| `--max-fee <max-fee>`            | Especifica una tarifa máxima de transacción. El valor por defecto es 10000 e8s.                                                                                             |
| `--subnet-type <subnet-types>`   | Especifica el tipo de subnet opcional para crear el canister. Si no se proporciona tipo de subnet, el canister se creará en un subnet de aplicación predeterminado.         |
| `--subnet <subnet-principal>`    | Especifica la subnet opcional para crear el canister. Si no se proporciona subnet, el canister se creará en un subnet de aplicación predeterminado.                         |
| `--next-to <canister-principal>` | Crea canisters en el mismo subnet que este canister.                                                                                                                        |
| `--created-at-time <timestamp>`  | Especifica el timestamp en nanosegundos para el campo `created_at_time` en la solicitud de transferencia del ledger. Útil para controlar la deduplicación de transacciones. |

### Ejemplos

Para crear un nuevo canister con cycles, transfiere tokens ICP desde tu cuenta
de ledger ejecutando un comando similar al siguiente:

```bash
dfx ledger create-canister tsqwz-udeik-5migd-ehrev-pvoqv-szx2g-akh5s-fkyqc-zy6q7-snav6-uqe --amount 1.25 --network ic
```

Este comando convierte la cantidad de tokens ICP que especificaste en cycles y
los asocia con un nuevo identificador de canister controlado por el principal
que especificaste.

Si la transacción tiene éxito, el ledger registra el evento y deberías ver una
salida similar a la siguiente:

    Transferencia enviada en BlockHeight: 20
    Canister creado con id: "53zcu-tiaaa-aaaaa-qaaba-cai"

Puedes crear un nuevo canister especificando valores separados para ICP y e8s
ejecutando un comando similar al siguiente:

```bash
dfx ledger create-canister tsqwz-udeik-5migd-ehrev-pvoqv-szx2g-akh5s-fkyqc-zy6q7-snav6-uqe --icp 3 --e8s 5000 --network ic
```

## dfx ledger fabricate-cycles

Usa el comando `dfx ledger fabricate-cycles` para agregar cycles a un canister
mientras desarrollas localmente. Los cycles se crean de la nada y no se deducen
de ningún lado.

### Uso básico

```
dfx ledger fabricate-cycles [options]
```

### Opciones

Puedes especificar las siguientes opciones para el comando
`dfx ledger fabricate-cycles`. Si no se especifica una cantidad, se utilizarán
10T cycles por defecto.

| Opción                  | Descripción                                                                                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `--all`                 | Deposita cycles en todos los canisters configurados en el archivo `dfx.json`.                                                                                            |
| `--amount <icp>`        | ICP a convertir en cycles y depositar en el canister de destino. Se puede especificar como un decimal con la parte fraccionaria hasta 8 decimales, por ejemplo, 100.012. |
| `--canister <name/id>`  | Especifica el nombre o el id del canister que recibirá el depósito de cycles. Debes especificar un canister o la opción `--all`.                                         |
| `--cycles <cycles>`     | Especifica la cantidad de cycles a fabricar.                                                                                                                             |
| `--e8s <e8s>`           | Especifica los e8s como un número entero. Útil en combinación con `--icp`.                                                                                               |
| `--icp`                 | Especifica ICP como un número entero. Útil en combinación con `--e8s`.                                                                                                   |
| `--t <trillion cycles>` | Especifica la cantidad de cycles a fabricar en billones de cycles. Solo acepta números enteros.                                                                          |

### Ejemplos

Si estás desarrollando localmente y deseas agregar 8T cycles a todos tus
canisters en tu proyecto, puedes hacerlo de la siguiente manera:

```bash
dfx ledger fabricate-cycles --all --cycles 8000000000000
```

El comando muestra una salida similar a la siguiente:

```bash
Fabricating 8000000000000 cycles onto hello_backend
Fabricated 8000000000000 cycles, updated balance: 11_899_662_119_932 cycles
```

Si prefieres agregar los cycles solo al canister llamado 'hello' y no quieres
escribir todos los ceros, puedes hacerlo así:

```bash
dfx ledger fabricate-cycles --canister hello --t 8
```

El comando muestra una salida similar a la siguiente:

```bash
Fabricating 8000000000000 cycles onto hello
Fabricated 8000000000000 cycles, updated balance: 11_899_662_119_932 cycles
```

## `dfx ledger notify`

Usa el comando `dfx ledger notify` para notificar al ledger sobre una
transacción enviada al canister de creación de cycles. Este comando solo debe
usarse si `dfx ledger create-canister`, `dfx ledger top-up`, o
`dfx cycles convert` enviaron correctamente un mensaje al ledger y una
transacción fue registrada en algún bloque, pero la posterior notificación falló
por algún motivo.

### Uso básico

```bash
dfx ledger notify [options] _block-height_ _destination-principal_
```

### Argumentos

Puedes especificar los siguientes argumentos para el comando
`dfx ledger notify`.

| Argumento                 | Descripción                                                                                                                                                                                                                                                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `<block-height>`          | Especifica la altura del bloque en la que la transacción de envío fue registrada.                                                                                                                                                                                                                                         |
| `<destination-principal>` | Especifica el principal del destino, ya sea un identificador de canister o la representación textual de un principal de usuario. Si la transacción de envío fue para el comando `create-canister`, especifica el principal `controller`. Si la transacción fue para el comando `top-up`, especifica el `id` del canister. |

### Ejemplos

El siguiente ejemplo ilustra el envío de un mensaje `notify` al ledger en
respuesta a una transacción `_send+` que fue registrada en la altura del bloque
`75948`:

```bash
dfx ledger notify 75948 tsqwz-udeik-5migd-ehrev-pvoqv-szx2g-akh5s-fkyqc-zy6q7-snav6-uqe --network ic
```

## dfx ledger show-subnet-types

Usa el comando `dfx ledger show-subnet-types` para listar los tipos de subred
disponibles que se pueden elegir para crear un canister.

### Uso básico

```bash
dfx ledger show-subnet-types [options] [flag]
```

### Opciones

Puedes especificar las siguientes opciones para el comando
`dfx ledger show-subnet-types`.

| Opción                                                      | Descripción                                                                                                              |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `--cycles-minting-canister-id <cycles-minting-canister-id>` | Identificador del canister de creación de cycles. Útil si deseas probar localmente con un id diferente para el canister. |

### Ejemplos

Puedes usar el comando `dfx ledger show-subnet-types` para listar los tipos de
subred disponibles para crear un canister. Si no se proporciona un id específico
del canister de creación de cycles, se usará el id del canister de creación de
cycles de la red principal.

Por ejemplo, puedes ejecutar el siguiente comando para obtener los tipos de
subred disponibles en la red principal:

```bash
dfx ledger show-subnet-types
```

Este comando muestra una salida similar a la siguiente:

```bash
["Type1", "Type2", ..., "TypeN"]
```

## dfx ledger top-up

Usa el comando `dfx ledger top-up` para recargar un canister con cycles acuñados
de tokens ICP.

### Uso básico

```bash
dfx ledger top-up [options] canister [flag] --network ic
```

### Argumentos

Puedes especificar el siguiente argumento para el comando `dfx ledger top-up`.

| Argumento  | Descripción                                                               |
| ---------- | ------------------------------------------------------------------------- |
| `canister` | Especifica el identificador o el nombre del canister que deseas recargar. |

### Opciones

Puedes especificar las siguientes opciones para el comando `dfx ledger top-up`.

| Opción                          | Descripción                                                                                                                                                                            |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--amount <amount>`             | Especifica la cantidad de tokens ICP a acuñar en cycles y depositar en el canister de destino. Puedes especificar la cantidad como un número con hasta ocho (8) decimales.             |
| `--e8s <e8s>`                   | Especifica las unidades fraccionarias de un token ICP, llamadas e8s, como un número entero. Un e8 es la unidad más pequeña de un token ICP. Puedes usar esta opción junto con `--icp`. |
| `--fee <fee>`                   | Especifica la tarifa de transacción para la operación. El valor por defecto es 10000 e8s.                                                                                              |
| `--icp <icp>`                   | Especifica los tokens ICP como un número entero. Puedes usar esta opción sola o junto con `--e8s`.                                                                                     |
| `--max-fee <max-fee>`           | Especifica una tarifa máxima para la transacción. El valor por defecto es 10000 e8s.                                                                                                   |
| `--created-at-time <timestamp>` | Especifica el valor de `created_at_time` en nanosegundos en la solicitud de transferencia del ledger. Útil para controlar la deduplicación de transacciones.                           |

### Ejemplos

Puedes usar el comando `dfx ledger top-up` para recargar los cycles de un
canister específico desde el saldo de tokens ICP que controlas. El identificador
del canister debe estar asociado con un canister de wallet de cycles que pueda
recibir cycles. Alternativamente, puedes modificar un canister que no sea de
wallet de cycles para implementar un método que reciba cycles usando las APIs
del sistema descritas en la
[Especificación de la Interfaz de Internet Computer](/docs/references/ic-interface-spec).

Por ejemplo, puedes ejecutar el siguiente comando para recargar un canister de
wallet de cycles desplegado en Internet Computer con 1 ICP en cycles:

```bash
dfx ledger top-up --icp 1 5a46r-jqaaa-aaaaa-qaadq-cai --network ic
```

Este comando muestra una salida similar a la siguiente:

```bash
Transfer sent at BlockHeight: 59482
Canister was topped up!
```

## dfx ledger transfer

Usa el comando `dfx ledger transfer` para transferir tokens ICP desde la
dirección de tu cuenta en el canister ledger a una dirección de destino.

### Uso básico

```bash
dfx ledger transfer [options] to --memo memo
```

### Argumentos

Puedes especificar el siguiente argumento para el comando `dfx ledger transfer`.

| Argumento       | Descripción                                                                                     |
| --------------- | ----------------------------------------------------------------------------------------------- |
| `<to>`          | Especifica el identificador de cuenta o la dirección a la que deseas transferir los tokens ICP. |
| `--memo <memo>` | Especifica un memo numérico para esta transacción.                                              |

### Opciones

Puedes especificar las siguientes opciones para el comando
`dfx ledger transfer`.

| Opción                          | Descripción                                                                                                                                                                                                 |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--amount <amount>`             | Especifica la cantidad de tokens ICP a transferir. Se puede especificar como un número con hasta ocho (8) decimales.                                                                                        |
| `--e8s <e8s>`                   | Especifica los e8s como un número entero, donde un e8 es la unidad más pequeña de un token ICP. Por ejemplo, 1.05000000 es 1 ICP y 5000000 e8s. Puedes usar esta opción sola o junto con la opción `--icp`. |
| `--fee <fee>`                   | Especifica la tarifa de transacción. El valor por defecto es 10000 e8s.                                                                                                                                     |
| `--icp <icp>`                   | Especifica ICP como un número entero. Puedes usar esta opción sola o junto con `--e8s`.                                                                                                                     |
| `--created-at-time <timestamp>` | Especifica el valor de `created_at_time` en nanosegundos en la solicitud de transferencia del ledger. Útil para controlar la deduplicación de transacciones.                                                |

### Ejemplos

Puedes usar el comando `dfx ledger transfer` para enviar ICP al identificador de
cuenta de un destino.

Por ejemplo, puedes ejecutar el siguiente comando para verificar el
identificador de cuenta asociado con el principal que estás utilizando:

```bash
dfx ledger account-id
```

Este comando muestra una salida similar a la siguiente:

```bash
30e596fd6c5ff5ad7b7d70bbbda1187c833e646c6251464da7f82bc217bba397
```

Puedes verificar el saldo de esta cuenta ejecutando el siguiente comando:

```bash
dfx ledger balance --network ic
```

Este comando muestra una salida similar a la siguiente:

    64.89580000 ICP

Usa el comando `dfx ledger transfer` para enviar parte de tu saldo ICP a otro
destino conocido, utilizando el siguiente comando:

```bash
dfx ledger transfer dd81336dbfef5c5870e84b48405c7b229c07ad999fdcacb85b9b9850bd60766f --memo 12345 --icp 1 --network ic
```

Este comando muestra una salida similar a la siguiente:

    Transfer sent at BlockHeight: 59513

Luego puedes usar el comando `dfx ledger balance --network ic` para verificar
que el saldo de tu cuenta refleje la transacción que acabas de realizar.
