# Generación de archivos Candid para canisters Rust

<MarkdownChipRow labels={["Principiante", "Rust"]} />

En las versiones del Rust CDK `v0.11.0` y superiores, el flujo de trabajo para
exportar Candid ha cambiado. Puedes llamar a la macro `ic_cdk::export_candid!()`
para habilitar el comportamiento de exportación Candid, y luego usar el
[candid-extractor](https://github.com/dfinity/cdk-rs/tree/main/src/candid-extractor)
para extraer el Candid del Wasm del canister.

### Preparación

- #### Paso 1: Actualizar la dependencia `ic-cdk` a la versión v0.11.0 o superior:

```toml title="Cargo.toml"
[dependencies]
ic-cdk = "0.11.0"
```

- #### Paso 2: Instalar [candid-extractor](https://github.com/dfinity/cdk-rs/tree/main/src/candid-extractor)

```bash
cargo install candid-extractor
```

Con `cargo-binstall` puedes instalar el binario precompilado sin esperar a la
compilación:

```bash
cargo binstall candid-extractor
```

### Flujo de trabajo

- #### Paso 1: Llama a la macro `export_candid` al final de tu archivo `lib.rs`:

```rust title="lib.rs"
#[query]
fn hello(name: String) -> String {
    format!("Hello, {}!", name)
}

#[update]
fn world(name: String) -> String {
    format!("World, {}!", name)
}

// Enable Candid export
ic_cdk::export_candid!();
```

- #### Paso 2: Compila el módulo Wasm del canister:

```bash
cargo build --release --target wasm32-unknown-unknown --package <CANISTER>
```

El módulo Wasm estará en:

```bash
target/wasm32-unknown-unknown/release/<CANISTER>.wasm
```

- #### Paso 3: Extrae el archivo Candid del módulo Wasm y guárdalo en un archivo:

```bash
candid-extractor target/wasm32-unknown-unknown/release/<CANISTER>.wasm > <CANISTER>.did
```
