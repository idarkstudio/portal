# Rust CDK (Kit de Desarrollo de Canisters)

<MarkdownChipRow labels={["Principiante", "Rust"]} />

Rust es un lenguaje de programación moderno, potente y con sólido sistema de
tipos, que cuenta con una activa comunidad de desarrolladores. Al compilar a
WebAssembly, Rust ofrece un entorno de desarrollo enriquecido para crear dapps
que se ejecutan en ICP.

El desarrollo de canisters en Rust está soportado en ICP a través del
[Rust Canister Development Kit (CDK)](https://github.com/dfinity/cdk-rs),
desarrollado y mantenido por DFINITY. Rust tiene soporte nativo en herramientas
de desarrollo para ICP como [`dfx`](/docs/building-apps/developer-tools/dfx/) y
[PocketIC](/docs/building-apps/advanced/test/pocket-ic), y puede utilizarse con
características como:

- [Certificación HTTP](/docs/building-apps/network-features/using-http/http-certification/custom-http-canisters)
- [Consultas compuestas](/docs/building-apps/interact-with-canisters/query-calls)
- [Estadísticas de consultas](/docs/building-apps/interact-with-canisters/query-calls)

Aunque el uso del IC SDK es el flujo de trabajo típico para desarrollar
canisters en Rust, desarrolladores experimentados pueden optar por omitir el IC
SDK y usar directamente el Rust CDK.

## Componentes del Rust CDK

El Rust CDK consta de los siguientes crates:

- [`ic-cdk`](https://crates.io/crates/ic-cdk): Métodos principales que permiten
  a programas Rust interactuar con la API del sistema ICP.

- [`ic-cdk-macros`](https://crates.io/crates/ic-cdk-macros): Define macros
  procedurales (ej. `update`, `query`, `import`) que facilitan la construcción
  de endpoints y APIs.

- [`ic-cdk-timers`](https://crates.io/crates/ic-cdk-timers): Provee una API para
  programar múltiples temporizadores y tareas periódicas.
