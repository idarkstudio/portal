# Estructuras estables

<MarkdownChipRow labels={["Intermedio", "Rust", "Tutorial"]} />

Las estructuras estables están diseñadas para usar memoria estable como
almacenamiento subyacente, permitiéndoles crecer hasta gigabytes de tamaño sin
necesidad de hooks `pre_upgrade`/`post_upgrade`.

:::danger

El uso de hooks pre_upgrade y post_upgrade está desaconsejado. Es propenso a
errores y puede dejar un canister inutilizable. Según las mejores prácticas, se
debe evitar el uso de estos métodos cuando sea posible.

:::

Existe una
[librería de estructuras estables](https://github.com/dfinity/stable-structures#readme)
que busca simplificar el manejo de estructuras de datos directamente en memoria
estable y proporciona plantillas de código de ejemplo.

Para más información sobre estructuras estables, consulta:

- [La librería de estructuras estables](https://github.com/dfinity/stable-structures)
- [El tutorial de Roman sobre estructuras estables](https://mmapped.blog/posts/14-stable-structures.html)
