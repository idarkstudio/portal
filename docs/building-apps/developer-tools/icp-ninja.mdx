# ICP Ninja

<MarkdownChipRow labels={["Principiante", "Herramientas de desarrollo"]} />
[ICP Ninja](https://icp.ninja) es un entorno de desarrollo integrado (IDE) basado
en la web para crear y desplegar aplicaciones descentralizadas en el Internet Computer.

ICP Ninja ofrece una galería de proyectos de ejemplo que puedes explorar para
aprender sobre diferentes tipos de aplicaciones, arquitecturas y casos de uso.
Cada proyecto puede editarse y desplegarse directamente en la mainnet desde el
navegador. Una vez desplegado, puedes abrir la interfaz del frontend en tu
navegador o interactuar con el backend a través de la
[Candid UI](/docs/building-apps/interact-with-canisters/candid/candid-concepts).

Desde la [página principal de ICP Ninja](https://icp.ninja), selecciona un
proyecto de ejemplo para comenzar. Puedes filtrar la galería por tipo de
proyecto, lenguaje y nivel de habilidad. Hay variantes de proyectos disponibles
con código backend en Motoko y Rust. Todos los proyectos usan React para el
frontend.

El ejemplo **"Hello, World!"** es el más adecuado para principiantes y se
asemeja a la plantilla predeterminada generada por la herramienta de línea de
comandos [`dfx`](/docs/building-apps/getting-started/install).

Una vez que abras un proyecto en el editor de código de ICP Ninja, podrás:

- Leer el archivo `README.md` para conocer más sobre la funcionalidad y
  estructura del proyecto.
- Editar la interfaz del usuario en la carpeta `frontend` (algunos archivos
  pueden ser inmutables).
- Revisar o modificar el código backend en `backend/main.mo` (Motoko) o
  `backend/lib.rs` (Rust).
- Agregar nuevos archivos al canister frontend o backend.
- Consultar al asistente de IA para obtener ayuda sobre ICP o código del
  proyecto.

:::danger

ICP Ninja no reemplaza herramientas como el
[IC SDK](/docs/building-apps/getting-started/install).

:::

Haz clic en el botón **"Deploy"**. En la pestaña "Build Logs" verás el progreso
del despliegue, como:

```
→ Reserving canisters
→ Building backend
→ Generating backend declarations
→ Building frontend
...
```

Una vez desplegado, recibirás dos URLs:

```
Backend canister smart contract:
https://a4gq6-oaaaa-aaaab-qaa4q-cai.icp1.io/?id=ts425-saaaa-aaaab-qbksq-cai
🥷🚀🎉 Frontend is available at:
https://2drrs-wqaaa-aaaab-qblbq-cai.icp1.io
```

- La **URL del backend canister** abre la
  [Candid UI](/docs/building-apps/interact-with-canisters/candid/candid-concepts)
  para interactuar con los métodos del canister.
- La **URL del frontend** carga la interfaz de usuario del proyecto, desplegada
  como un
  [asset canister](/docs/building-apps/frontends/using-an-asset-canister).

También puedes previsualizar la interfaz de usuario y la Candid UI dentro del
editor de ICP Ninja.

:::info

El proyecto estará disponible por **20 minutos**. Un temporizador junto al botón
"Deploy" mostrará el tiempo restante. Una vez expirado, las URLs dejarán de ser
válidas, pero el código seguirá accesible para volver a desplegarlo.

:::

Para actualizar un proyecto después del despliegue, edita el código en ICP Ninja
y selecciona **"Redeploy"**. Esto reiniciará el temporizador de 20 minutos y
aplicará los cambios.

## Descargar y desarrollar localmente

Para continuar desarrollando un proyecto de ICP Ninja localmente o agregar
funcionalidades avanzadas, puedes descargar los archivos del proyecto y usar
`dfx`.

Desde el menú de opciones del proyecto en ICP Ninja, selecciona **"Download
files"**. Luego, revisa el archivo `BUILD.md` incluido en la descarga, donde
encontrarás instrucciones para configurar y usar `dfx` con tu proyecto.

## Limitaciones actuales

ICP Ninja está en desarrollo activo y presenta algunas limitaciones:

- **Paquetes soportados**: Solo ciertos paquetes npm están disponibles. La lista
  está en `package-lock.json` y no se puede modificar.
- **Estructura de proyectos**: Los proyectos deben seguir una estructura
  específica con un máximo de dos canisters (backend y frontend). El frontend
  solo puede contener una subcarpeta `frontend/src`.
