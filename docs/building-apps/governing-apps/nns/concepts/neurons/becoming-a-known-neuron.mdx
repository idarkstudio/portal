# Registrar una neurona conocida

<MarkdownChipRow labels={["Avanzado", "Gobernanza", "Tutorial"]} />

Una neurona conocida tiene un nombre y, opcionalmente, una descripción breve.
Una neurona conocida puede registrarse en la gobernanza del NNS a través de una
propuesta, almacenando oficialmente su nombre y descripción dentro del NNS. Esta
información puede ser utilizada por otras neuronas para encontrar neuronas
conocidas y
[seguirlas](/docs/building-apps/governing-apps/nns/concepts/neurons/neuron-following).

Para convertirse en una neurona conocida en la DAO del NNS, primero debes crear
una neurona, y luego enviar una propuesta al NNS para registrarte como una
neurona conocida. Después de que la propuesta sea aceptada y tu neurona esté
registrada, será visible para todos los usuarios del NNS cuando configuren el
seguimiento de sus propias neuronas.

Puede ser útil que los candidatos a neuronas conocidas sean neuronas activamente
votantes (no registradas) durante un tiempo antes de registrarse como neuronas
conocidas. Durante este tiempo, el titular de la neurona puede familiarizarse
con la votación y comenzar a convertirse en un experto en un tema. También
pueden compartir su ID de neurona para que otros los sigan. De esta forma, para
cuando registren la neurona como conocida, ya habrá evidencia de su
comportamiento de votación en la que los participantes del NNS puedan basar su
decisión. Además, para convencer a la DAO del NNS de aceptar una nueva neurona
conocida, puede ser útil que los candidatos se presenten ante la comunidad fuera
del contexto de gobernanza, por ejemplo, en el foro o en redes sociales.

## Crear una neurona

Hay múltiples opciones para crear y configurar una neurona que luego pueda
registrarse como neurona conocida. Una neurona conocida puede ser operada por
una persona individual o por una organización donde una persona controla la
neurona o es operada por un grupo de personas. Dependiendo de esto, diferentes
opciones de creación de neuronas pueden ser más adecuadas.

### Crear una neurona controlada por una sola parte

Si deseas crear una neurona conocida que sea operada por una sola parte que
conoce la clave de control de la neurona y puede modificarla, puedes usar una de
las siguientes opciones:

- [Crear la neurona en la aplicación NNS](/docs/building-apps/governing-apps/nns/overview#stake-icp-utility-tokens-in-a-neuron).
- [Crear la neurona en la aplicación NNS que esté controlada por una wallet de hardware Ledger](https://support.dfinity.org/hc/en-us/articles/8760495850900-How-do-I-use-my-Ledger-Nano-with-the-Internet-Computer)
- [Crear la neurona mediante la herramienta de línea de comandos quill](https://support.dfinity.org/hc/en-us/articles/4408752586260-What-is-Quill).

:::info

Si hay varias personas involucradas en la decisión de voto de una neurona
conocida, la neurona puede configurarse para seguir sus neuronas individuales en
los temas sobre los cuales debe votar. Sin embargo, para una neurona creada de
esta manera, la **persona que creó la neurona tiene la clave de control**. Esta
persona puede modificar la neurona y, en particular, también puede votar usando
la neurona sin tener en cuenta la opinión de otros. Esto puede ser adecuado para
individuos que operan una neurona conocida, o para organizaciones donde una
persona tiene la confianza para esta tarea.

:::

## Comenzar a votar y presentar tu neurona a la comunidad

Una vez que hayas creado una neurona, puedes comenzar a votar con ella y también
compartir contexto sobre cómo y por qué votaste con la comunidad. Ya puedes
compartir tu ID de neurona con otros para que te sigan en ciertos temas.

No hay reglas que una neurona conocida deba seguir respecto a si se presenta o
no ante la comunidad, pero puede tener sentido que los propietarios de neuronas
se presenten antes de enviar la propuesta para registrarse como neurona
conocida. Esto puede servir como una forma de promocionar la neurona y explicar
la motivación detrás de ella. Esto puede hacerse, por ejemplo, con una
publicación en el foro o compartiendo información en redes sociales, como
OpenChat o X.

Esto podría ser útil para que los seguidores puedan tomar decisiones bien
informadas sobre a quién seguir en cada tema:

- **Quién eres**: Nombre de la persona o grupo y su relación con ICP. Puedes
  argumentar por qué las personas detrás de la neurona tienen un interés a largo
  plazo en el bienestar de ICP y están motivadas para tomar buenas decisiones de
  votación.
- **Control de la neurona**: ¿Quién controla la neurona? ¿Tiene un único
  controlador o puede ser modificada por un grupo de personas?
- **Temas cubiertos**: Una descripción de los temas sobre los que votará la
  neurona conocida. ¿La neurona se compromete a votar siempre sobre estos temas?
  Dado que el seguimiento se hace por temas de propuesta, esta es información
  relevante para los seguidores. Por lo general, las neuronas querrán seguir a
  otras neuronas que siempre votan sobre un tema determinado para no perderse
  las [recompensas de votación](./staking-voting-rewards.mdx).
- **Profundidad de las revisiones**: Una descripción de cómo la neurona conocida
  planea verificar las propuestas. ¿Con qué profundidad revisará el código o el
  contenido de la propuesta y cómo se hará?
- **Configuración de seguimiento**: Para los temas donde la neurona conocida no
  vote directamente, ¿a quién sigue la neurona?
- **Principios de votación**: ¿Cuáles son los principios según los cuales
  planeas votar?
- **Enlace al ID de la neurona / propuesta**: Si ya creaste la neurona, puedes
  proporcionar su ID o incluso un enlace a un panel donde pueda ser
  inspeccionada. Lo mismo aplica para la propuesta para registrarla como neurona
  conocida en caso de que ya se haya hecho.

:::info

Puede ser útil que las neuronas conocidas **se centren en menos temas y se
comprometan a votar siempre sobre ellos** en lugar de intentar cubrir muchos
temas y votar de manera menos confiable. Por ejemplo, podrían convertirse en
expertos en algunos temas de propuesta. Si una neurona conocida se compromete a
votar siempre sobre un tema en particular, es más probable que otros la sigan en
ese tema, ya que los seguidores quieren asegurarse de no perderse recompensas.

:::

## Registrar la neurona conocida

Para registrar una neurona como neurona conocida, debes enviar una propuesta al
NNS. La propuesta puede ser enviada por cualquier neurona que tenga al menos 10
ICP apostados. Para simplificar, asumimos en el siguiente ejemplo que la neurona
que se va a registrar fue creada en la aplicación NNS y que la misma neurona se
utiliza para enviar la propuesta.

- ### Paso 1: Descargar e instalar `dfx`

No es posible enviar propuestas a través de la aplicación NNS. Por lo tanto,
debes usar una herramienta de línea de comandos llamada `dfx`. `dfx` solo es
compatible de forma nativa con Mac y Linux, pero puede instalarse en Windows
usando WSL.

Para instalar `dfx`, sigue las
[instrucciones de instalación](/docs/building-apps/getting-started/install#installing-dfx).

Aquí están las instrucciones para Mac y Linux:

```bash
sh -ci "$(curl -fsSL https://internetcomputer.org/install.sh)"
```

Si estás usando una máquina con Apple Silicon, necesitarás tener
[Rosetta](https://support.apple.com/en-us/HT211861) instalado. Puedes instalar
Rosetta ejecutando `softwareupdate --install-rosetta` en tu terminal.

- ### Paso 2: Agregar tu principal de `dfx` como hotkey de tu neurona

Tu neurona está controlada por un **ID principal**, que es una identidad en ICP.
Sin embargo, quieres poder enviar propuestas desde la línea de comandos en
nombre de esta neurona. Para esto, puedes registrar el principal que tienes en
tu computadora como una
[**hotkey**](/docs/building-apps/governing-apps/nns/concepts/neurons/neuron-management#neuron-attributes)
de la neurona. Las hotkeys tienen permiso para votar y enviar propuestas por la
neurona.

Ejecuta `dfx identity get-principal` para obtener el ID principal que
corresponde a tu
[identidad de desarrollador](/docs/building-apps/getting-started/identities).
Los siguientes pasos se referirán a esto como tu "principal de dfx". Debería
mostrar un texto parecido a esto:
`hnswe-crhc7-funvc-qqkg4-pk3j4-vxfhs-ckf2o-i56yb-frent-vl7vk-3qe`.

Luego, vuelve a la aplicación NNS. En la página de "Neuron Staking", haz clic en
“Add Hotkey” para tu neurona. Es posible que tengas que desplazarte un poco
hacia abajo. Una vez que hayas hecho clic en “Add Hotkey”, pega tu principal de
dfx en la ventana que aparece y presiona confirmar. Tu principal de dfx debería
aparecer bajo “Hotkeys”. Ahora puedes controlar tu neurona desde la terminal
local.

- ### Paso 3: Enviar la propuesta

Para enviar la propuesta, necesitas el ID de la neurona que se registrará como
neurona conocida, un nombre para la neurona conocida y una breve descripción.
Puedes encontrar tu ID de neurona en la aplicación NNS en la parte superior
derecha de la página del panel de control de tu neurona.

Para enviar la propuesta, personaliza la siguiente plantilla en un editor de
texto y luego ejecútala.

Puedes ejecutarla pegando la plantilla personalizada en tu terminal.

```
NEURON_ID="tu ID de neurona" # Configura con tu ID de neurona copiado en el paso anterior
NEW_NAME="nombre deseado para la neurona conocida" # Personaliza
NEW_DESCRIPTION="descripción deseada para la neurona conocida" # Personaliza
PROPOSAL_TITLE="Make $NEURON_ID a known neuron (${NEW_NAME})"
PROPOSAL_SUMMARY="agrega aquí el resumen de la propuesta" # Personaliza
PROPOSAL_URL="enlace a la publicación del foro" # Personaliza con la URL que quieras que aparezca en la propuesta, como el enlace a la publicación del foro
dfx canister --network ic call rrkah-fqaaa-aaaaa-aaaaq-cai manage_neuron "( record { id = opt record { id = ${NEURON_ID}: nat64}; command = opt variant { MakeProposal = record { title = opt \"${PROPOSAL_TITLE}\"; url = \"${PROPOSAL_URL}\"; summary = \"${PROPOSAL_SUMMARY}\"; action = opt variant {RegisterKnownNeuron = record {id = opt record { id = ${NEURON_ID}: nat64}; known_neuron_data = opt record {name = \"${NEW_NAME}\"; description = opt \"${NEW_DESCRIPTION}\"}}}}}})"
```

Aquí tienes un ejemplo concreto como referencia:

```
NEURON_ID="12664007384337444895"
NEW_NAME="Testname"
NEW_DESCRIPTION="Me gusta la DAO del NNS"
PROPOSAL_TITLE="Make $NEURON_ID a known neuron (${NEW_NAME})"
PROPOSAL_SUMMARY="Hola a todos. Me gustaría convertirme en una neurona conocida. Encuentra más información sobre mí en la publicación del foro enlazada."
PROPOSAL_URL="https://forum.dfinity.org/link-to-post/3074"
dfx canister --network ic call rrkah-fqaaa-aaaaa-aaaaq-cai manage_neuron "( record { id = opt record { id = ${NEURON_ID}: nat64}; command = opt variant { MakeProposal = record { title = opt \"${PROPOSAL_TITLE}\"; url = \"${PROPOSAL_URL}\"; summary = \"${PROPOSAL_SUMMARY}\"; action = opt variant {RegisterKnownNeuron = record {id = opt record { id = ${NEURON_ID}: nat64}; known_neuron_data = opt record {name = \"${NEW_NAME}\"; description = opt \"${NEW_DESCRIPTION}\"}}}}}})"
```

Después de ejecutar este comando, deberías ver algo como esto:

```
(
  record {
    command = opt variant {
      MakeProposal = record {
        message = opt "The proposal has been created successfully.";
        proposal_id = opt record { id = 129_666 : nat64 };
      }
    };
  },
)
```

Lo que ves después de `id =` es el ID de la propuesta que acabas de enviar, ¡en
la cual ahora otros propietarios de neuronas del NNS pueden votar! Debería
aparecer en el
[panel de control](https://dashboard.internetcomputer.org/governance) en breve.
Si tienes problemas para encontrarla, puedes usar la siguiente URL y reemplazar
el número al final con el ID de la propuesta que acabas de crear (sin los
guiones bajos): https://dashboard.internetcomputer.org/proposal/129666.
