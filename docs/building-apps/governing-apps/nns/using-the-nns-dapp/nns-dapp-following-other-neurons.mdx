Los propietarios de neuronas pueden encontrar difícil votar manualmente en cada
propuesta presentada a la NNS. Por ejemplo, es posible que no tengan el tiempo o
la experiencia necesaria para evaluar cada propuesta individual. La NNS utiliza
una forma de democracia líquida para abordar estos desafíos llamada
**seguimiento**.

Dado que es de interés de cada neurona seguir a otras neuronas que respalden los
mejores intereses de la red y los suyos propios, recomendamos estudiar las
reglas precisas del seguimiento, así como cómo encontrar neuronas para seguir en
[Seguimiento](/docs/building-apps/governing-apps/nns/concepts/neurons/neuron-following).
Para obtener información sobre cómo convertirse en una neurona que puede ser
seguida, consulte
[Registro de una neurona conocida](/docs/building-apps/governing-apps/nns/concepts/neurons/becoming-a-known-neuron).

## Configuración del seguimiento de tus neuronas en la aplicación NNS

Para configurar tu neurona para seguir a un grupo de otras neuronas:

- #### Paso 1: Desde la aplicación NNS, selecciona 'Neuron Staking', luego selecciona la neurona para la cual deseas establecer una regla de seguimiento.

![NNS Neuron following 1](../../_attachments/nns8.png)

- #### Paso 2: En los detalles de la neurona, desplázate hacia abajo hasta la sección 'Seguimiento' y selecciona 'Seguir neuronas'.

![NNS Neuron following 2](../../_attachments/nns13.png)

- #### Paso 3: A continuación, selecciona un tema para seguir.

El tema se refiere a los diferentes tipos de propuestas; por ejemplo, el tema
'Gobernanza' define un rol de seguimiento para propuestas relacionadas con la
gobernanza, mientras que el tema 'Gestión de subredes' define un rol de
seguimiento para propuestas de gestión de subredes. También hay una regla de
'atrapar todo' que se puede seguir para todos los tipos de propuestas excepto
gobernanza, SNS y el fondo de las neuronas.

Para este ejemplo, selecciona 'SNS & Neurons' Fund'.

![NNS Neuron following 3](../../_attachments/nns14.png)

- #### Paso 4: Selecciona 'Agregar seguido'.

![NNS Neuron following 4](../../_attachments/nns15.png)

- #### Paso 5: Ingresa un ID de neurona para seguir, o selecciona un grupo de neuronas del menú proporcionado.

En este ejemplo, selecciona 'DFINITY Foundation'.

![NNS Neuron following 5](../../_attachments/nns16.png)

- #### Paso 6: La ventana ahora reflejará la configuración de seguimiento:

![NNS Neuron following 6](../../_attachments/nns17.png)

La configuración también se mostrará en los detalles de la neurona:

![NNS Neuron following 7](../../_attachments/nns18.png)
