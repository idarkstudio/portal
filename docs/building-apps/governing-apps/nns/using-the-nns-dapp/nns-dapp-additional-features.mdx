# Funcionalidades adicionales

<MarkdownChipRow labels={["Intermedio", "Gobernanza", "Tutorial"]} />

Además de ser el portal para interactuar con el NNS DAO, la aplicación NNS
también proporciona acceso a los DAO de SNS, sus lanzamientos y permite a los
usuarios gestionar los canisters que controlan. Esta es una guía breve sobre
algunas de estas funcionalidades adicionales.

## Intercambios de descentralización de SNS

Puedes participar en intercambios de descentralización de SNS desde la
aplicación NNS utilizando la pestaña 'Launchpad'. Un SNS es una versión avanzada
de una organización autónoma descentralizada, donde los participantes del SNS
pueden votar sobre propuestas, como una nueva característica, un elemento del
roadmap o la asignación de fondos de SNS.

[Aprende más sobre los SNS](https://internetcomputer.org/sns).

Para ver los intercambios de descentralización de SNS actuales y pasados desde
la aplicación NNS:

- #### Paso 1: Desde la aplicación NNS, haz clic en **Launchpad** en la barra de navegación izquierda.

![Launchpad](../../_attachments/nns21.png)

- #### Paso 2: Selecciona cualquier intercambio de SNS para ver los detalles, como el estado, el número total de participantes, el suministro de tokens y cuándo finalizó el intercambio.

![Intercambio de SNS](../../_attachments/nns22.png)

## Desplegar y gestionar canisters desde la aplicación NNS

Debes tener **ciclos** disponibles para crear y gestionar
[canisters](/docs/concepts/glossary#c). La aplicación [NNS](https://nns.ic0.app)
proporciona una forma conveniente de crear y gestionar canisters al permitirte
convertir tokens de utilidad ICP en ciclos y adjuntar ciclos a identificadores
de canisters específicos.

Para crear un nuevo canister:

- #### Paso 1: Desde la aplicación NNS, haz clic en **Canisters**, luego haz clic en **Crear Canister** o **Enlazar Canister**.

![Mis canisters](../../_attachments/nns23.png)

- #### Paso 2: Si seleccionas **Crear Canister**, selecciona la cuenta de origen que deseas utilizar para crear el canister.

![Crear un nuevo canister](../../_attachments/nns24.png)

- #### Paso 3: Luego, ingresa la cantidad de tokens ICP y ciclos para crear el canister. Luego selecciona **Revisar Creación de Canister**.

![Crear un nuevo canister](../../_attachments/nns25.png)

- #### Paso 4: Revisa los detalles de la conversión de tokens de utilidad ICP a ciclos, luego haz clic en **Confirmar** para continuar.

Después de hacer clic en Confirmar, puedes revisar:

- El nuevo identificador del canister.
- El número de ciclos disponibles para que el canister los utilice.
- El principal controlador que actualmente tiene derechos de gestión completos
  para el nuevo canister.

:::info

Para cambiar el principal utilizado como controlador del canister, haz clic en
**Cambiar Controladores**.

Para agregar ciclos al canister, haz clic en **Agregar Ciclos**.

:::

- #### Paso 5: Para enlazar un canister, ingresa el ID del canister, luego selecciona **Confirmar**.

![Enlazar canister](../../_attachments/nns26.png)

- #### Paso 6: Vuelve a la pestaña **Canisters** para ver los canisters que has creado.

Por ejemplo:
