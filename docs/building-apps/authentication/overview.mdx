# Servicios de autenticación

<MarkdownChipRow labels={["Principiante", "Concepto"]} />

Al construir una aplicación que permite a los usuarios tener perfiles o comprar
y vender activos, debes implementar un método de autenticación. Un método de
autenticación permite a los usuarios iniciar sesión en una aplicación
proporcionando alguna forma de credencial o verificación de identidad. Los
métodos de autenticación varían en niveles de seguridad y privacidad de datos.

Para implementar la autenticación en tu dapp, la interfaz de usuario de tu
aplicación frontend debe proporcionar un componente que desencadene un flujo de
autenticación. Luego, la lógica del backend debe implementar código para manejar
la autenticación y devolver una respuesta al servicio frontend.

Un ejemplo simple de este flujo de trabajo es una aplicación básica de '¿Quién
soy yo?' que utiliza Internet Identity para la autenticación. Consulta la
documentación de
[integración con Internet Identity](/docs/building-apps/authentication/integrate-internet-identity)
para obtener más información.

## Métodos de autenticación

Los métodos de autenticación disponibles en ICP incluyen:

- [Internet Identity](/docs/building-apps/authentication/overview): El servicio
  de identidad nativo de ICP que utiliza un par de claves pública/privada
  criptográficas para la autenticación.

- [Correo electrónico y contraseña](https://nfid.one): Autenticación con un
  correo electrónico y contraseña.

- [NFID](https://nfid.one/): Una forma digital de identidad que permite a los
  usuarios utilizar un correo electrónico y contraseña o su cuenta de Google.

- [`ic-auth`](https://github.com/id-daniel-mccoy/ic-auth): Una herramienta
  modular para integrar proveedores de wallets en aplicaciones de ICP. Admite
  Stoic, Plug, Internet Identity y NFID.

- [Wallet Plug](https://docs.plugwallet.ooo/): Una wallet en el navegador para
  administrar todos los activos de ICP, como ciclos, ICP, tokens y NFT.

Las siguientes herramientas permiten autenticarse con dapps de ICP utilizando
direcciones de wallet de otras cadenas y ecosistemas:

- [Iniciar sesión con Bitcoin](https://github.com/AstroxNetwork/ic-siwb): Un
  estándar de autenticación que permite la autenticación basada en wallets de
  Bitcoin para aplicaciones de ICP.

- [Iniciar sesión con Ethereum](https://github.com/kristoferlund/ic-siwe-react-demo-rust):
  Un estándar de autenticación que permite la autenticación basada en wallets de
  Ethereum para aplicaciones de ICP.

- [Iniciar sesión con Solana](https://github.com/kristoferlund/ic-siws): Un
  estándar de autenticación que permite la autenticación basada en wallets de
  Solana para aplicaciones de ICP.

- [Biblioteca MSQ](https://icp.msq.tech/): Una biblioteca de cliente para dapps
  que permite la interacción del usuario con ICP únicamente a través de su
  wallet existente de MetaMask utilizando la función
  [Metamask Snaps](https://metamask.io/snaps/).
