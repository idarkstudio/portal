# Integración con Internet Identity

<MarkdownChipRow labels={["Intermedio", "Tutorial"]} />

Esta guía muestra un ejemplo de cómo integrar la autenticación de Internet
Identity en una aplicación. En este caso, un usuario puede interactuar con la
interfaz de usuario para iniciar sesión con su Internet Identity y luego hacer
una llamada al método `whoami` del canister backend, que devuelve el principal
del usuario.

## Creación de una aplicación sencilla con autenticación de II

### Paso 1: Crear o abrir un proyecto

Primero, usa `dfx start` para iniciar una  
[instancia local de la réplica](/docs/building-apps/developer-tools/dfx/dfx-start)  
(si es necesario) y  
[crear un nuevo proyecto](/docs/building-apps/developer-tools/dfx/dfx-new)  
o abre un proyecto existente.

#### Crear un nuevo proyecto

Al crear un nuevo proyecto con el comando `dfx new`, tendrás la opción de
**Agregar características adicionales**. En este paso, selecciona **Internet
Identity**.

Esta opción añadirá la versión **pullable** del canister de Internet Identity a
tu proyecto. Un canister pullable es un canister que proporciona un servicio
público con un ID de canister estático.  
[Más información sobre los canisters pullables](/docs/building-apps/advanced/using-third-party-canisters).

#### Usar un proyecto existente

Si ya tienes un proyecto que no fue creado con la opción de Internet Identity,
puedes modificarlo para utilizar el canister de Internet Identity pullable.
Primero, agrega la configuración del canister en el archivo `dfx.json` del
proyecto:

```json title="dfx.json"
{
  "canisters": {
    "internet_identity": {
      "candid": "https://github.com/dfinity/internet-identity/releases/latest/download/internet_identity.did",
      "frontend": {},
      "remote": {
        "id": {
          "ic": "rdmx6-jaaaa-aaaaa-aaadq-cai"
        }
      },
      "type": "custom",
      "wasm": "https://github.com/dfinity/internet-identity/releases/latest/download/internet_identity_dev.wasm.gz"
    }
  }
}
```

Luego, despliega el canister localmente:

```bash
dfx deploy
```

:::info  
Este ejemplo utiliza un frontend basado en **Vanilla JS**, el cual puede
seleccionarse al crear un proyecto con `dfx new`. Si usaste otro framework o
plantilla, necesitarás adaptar el código.  
:::

### Paso 2: Crear una función "Who am I?"

Para agregar una función simple "Who am I?", inserta el siguiente código en el
archivo fuente del canister backend:

<Tabs>
<TabItem value="motoko" label="Motoko" default>

```motoko title="src/ii-integration-backend/main.mo"
actor {
  public shared query (msg) func whoami() : async Principal {
    msg.caller
  };
};
```

</TabItem>
<TabItem value="rust" label="Rust">

```rust title="src/ii-integration-backend/main.rs"
#[query]
async fn whoami() -> Principal {
  caller()
}
```

</TabItem>
</Tabs>

Luego, compila el proyecto para que las nuevas declaraciones del backend estén
disponibles en el frontend:

```bash
dfx build
```

En el código del canister frontend, agrega un método a la clase `App` para
llamar a la función del backend:

```js title="src/ii-integration-frontend/src/App.js"
/**
 * Llama a la función del backend y muestra el principal devuelto en pantalla
 */
#handleWhoAmI = async () => {
  const principal = await ii_integration_backend.whoami();
  this.greeting = `Tu principal es: ${principal.toText()}`;
  this.#render();
};
```

Finalmente, actualiza el método `#render` para agregar un botón "Who am I?" y un
listener de clic:

```js title="src/ii-integration-frontend/src/App.js"
#render() {
  let body = html`
    <main>
      <img src="${logo}" alt="DFINITY logo" />
      <br />
      <br />
      <form action="#">
        <label for="name">Ingresa tu nombre: &nbsp;</label>
        <input id="name" alt="Nombre" type="text" />
        <button type="submit">Haz click</button>
      </form>
// highlight-start
      <center>
        <button id="whoami">Who am I?</button>
      </center>
// highlight-end
      <section id="greeting">${this.greeting}</section>
    </main>
  `;
  render(body, document.getElementById('root'));
  document
    .querySelector('form')
    .addEventListener('submit', this.#handleSubmit);
// highlight-start
  document
    .querySelector('#whoami')
    .addEventListener('click', this.#handleWhoAmI);
// highlight-end
}
```

Despliega el proyecto:

```bash
dfx deploy
```

Visualiza la aplicación desplegada en el frontend. Al hacer clic en el botón
"Who am I?", debería devolver el principal anónimo.

```
Your principal is: 2vxsx-fae
```

### Paso 3: Implementar autenticación.

Instala el paquete `npm` requerido:

```bash
npm install @dfinity/auth-client
```

:::caution

Asegúrate de que todas las dependencias **@dfinity/&lt;package&gt;** en
**package.json**  
tengan la misma versión.

:::

Añade un método a la clase `App` para obtener la URL correcta de Internet
Identity:

```js title="src/ii-integration-frontend/src/App.js"
/**
 * Obtiene la URL correcta de Internet Identity según el entorno actual
 */
#identityProvider = () => {
  if (process.env.DFX_NETWORK === "local") {
    return `http://${process.env.CANISTER_ID_INTERNET_IDENTITY}.localhost:4943`;
  } else if (process.env.DFX_NETWORK === "ic") {
    return `https://${process.env.CANISTER_ID_INTERNET_IDENTITY}.ic0.app`;
  } else {
    return `https://${process.env.CANISTER_ID_INTERNET_IDENTITY}.dfinity.network`;
  }
};
```

:::info

Si estás desarrollando con el navegador Safari, debes cambiar el valor  
devuelto para el entorno de desarrollo local a  
`http://localhost:4943?canisterId=<canister_id>`.

:::

Añade un método para crear una instancia de `AuthClient`, luego llámalo en el
constructor de la clase `App`:

```js title="src/ii-integration-frontend/src/App.js"
constructor() {
  this.#render();
  await this.#createAuthClient();
}

/**
 * Reemplaza la identidad del backend actor con la identidad de AuthClient,
 * además, vuelve a renderizar para mostrar el estado de autenticación actualizado
 */
#onIdentityUpdate = async () => {
  Actor.agentOf(ii_integration_backend).replaceIdentity(this.authClient.getIdentity());
  this.isAuthenticated = await this.authClient.isAuthenticated();
  this.#render();
}

/**
 * Crea AuthClient, cargando una sesión existente si está disponible
 */
#createAuthClient = async () => {
  this.authClient = await AuthClient.create();
  await this.#onIdentityUpdate();
}
```

Añade métodos a la clase `App` para facilitar el inicio y cierre de sesión:

```js title="src/ii-integration-frontend/src/App.js"
/**
 * Iniciar sesión con AuthClient, esto debe llamarse sin demora en un controlador de clics
 */
#handleLogin = async () => {
  await new Promise((resolve, reject) => this.authClient.login({
    identityProvider: this.#identityProvider(),
    onSuccess: resolve,
    onError: reject
  }));
  await this.#onIdentityUpdate();
}

/**
 * Cerrar sesión con AuthClient
 */
#handleLogout = async () => {
  await this.authClient.logout();
  await this.#onIdentityUpdate();
}
```

:::warning

Asegúrate de crear siempre una única instancia de `AuthClient` al cargar la
página y  
reutilizarla dentro de tus controladores de clics, como se muestra en los pasos
anteriores y actuales.

:::

Por último, actualiza el método `#render` para añadir los nuevos botones "Login"
y "Logout"  
y sus respectivos controladores de eventos:

```js title="src/ii-integration-frontend/src/App.js"
#render() {
  let body = html`
    <main>
      <img src="${logo}" alt="DFINITY logo" />
      <br />
      <br />
      <form action="#">
        <label for="name">Ingresa tu nombre: &nbsp;</label>
        <input id="name" alt="Name" type="text" />
        <button type="submit">Click Me!</button>
      </form>
      <center>
// highlight-start
        ${this.isAuthenticated
          ? html`<button id="logout">Logout</button>`
          : html`<button id="login">Login</button>`}
// highlight-end
        <button id="whoami">Who am I?</button>
      </center>
      <section id="greeting">${this.greeting}</section>
    </main>
  `;
  render(body, document.getElementById('root'));
  document
    .querySelector('form')
    .addEventListener('submit', this.#handleSubmit);
  document
    .querySelector('#whoami')
    .addEventListener('click', this.#handleWhoAmI);
// highlight-start
  document
    .querySelector('#login')
    ?.addEventListener('click', this.#handleLogin);
  document
    .querySelector('#logout')
    ?.addEventListener('click', this.#handleLogout);
// highlight-end
}
```

Despliega la aplicación actualizada:

```bash
dfx deploy
```

Haz clic en el botón "Login". Serás redirigido a la interfaz de Internet
Identity.  
Como estás ejecutando esto localmente, usarás una instancia local y no de
producción de Internet Identity.  
Para crear una, sigue los pasos en pantalla.

Haz clic en el botón "Who am I?" y debería devolver tu principal de Internet
Identity:

```
Your principal is: 5uylz-j7fcd-isj73-gp57f-xwwyy-po2ib-7iboa-fdkdv-nrsam-3bd3r-qqe
```

:::info

El principal anterior es solo un ejemplo. El principal devuelto será diferente  
según la cuenta y el entorno donde la aplicación e Internet Identity estén
ejecutándose.

:::

## Desarrollo de frontend local

Al modificar el frontend de este ejemplo, se recomienda desarrollar utilizando
un servidor de desarrollo local en lugar de usar el canister de frontend
desplegado. Esto se debe a que el uso de un servidor de desarrollo local
permitirá Hot Module Reloading, lo que te permitirá ver instantáneamente
cualquier modificación realizada en tu frontend, sin necesidad de volver a
desplegar el canister de frontend para ver los cambios.

Para iniciar un servidor de desarrollo local, ejecuta `npm run start`. La salida
mostrará la dirección local en la que se está ejecutando el proyecto, como
`127.0.0.1:4943`.

## Pruebas end-to-end

Para ejecutar pruebas end-to-end en integraciones con Internet Identity, puedes
usar el
[plugin Internet Identity Playwright](https://github.com/dfinity/internet-identity-playwright).

Para usar este plugin, primero instala [Playwright](https://playwright.dev/),
luego instala el propio plugin con un gestor de paquetes:

```

# Instalar con npm

npm install --save-dev @dfinity/internet-identity-playwright

# Instalar con pnpm

pnpm add --save-dev @dfinity/internet-identity-playwright

# Instalar con yarn

yarn add -D @dfinity/internet-identity-playwright

```

Importa el plugin en tu archivo de prueba de Playwright:

```typescript title="e2e/login.spec.ts"
import { testWithII } from "@dfinity/internet-identity-playwright";
```

Luego, comienza a escribir tus pruebas, como:

```typescript title="e2e/login.spec.ts"
testWithII("should sign-in with a new user", async ({ page, iiPage }) => {
  await page.goto("/");

  await iiPage.signInWithNewIdentity();
});

testWithII(
  "should sign-in with an existing new user",
  async ({ page, iiPage }) => {
    await page.goto("/");

    await iiPage.signInWithIdentity({ identity: 10003 });
  }
);
```

En esta prueba, `iiPage` representa la página de tu aplicación que inicia el
flujo de autenticación con Internet Identity. Por defecto, la prueba buscará un
botón identificado por `[data-tid=login-button]`. Esto se puede personalizar
configurando tu propio selector:

```typescript title="e2e/login.spec.ts"
const loginSelector = "#login";

testWithII("should sign-in with a new user", async ({ page, iiPage }) => {
  await page.goto("/");

  await iiPage.signInWithNewIdentity({ selector: loginSelector });
});

testWithII(
  "should sign-in with an existing new user",
  async ({ page, iiPage }) => {
    await page.goto("/");

    await iiPage.signInWithIdentity({
      identity: 10003,
      selector: loginSelector,
    });
  }
);
```

Si lo deseas, puedes hacer que la prueba espere a que Internet Identity esté
listo proporcionando la URL de la réplica local y el canister ID de tu instancia
local de Internet Identity:

```typescript title="e2e/login.spec.ts"
testWithII.beforeEach(async ({ iiPage, browser }) => {
  const url = "http://127.0.0.1:4943";
  const canisterId = "rdmx6-jaaaa-aaaaa-aaadq-cai";

  await iiPage.waitReady({ url, canisterId });
});
```

También puedes configurar un parámetro de tiempo de espera que indique cuánto
tiempo debe esperar la función antes de que falle la prueba:

```typescript title="e2e/login.spec.ts"
testWithII.beforeEach(async ({ iiPage, browser }) => {
  const url = "http://127.0.0.1:4943";
  const canisterId = "rdmx6-jaaaa-aaaaa-aaadq-cai";
  const timeout = 30000;

  await iiPage.waitReady({ url, canisterId, timeout });
});
```

Una vez que tus pruebas estén listas, ejecútalas con el siguiente comando:

```
npx playwright test
```

[Ver más detalles en el repositorio del plugin](https://github.com/dfinity/internet-identity-playwright).
