# Hora del sistema y marcas de tiempo

<MarkdownChipRow labels={["Principiante", "Concepto"]} />

La hora del sistema es una parte públicamente expuesta y verificada del  
[árbol de estado del IC](/docs/references/ic-interface-spec#state-tree).  
La hora del sistema se expresa en nanosegundos desde `1970-01-01` e indica el
momento en que  
el estado está actualizado. Se expone en `/time`, y todos los árboles de estado
parciales incluyen  
una marca de tiempo.

La hora del sistema observada por el

<GlossaryTooltip>canister</GlossaryTooltip>
aumenta de manera monótona, incluso a través de actualizaciones del canister. Dado
que la red ICP es descentralizada, las horas del sistema de diferentes canisters
son independientes, y no hay un concepto de zona horaria, lo que a veces da lugar
a que las llamadas parezcan viajar en el tiempo hacia atrás.

La hora del sistema, expresada en nanosegundos, puede requerir conversión a
diferentes formatos,  
como `DateTime`. Esta guía detallará algunas de las conversiones más utilizadas.

## Obtener la hora del sistema

Tu canister puede obtener la hora del sistema de forma programática para usarla
dentro  
de tu aplicación.

## Paquetes de conversión

Para canisters en Motoko:

- [`time` paquete de Mops](https://mops.one/time): Admite funciones para
  convertir  
  la hora del sistema en microsegundos, milisegundos, formato de fecha en texto
  y más.

- [`dateTime` paquete de Mops](https://mops.one/datetime): Admite funciones para
  convertir  
  la hora del sistema en formato UTC, zona horaria local y zonas horarias fijas.

Para canisters en Rust:

- [`time`](https://time-rs.github.io/api/time/index.html)

- [`datetimeutils`](https://crates.io/crates/datetimeutils)

## Convertir marcas de tiempo Unix a formato `DateTime`

El formato en nanosegundos en el que se devuelve la hora del sistema utiliza el
formato  
de marca de tiempo Unix, que es simplemente el número total de nanosegundos,  
por ejemplo, `1721402551`.

El formato `DateTime` usa la estructura `YYYY-MM-DD HH:MM:SS`.

A continuación se muestran ejemplos de cómo convertir marcas de tiempo Unix a
formato `DateTime`.

<AdornedTabs groupId="language">
<TabItem value="motoko" label="Motoko">

```motoko no-repl
import Time "mo:time/time";
import DateTime "mo:datetime/DateTime";
import Debug "mo:base/Debug";

actor {
    let now = Time.now();
    let dateTime = DateTime.DateTime(now);

    Debug.print(dateTime.toText());
};
```

</TabItem>

<TabItem value="rust" label="Rust">

```rust
use crate::types::utils::CalendarDate;
use time::{Duration, OffsetDateTime};

pub fn calendar_date(timestamp: &u64) -> CalendarDate {
    CalendarDate::from(&to_date(timestamp).to_calendar_date())
}
```

También puedes convertir la hora Unix a un formato `OffsetDateTime`:

```rust
use crate::types::utils::CalendarDate;
use time::{Duration, OffsetDateTime};

fn to_date(timestamp: &u64) -> OffsetDateTime {
    let nanoseconds = *timestamp as i64;
    let seconds = nanoseconds / 1_000_000_000;
    let nanos_remainder = nanoseconds % 1_000_000_000;

    OffsetDateTime::from_unix_timestamp(seconds).unwrap() + Duration::nanoseconds(nanos_remainder)
}
```

</TabItem>
</AdornedTabs>

## Calcular el tiempo entre dos marcas de tiempo

Para algunas aplicaciones, puede ser útil calcular el tiempo transcurrido  
entre dos marcas de tiempo. A continuación se muestra un ejemplo de canister  
escrito en Motoko que demuestra cómo usar
[temporizadores](periodic-tasks-timers.mdx)  
para generar dos marcas de tiempo y luego crear una función que pueda calcular
la diferencia:

```motoko no-repl
import Debug "mo:base/Debug";
import { setTimer; recurringTimer } = "mo:base/Timer";
import Time "mo:time/time";
import DateTime "mo:datetime/DateTime";
import Int "mo:base/Int";

actor Alarm {

  let N1 = 10;
  let N2 = 13;

  var now1 = Time.now();
  var now2 = Time.now();

  private func time1() : async () {
    var now1 = Time.now();
    Debug.print(debug_show(now1));
  };

  private func time2() : async () {
    var now2 = Time.now();
    Debug.print(debug_show(now2));
  };

  ignore setTimer<system>(#seconds N1,
    func () : async () {
      ignore recurringTimer<system>(#seconds N1, time1);
      var now1 = Time.now();
  });

  ignore setTimer<system>(#seconds N1,
    func () : async () {
      ignore recurringTimer<system>(#seconds N2, time2);
      var now2 = Time.now();
  });

  public query func calculate(now1 : Int, now2 : Int) : async Int {
    return (now2 - now1);
  };
}
```

Este canister despliega dos temporizadores recurrentes: uno cada 10 segundos  
y otro cada 13 segundos. Puedes modificar estos valores según los
requerimientos  
de tu aplicación.

Una vez desplegado, las marcas de tiempo de cada temporizador se imprimirán en
la terminal:

```
2024-07-19 20:55:43.012377 UTC: [Canister bd3sg-teaaa-aaaaa-qaaba-cai] +1_721_422_543_012_377_000
2024-07-19 20:55:45.633980 UTC: [Canister bd3sg-teaaa-aaaaa-qaaba-cai] +1_721_422_545_633_980_000
```

Luego, llama al método `calculate` del canister y pasa estas dos marcas de
tiempo:

```
dfx canister call test23_backend calculate
```

Ingresa las dos marcas de tiempo en nanosegundos:

```
1_721_422_543_012_377_000
1_721_422_545_633_980_000
```

La diferencia entre ambas, en nanosegundos, será devuelta:

```
(2_621_603_000 : int)
```
