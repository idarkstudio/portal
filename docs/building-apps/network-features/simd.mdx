# WebAssembly SIMD

<MarkdownChipRow labels={["Avanzado", "Concepto"]} />

ICP admite WebAssembly SIMD de forma determinista. Esto representa un hito
importante  
para los contratos inteligentes que requieren el máximo rendimiento en la
cadena,  
como inteligencia artificial (IA), procesamiento de imágenes (NFTs), juegos,  
aplicaciones descentralizadas científicas (dapps) y más.

Sin embargo, también es posible lograr una mejora significativa en el
rendimiento  
de operaciones "clásicas" de blockchain implementadas en canisters. Por
ejemplo,  
la distribución de recompensas o las operaciones criptográficas podrían
beneficiarse  
de las nuevas instrucciones SIMD de WebAssembly.

### ¿Qué es WebAssembly SIMD?

WebAssembly SIMD (instrucción única, múltiples datos) es un conjunto de más de
200  
instrucciones vectoriales deterministas definidas en la  
[especificación central de WebAssembly](https://webassembly.github.io/spec/core/syntax/instructions.html#vector-instructions).  
Este procesamiento en paralelo acelera significativamente tareas específicas
dentro  
de los canisters que se ejecutan en ICP.

La funcionalidad SIMD está disponible en cada nodo de ICP.

### Beneficios para desarrolladores

La compatibilidad con WebAssembly SIMD permite un nuevo nivel de rendimiento en
ICP.  
Los desarrolladores pueden:

- **Optimizar el código para tareas computacionalmente exigentes:** Identificar
  áreas  
  dentro de sus canisters que pueden beneficiarse de las instrucciones SIMD y
  adaptar  
  su código para un mejor rendimiento.
- **Desbloquear nuevas posibilidades:** Explorar funcionalidades novedosas y
  aplicaciones  
  complejas que antes estaban limitadas por la potencia de procesamiento.
- **Construir una base preparada para el futuro:** Posicionarse a la vanguardia
  de la  
  innovación en blockchain.

## Uso de WebAssembly SIMD

Existen dos formas principales de aprovechar WebAssembly SIMD en un contrato
inteligente:

1. **Auto-vectorización de bucles:** Solo habilitar WebAssembly SIMD y
   recompilar el proyecto  
   puede ser suficiente para obtener un aumento significativo en el
   rendimiento.  
   Esto suele ser simple, sin errores y puede requerir solo un cambio de una
   línea.  
   A menudo es el primer paso recomendado, pero el resultado depende en gran
   medida de  
   los algoritmos utilizados, las bibliotecas y los compiladores.

2. **Intrínsecos SIMD:** Algunas funciones con alta carga computacional pueden
   reescribirse  
   utilizando instrucciones SIMD directas. Esto expone todo el potencial de
   SIMD, pero en  
   muchos casos, algunos algoritmos principales del canister deben reescribirse
   por  
   completo usando nuevas instrucciones.

## Uso de la auto-vectorización de bucles

Para aprovechar la auto-vectorización de bucles, las instrucciones SIMD de
WebAssembly  
deben habilitarse globalmente para todo el espacio de trabajo o localmente para
funciones  
específicas dentro del canister. Una vez que las instrucciones están disponibles
para el  
compilador, este convierte automáticamente algunos bucles normales en bucles con
cálculos  
paralelos.

Si bien el cambio es fácil y libre de errores, el resultado en la práctica
depende de  
muchos factores, como el propio algoritmo, el nivel de optimización del
compilador y  
sus opciones, las dependencias del proyecto, etc.

### Ejemplo

Para habilitar las instrucciones SIMD de WebAssembly globalmente para todo el
espacio de trabajo  
y todas sus dependencias:

## Uso de intrínsecos SIMD de WebAssembly

Las instrucciones SIMD de WebAssembly están disponibles como intrínsecos
específicos  
de la plataforma `wasm32`. Para utilizar los intrínsecos, las instrucciones
SIMD  
deben habilitarse como se describió en la sección anterior.

## Preguntas frecuentes

### ¿Cómo medir la mejora de rendimiento de un canister?

ICP proporciona la llamada `ic0.performance_counter`  
[API del sistema](/docs/references/ic-interface-spec#system-api-performance-counter)  
para medir el rendimiento de un canister.

También existe el marco de referencia de pruebas `canbench`  
[benchmarking framework](https://github.com/dfinity/canbench).

### ¿Existen bibliotecas para inferencias de inteligencia artificial (IA)?

La biblioteca `tract` de Sonos es una pequeña y autónoma biblioteca de
inferencia  
de TensorFlow y ONNX en [Rust](https://github.com/sonos/tract). DFINITY  
[contribuyó con soporte para WebAssembly SIMD](https://github.com/sonos/tract/pull/1420)  
a la biblioteca. Esta biblioteca se usa en algunas demostraciones de IA de
DFINITY  
[demos](https://www.youtube.com/watch?v=6qLvIXiCGcM) y  
[ejemplos](https://github.com/dfinity/examples/tree/master/rust/image-classification).
