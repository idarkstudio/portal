# Ejemplo de vetKeys

<MarkdownChipRow labels={["Avanzado", "Encriptación"]} />

Este ejemplo proporciona un canister (`src/chainkey_testing_canister`) que
demuestra cómo la
[API del sistema vetKD propuesta](https://github.com/dfinity/portal/pull/3763)
puede utilizarse para encriptar, transferir y desencriptar un archivo enviado a
una dirección de Ethereum.

El
[repositorio de GitHub para este ejemplo](https://github.com/kristoferlund/send_file_to_eth_demo)
es una plantilla pública, y hay una demostración en vivo disponible:
https://h62xu-2iaaa-aaaal-qshoq-cai.icp0.io/

Utiliza [`ic-siwe`](https://github.com/kristoferlund/ic-siwe) y
[`ic-siwe-js`](https://www.npmjs.com/package/ic-siwe-js) para facilitar el
inicio de sesión con Ethereum, el envío de un archivo a una dirección de
Ethereum y el uso de la dirección del destinatario para identificar el
[esquema IBE](/docs/references/vetkeys-overview) utilizado para generar una
clave pública para el destinatario.

Otros ejemplos disponibles son:

- [Aplicación de encriptación en Rust](https://github.com/dfinity/examples/tree/master/rust/vetkd).
- [Dapp de notas encriptadas](https://github.com/dfinity/examples/tree/master/motoko/encrypted-notes-dapp-vetkd).

## Encriptar y almacenar un archivo

### Paso 1: Obtener la clave pública del destinatario

Primero, identifica la dirección de Ethereum del destinatario al que deseas
enviar un archivo. Luego, define un método `vetkd_public_key` que recuperará la
clave pública del destinatario utilizando su dirección de Ethereum para
identificar el esquema IBE que genera la clave pública. Este método llamará al
`chainkey_testing_canister`:

```rust reference
https://github.com/kristoferlund/send_file_to_eth_demo/blob/main/src/backend/src/vetkd/controller/vetkd_public_key.rs#L1-L23
```

:::info

Este ejemplo usa un canister de prueba local de vetKeys. Cuando la funcionalidad
esté disponible, esto debe reemplazarse con la API oficial de vetKeys.

:::

### Paso 2: Encriptar un archivo en el frontend

A continuación, define una solicitud en el frontend de la aplicación que utilice
la clave pública del destinatario y el método `vetkd.IBECiphertext.encrypt` del
paquete `ic-vetkd-utils`. Esta solicitud tomará el archivo subido por el usuario
y lo encriptará.

```typescript reference
https://github.com/kristoferlund/send_file_to_eth_demo/blob/main/src/frontend/src/transfer/hooks/useTransferCreate.tsx#L1-L46
```

### Paso 3: Almacenar el archivo encriptado en el backend

En el canister del backend, crea un método `transfer_create` que verifique los
parámetros `from` y `to` de la solicitud del frontend y luego almacene el
archivo encriptado:

```rust reference
https://github.com/kristoferlund/send_file_to_eth_demo/blob/main/src/backend/src/transfer/controller/transfer_create.rs#L1-L35
```

## Recibir y desencriptar un archivo

### Paso 1: Obtener una lista de transferencias de archivos encriptados disponibles

El archivo ahora ha sido encriptado con la dirección de Ethereum del
destinatario y su clave privada correspondiente. Para que el destinatario reciba
el archivo, debe iniciar sesión en la aplicación con su dirección de Ethereum.
El frontend llamará al método `transfer_list` del backend y recibirá las
transferencias de archivos existentes en la aplicación.

```rust reference
https://github.com/kristoferlund/send_file_to_eth_demo/blob/main/src/backend/src/transfer/controller/transfer_list.rs#L1-L15
```

### Paso 2: Obtener la clave privada del destinatario

Luego, el backend obtiene la clave privada encriptada de la dirección de
Ethereum del usuario de manera similar a como obtuvo la clave pública para
encriptar el archivo:

```rust reference
https://github.com/kristoferlund/send_file_to_eth_demo/blob/main/src/backend/src/vetkd/controller/vetkd_encrypted_key.rs#L1-L31
```

### Paso 3: Desencriptar la clave privada y el archivo

Finalmente, el frontend desencripta la clave privada, la usa para desencriptar
el archivo y lo devuelve al usuario:

```typescript reference
https://github.com/kristoferlund/send_file_to_eth_demo/blob/main/src/frontend/src/transfer/hooks/useTransferGet.tsx#L1-L46
```
