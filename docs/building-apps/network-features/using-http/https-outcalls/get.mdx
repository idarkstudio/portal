# HTTPS outcalls: GET

<MarkdownChipRow labels={["Avanzado", "Network feature"]} />

Un ejemplo mínimo para hacer una solicitud HTTP `GET`. El propósito de esta dapp
es solo para mostrar cómo hacer solicitudes HTTP desde un canister. Envía una
solicitud `GET` a la API de Coinbase y recupera algunos datos históricos sobre
el token ICP.

## Ejemplo `GET`

<AdornedTabs groupId="languages">
<TabItem value="motoko" label="Motoko" default>

```motoko no-repl file=../../../../references/samples/motoko/send_http_get/src/send_http_get_backend/main.mo

```

- `get_icp_usd_exchange()` es una llamada de actualización. Todos los métodos
  que hacen HTTPS outcalls deben ser llamadas de actualización porque pasan por
  consenso, incluso si el HTTPS outcall es un `GET`.
- El código anterior agrega `20_949_972_000` ciclos. Esto suele ser suficiente
  para solicitudes `GET`, pero esto puede necesitar cambiar dependiendo de tu
  caso de uso.
- El código anterior importa `Types.mo` para separar los tipos personalizados
  del archivo actor (como una mejor práctica).

</TabItem>
<TabItem value="rust" label="Rust">

```rust file=../../../../references/samples/rust/send_http_get/src/send_http_get_backend/src/lib.rs

```

- `get_icp_usd_exchange() -> String` devuelve una `String`, pero esto no es
  necesario. En este tutorial, esto se hace para facilitar las pruebas.
- El archivo `lib.rs` usa
  [http_request](https://docs.rs/ic-cdk/latest/ic_cdk/api/management_canister/http_request/fn.http_request.html),
  que es un método conveniente de Rust CDK que ya envía ciclos al canister de
  gestión bajo el capó. Sabe cuántos ciclos enviar para un subred de 13 nodos en
  la mayoría de los casos. Si tu HTTPS outcall necesita más ciclos, debes usar
  el método
  [http_request_with_cycles()](https://docs.rs/ic-cdk/latest/ic_cdk/api/management_canister/http_request/fn.http_request_with_cycles.html)
  y llamar explícitamente los ciclos necesarios.
- El método `http_request` de Rust CDK utilizado arriba envuelve el método del
  canister de gestión
  [`http_request`](/docs/references/ic-interface-spec#ic-http_request), pero no
  es estrictamente el mismo.

Para usar HTTPS outcalls, debes actualizar el archivo Candid del canister:

```candid file=../../../../references/samples/rust/send_http_get/src/send_http_get_backend/send_http_get_backend.did

```

Actualiza el archivo `Cargo.toml` para usar las dependencias correctas:

```toml file=../../../../references/samples/rust/send_http_get/src/send_http_get_backend/Cargo.toml

```

Los encabezados en la respuesta pueden no ser siempre idénticos en todos los
nodos que procesan la solicitud para el consenso, lo que provoca que el
resultado de la llamada sea "No se pudo alcanzar consenso". Este mensaje de
error en particular puede ser difícil de depurar, pero un método para resolver
este error es editar la respuesta usando la función transform. La función
transform se ejecuta antes del consenso y se puede utilizar para eliminar
algunos encabezados de la respuesta.
