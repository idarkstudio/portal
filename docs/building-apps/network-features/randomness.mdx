# Aleatoriedad Onchain

<MarkdownChipRow labels={["Avanzado", "Concepto"]} />

El Internet Computer proporciona una forma segura y verificable de generar
números aleatorios directamente dentro de los canisters. Esta funcionalidad se
expone a través del método [raw_rand](/docs/references/ic-interface-spec),
ofrecido por el
[management canister](/docs/references/system-canisters/management-canister) y
el [módulo Random de Motoko](/docs/motoko/main/base/Random).

El método no requiere entrada y devuelve 32 bytes pseudoaleatorios al llamador.

## Cómo funciona

En segundo plano, ICP utiliza una Verifiable Random Function (VRF) para generar
aleatoriedad.

Durante cada ronda, la VRF se evalúa utilizando como entrada el número de la
ronda actual. Este proceso produce un nuevo conjunto de bytes aleatorios.

Estos bytes se convierten en la semilla de un generador de números
pseudoaleatorios (PRNG) llamado random tape. El random tape se construye
utilizando
[criptografía de clave de cadena (_chain-key cryptography_)](https://internetcomputer.org/how-it-works/chain-key-technology)
y se usa para crear valores aleatorios únicos para cada canister que solicitó
aleatoriedad en la ronda anterior.

Las llamadas a `raw_rand` solo utilizan el random tape de la siguiente ronda.
Esto garantiza que nadie pueda explotar el conocimiento de la aleatoriedad de la
ronda actual para predecir salidas futuras. Para obtener más información sobre
la capa de ejecución de ICP, consulta la
[documentación de la capa de ejecución](https://internetcomputer.org/how-it-works/execution-layer/).

Para conocer más detalles técnicos sobre la aleatoriedad en ICP, mira el
[video de Community Conversations sobre aleatoriedad](https://www.youtube.com/watch?v=nl5BuiWClD0).

## Cómo usarlo

Los desarrolladores pueden acceder directamente a la aleatoriedad a través del
método `raw_rand` en el management canister. Consulta los ejemplos a
continuación.

<AdornedTabs groupId="language">
<TabItem value="motoko" label="Motoko" default>

```motoko
import IC "ic:aaaaa-aa";

actor {
  public func random_bytes() : async Blob {
    await IC.raw_rand();
  };
};
```

Además del método `raw_rand`, Motoko ofrece un
[módulo Random](/docs/motoko/main/base/Random) para generar números aleatorios.

</TabItem>

<TabItem value="rust" label="Rust">

```rust
let (randomBytes,): (Vec<u8>,) = ic_cdk::api::management_canister::main::raw_rand().await?;
```
