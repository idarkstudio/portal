# Generando una dirección de Bitcoin

<MarkdownChipRow labels={["Avanzado", "Bitcoin"]} />

Para que un canister pueda recibir pagos en Bitcoin, debe generar una dirección
de Bitcoin.  
A diferencia de la mayoría de las otras blockchains, Bitcoin no utiliza cuentas.
En su lugar,  
usa un modelo UTXO. Un UTXO es una salida de transacción no gastada, y una
transacción de  
Bitcoin gasta uno o más UTXOs y crea nuevos UTXOs. Cada UTXO está asociado con
una dirección  
de Bitcoin, que se deriva de una clave pública o de un script que define las
condiciones  
bajo las cuales el UTXO puede ser gastado. Una dirección de Bitcoin se usa a
menudo como  
una factura de un solo uso en lugar de una dirección persistente para aumentar
la privacidad.

## Direcciones legacy de Bitcoin

Estas direcciones comienzan con un `1` y se llaman `P2PKH` (Pay to Public Key
Hash).  
Codifican el hash de una clave pública ECDSA.

También existe otro tipo de dirección legacy que comienza con un `3`, llamada
`P2SH` (Pay to Script Hash),  
que codifica el hash de un [script](https://en.bitcoin.it/wiki/Script).  
El script puede definir condiciones complejas como multisig o timelocks.

## Direcciones SegWit de Bitcoin

Las direcciones SegWit son más recientes y siguen el formato  
[`Bech32`](https://github.com/bitcoin/bips/blob/master/bip-0173.mediawiki),  
comenzando con `bc1`. Son más baratas de gastar que las direcciones legacy  
y resuelven problemas relacionados con la maleabilidad de transacciones,  
lo cual es importante para casos de uso avanzados como  
Partially Signed Bitcoin Transactions (PSBT) o la Lightning Network.

Las direcciones SegWit pueden ser de tres tipos:

- `P2WPKH` (Pay to witness public key hash): Una dirección SegWit que codifica  
  el hash de una clave pública ECDSA.
- `P2WSH` (Pay to witness script hash): Una dirección SegWit que codifica el
  hash  
  de un script.
- `P2TR` (Pay to taproot): Una dirección SegWit que puede ser desbloqueada  
  por una firma Schnorr o un script.

## Generando direcciones con threshold ECDSA

Como se mencionó anteriormente, una dirección de Bitcoin se deriva de una clave
pública o un script.  
Para generar una dirección de Bitcoin que solo pueda ser gastada por un canister
específico  
o un llamador específico de un canister, necesitas derivar la dirección de la
clave pública del canister.

Una clave pública ECDSA se puede obtener utilizando la API  
[`ecdsa_public_key`](/docs/references/ic-interface-spec#ic-ecdsa_public_key).  
El
[ejemplo básico de Bitcoin](https://github.com/dfinity/examples/tree/master/motoko/basic_bitcoin)  
demuestra cómo generar una dirección `P2PKH` a partir de la clave pública de un
canister.
