# Ordinals

<MarkdownChipRow labels={["Avanzado", "Bitcoin", "Tutorial"]} />

En Bitcoin, el término 'satoshi' se refiere a la unidad más pequeña de BTC,
equivalente a 100 millonésimas de 1 bitcoin.  
La [teoría Ordinal](https://docs.ordinals.com/digital-artifacts.html), o
simplemente 'Ordinals', es un esquema de numeración utilizado para rastrear y
transferir satoshis individuales. El término 'Ordinal' proviene del hecho de que
cada satoshi se numera según el orden en que ha sido minado y el orden en que se
transfiere, basado en las entradas y salidas de las transacciones.

Los activos digitales, como tokens, cuentas o NFTs, pueden adjuntarse a un
satoshi utilizando su número Ordinal como identificador único. La vinculación de
un activo a un Ordinal se realiza mediante un proceso llamado "inscripción"
(inscribing) y se logra enviando una transacción a la red de Bitcoin que
contiene el satoshi a inscribir junto con los datos del activo. Una vez que la
transacción se agrega a la red, el satoshi se convierte en un artefacto digital
inmutable, a menudo denominado "Ordinal inscrito" o simplemente "inscripción".  
Las inscripciones pueden ser rastreadas, compradas, vendidas, intercambiadas,
transferidas o coleccionadas.

Los Ordinals están disponibles a través de un proyecto de código abierto en  
[GitHub](https://github.com/ordinals/ord), que incluye los componentes
necesarios para facilitar el rastreo, las transacciones y la inscripción de
Ordinals con artefactos digitales. El documento  
[Ordinal BIP](https://github.com/ordinals/ord/blob/master/bip.mediawiki)
proporciona más detalles técnicos.

## Ordinals en ICP

Los canisters desplegados en ICP pueden firmar y enviar transacciones
directamente a la red de Bitcoin a través de la
[integración de Bitcoin de ICP](../overview.mdx) y  
[firmas umbral](/docs/references/t-sigs-how-it-works).

Para que un canister pueda inscribir Ordinals, debe firmar transacciones
utilizando  
[firmas Schnorr umbral](/docs/references/t-sigs-how-it-works#deuterium-schnorr-release-beta)  
y contar con una  
[dirección taproot de Bitcoin](/docs/building-apps/chain-fusion/bitcoin/using-btc/generate-addresses#generating-addresses-with-threshold-schnorr).

## Inscribir un Ordinal

Para inscribir un Ordinal a través de un canister en ICP, primero debes llamar a
la API `schnorr_public_key` para obtener una clave pública Schnorr. Esta clave
pública se usará para generar una dirección taproot (P2TR) de Bitcoin para tu
canister.  
Una dirección taproot es necesaria para firmar y enviar transacciones de
inscripción de Ordinals en Bitcoin.

[Más información sobre direcciones taproot de Bitcoin](/docs/building-apps/chain-fusion/bitcoin/using-btc/generate-addresses#generating-addresses-with-threshold-schnorr).

Una vez que hayas generado una dirección taproot para tu canister, debes
escribir un método en tu canister que cree una transacción de inscripción y la
firme con la clave pública Schnorr de tu canister.

Aquí tienes un ejemplo de una transacción de inscripción escrita en Rust:
