# Enviar transacciones

<MarkdownChipRow labels={["Avanzado", "Bitcoin", "Tutorial"]} />

Para enviar transacciones a la red de Bitcoin, la API de integración de Bitcoin
expone el método `bitcoin_send_transaction`.

:::info

Para probar canisters localmente que utilicen los siguientes fragmentos de
código, es necesario habilitar el desarrollo local de Bitcoin. Para hacerlo,
puedes iniciar la réplica local con `dfx start --enable-bitcoin` o incluir la
siguiente configuración en el archivo `dfx.json` del proyecto:

```json reference
https://github.com/dfinity/examples/blob/master/motoko/basic_bitcoin/dfx.json#L9-L16
```

[Más información sobre las opciones de configuración de `dfx.json`](https://internetcomputer.org/docs/building-apps/developer-tools/dfx-json-reference).

:::
