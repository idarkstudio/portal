# Creando transacciones de Bitcoin

<MarkdownChipRow labels={["Avanzado", "Bitcoin"]} />

Una transacción de Bitcoin gasta una cantidad de salidas de transacción no
gastadas (UTXOs) y crea nuevas UTXOs. Para crear una transacción de Bitcoin,
debes:

1. Obtener los UTXOs disponibles correspondientes a una dirección de Bitcoin
   controlada por el canister utilizando el endpoint `bitcoin_get_utxos` de la
   API.
2. Calcular una tarifa de transacción adecuada usando el endpoint
   `bitcoin_get_current_fee_percentiles` de la API.
3. Seleccionar un subconjunto de los UTXOs disponibles que cubran el monto de la
   transacción y la tarifa.
4. Crear una transacción que gaste los UTXOs seleccionados y cree nuevos UTXOs.
   Al menos uno para el destinatario y, en la mayoría de los casos, uno para
   recolectar el cambio.

Un UTXO tiene la siguiente estructura:

<Tabs groupId="language">
<TabItem value="motoko" label="Motoko" default>

```motoko no-repl

/// Una salida de transacción no gastada.
public type Utxo = {
    outpoint : OutPoint;
    value : Satoshi;
    height : Nat32;
};

/// Una referencia a una salida de transacción.
public type OutPoint = {
    txid : Blob;
    vout : Nat32;
};

```

</TabItem>
<TabItem value="rust" label="Rust">

```rust

/// Salida de transacción no gastada (UTXO).
pub struct Utxo {
    /// Ver [Outpoint].
    pub outpoint: Outpoint,
    /// Valor en satoshis.
    pub value: Satoshi,
    /// Altura en la cadena de bloques.
    pub height: u32,
}

/// Identificador de [Utxo].
pub struct Outpoint {
    /// Identificador de transacción.
    pub txid: Vec<u8>,
    /// Número de índice implícito.
    pub vout: u32,
}

```

</TabItem>
</Tabs>

Para crear una transacción que envíe `X` satoshis a una dirección de destino,
debes seleccionar un subconjunto de los UTXOs disponibles que cubran el monto
`X` más la tarifa de la transacción.

## Calcular la tarifa de transacción por byte

transacción en bytes. Una tarifa adecuada por byte se puede determinar

## Construir la transacción

A continuación, se puede construir la transacción. El siguiente fragmento de
código muestra una versión simplificada de cómo construir una transacción que
envía `amount` satoshis a `dst_address` y devuelve el cambio a `own_address`.

Dado que la tarifa de una transacción se basa en su tamaño, la transacción debe
construirse de forma iterativa y firmarse con un firmante simulado que
simplemente agregue el tamaño respectivo de la firma. Cada UTXO seleccionado se
usa como entrada para la transacción y requiere una firma.
