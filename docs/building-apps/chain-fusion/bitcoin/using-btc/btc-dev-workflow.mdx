# Flujo de trabajo para desarrolladores de ICP BTC

<MarkdownChipRow labels={["Avanzado", "Bitcoin"]} />

Los desarrolladores en ICP pueden crear canisters y dapps que interactúan
directamente con las redes Bitcoin mainnet y testnet a través de la integración
directa de ICP con Bitcoin. Para usar esta integración, los desarrolladores
deben implementar un flujo de trabajo específico para preparar transacciones y
enviarlas a la red Bitcoin. También pueden integrar e interactuar con chain-key
Bitcoin (ckBTC) desde un canister, que utiliza la implementación del token
ICRC-1.

## Usando la integración con Bitcoin

Para interactuar con las redes Bitcoin testnet o mainnet, un desarrollador
necesita usar tanto el canister de gestión como la API de integración de Bitcoin
para completar los siguientes pasos:

1. [Generar una dirección Bitcoin](generate-addresses.mdx): Para recibir BTC, tu
   canister debe generar una dirección Bitcoin usando el endpoint API
   `ecdsa_public_key` del
   [canister de gestión](/docs/references/system-canisters/management-canister#signing-and-submitting-bitcoin-transactions).

2. [Crear una transacción Bitcoin](./create-transactions.mdx): Si el canister
   controla BTC, puede crear una transacción para gastarlos.

3. [Firmar una transacción](./sign-transactions.mdx): Luego, la transacción debe
   firmarse con t-ECDSA usando el endpoint API `sign_with_ecdsa` del
   [canister de gestión](/docs/references/system-canisters/management-canister#signing-and-submitting-bitcoin-transactions).
   Las transacciones no pueden enviarse a la red Bitcoin hasta que estén
   firmadas.

4. [Enviar una transacción](./submit-transactions.mdx): Una vez firmada, la
   transacción puede enviarse a la red Bitcoin para ejecutarse usando el
   endpoint
   [`bitcoin_send_transaction`](https://github.com/dfinity/bitcoin-canister/blob/master/INTERFACE_SPECIFICATION.md#bitcoin_send_transaction)
   de la API Bitcoin, que debe especificar un `blob` de la transacción Bitcoin y
   una red (mainnet o testnet).

5. [Leer información de la red Bitcoin](read-state.mdx): Por último, puedes
   consultar y obtener información de la red Bitcoin, como las transacciones no
   gastadas (UTXOs) de una dirección Bitcoin, el saldo de una dirección Bitcoin
   y los percentiles de las tarifas de las últimas 10_000 transacciones. Los
   puntos finales para cada consulta se pueden encontrar en la
   [especificación de la API de Bitcoin](https://github.com/dfinity/bitcoin-canister/blob/master/INTERFACE_SPECIFICATION.md).

Cada uno de estos puntos finales de la API se puede ejecutar programáticamente
dentro de un contrato inteligente que se implementa en ICP. Consulta la
documentación de cada paso del flujo de trabajo para ver ejemplos de código para
interactuar con cada punto final de la API.

:::tip

Trabajar con estructuras de datos de Bitcoin como direcciones, UTXOs y
transacciones puede ser complicado. La buena noticia es que se pueden usar
bibliotecas populares como
[`rust-bitcoin`](https://github.com/rust-bitcoin/rust-bitcoin) y
[`bitcoinjs-lib`](https://github.com/bitcoinjs/bitcoinjs-lib) dentro de
canisters.

:::

## Usando el soporte de integración Bitcoin de `dfx`

Para desarrollar y probar localmente un canister que use la integración Bitcoin,
puedes iniciar la réplica local con `dfx start --enable-bitcoin`. También puedes
incluir esta configuración en el archivo `dfx.json` del proyecto:

```json reference
https://github.com/dfinity/examples/blob/master/motoko/basic_bitcoin/dfx.json#L9-L16
```

[Más información sobre opciones de configuración de `dfx.json`](https://internetcomputer.org/docs/building-apps/developer-tools/dfx-json-reference).

## Usando una instancia local de Bitcoin testnet

Puedes desarrollar y probar tu canister contra una instancia local de Bitcoin
testnet en tu entorno de desarrollo.
[Más información en la documentación de desarrollo local con Bitcoin](local-development.mdx).

## Usando ckBTC

Chain-key Bitcoin (ckBTC) es un token gemelo digital de Bitcoin respaldado 1:1
con Bitcoin mantenido en un smart contract de ICP. Los tokens ckBTC cumplen con
el [estándar ICRC](/docs/defi/chain-key-tokens/ckbtc/overview).

ckBTC y otros tokens chain-key pueden interactuarse de la misma manera que otros
tokens ICRC. No hay pasos, parámetros o tipos de smart contracts especiales
requeridos para integrarse con tokens chain-key como ckBTC.

[Más información sobre ckBTC](/docs/defi/chain-key-tokens/ckbtc/overview).
