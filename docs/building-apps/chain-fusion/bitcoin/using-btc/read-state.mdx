# Lectura del estado de Bitcoin

<MarkdownChipRow labels={["Avanzado", "Bitcoin", "Tutorial"]} />

Para leer información del estado de la red de Bitcoin, la API de integración de
Bitcoin expone los siguientes métodos:

- `bitcoin_get_utxos`: Devuelve las salidas de transacciones no gastadas (UTXOs)
  de una dirección de Bitcoin.
- `bitcoin_get_balance`: Devuelve el saldo de una dirección de Bitcoin.
- `bitcoin_get_current_fee_percentiles`: Devuelve los percentiles de las tarifas
  de las últimas 10,000 transacciones. La tarifa se devuelve en millisatoshi por
  byte virtual.
- `bitcoin_get_block_headers`: Devuelve los encabezados de bloque dentro de un
  rango de altura inicial y altura final (opcional) para la red de Bitcoin
  especificada (testnet o mainnet).

Se admiten direcciones estándar de Bitcoin (P2PKH, P2SH, P2WPKH, etc.).

:::info

Para probar canisters localmente que utilicen los siguientes fragmentos de
código, es necesario habilitar el desarrollo local de Bitcoin. Para hacerlo,
puedes iniciar la réplica local con `dfx start --enable-bitcoin` o incluir la
siguiente configuración en el archivo `dfx.json` del proyecto:

```json reference
https://github.com/dfinity/examples/blob/master/motoko/basic_bitcoin/dfx.json#L9-L16
```

[Más información sobre las opciones de configuración de `dfx.json`](https://internetcomputer.org/docs/building-apps/developer-tools/dfx-json-reference).

:::

## Redes de Bitcoin

Se admiten tanto la red testnet como la mainnet de Bitcoin. La red se puede
especificar como un parámetro en cada función.

## Costos de la API

Cada llamada a la API tiene un costo en ciclos, por lo que se debe enviar una
cantidad suficiente de ciclos con cada llamada.

Los costos de los ciclos varían entre la red testnet y la mainnet de Bitcoin.
Para un desglose de los costos, consulta
[Costos de la API de Bitcoin](/docs/references/bitcoin-how-it-works).

## Lectura de salidas de transacciones no gastadas

Para leer las salidas de transacciones no gastadas de la red de Bitcoin, realiza
una llamada al método `bitcoin_get_utxos` de la API de Bitcoin. Puedes crear una
función en tu canister para llamar a este método, por ejemplo:

## Lectura del percentil de tarifas

Las tarifas de transacción en la red de Bitcoin cambian dinámicamente según la
cantidad de transacciones pendientes. Para obtener los percentiles de tarifas de
los últimos bloques (4 - 10), llama a `bitcoin_get_current_fee_percentiles`.

La función devuelve 101 valores numéricos que representan tarifas medidas en
millisatoshi por byte virtual. El elemento `i`-ésimo del resultado corresponde a
la tarifa del percentil `i`. Por ejemplo, para obtener la tarifa mediana de los
últimos bloques, consulta el elemento `50`-ésimo del resultado.
