# Integración de Bitcoin

<MarkdownChipRow labels={["Avanzado", "Bitcoin"]} />

La integración de Internet Computer con Bitcoin permite que los contratos
inteligentes de ICP interactúen directamente con la red de Bitcoin.

## ¿Por qué es importante la integración con Bitcoin?

La integración de Bitcoin es importante porque brinda funcionalidad de contratos
inteligentes a Bitcoin, que no tiene una plataforma nativa de contratos
inteligentes en sí, abriendo nuevas posibilidades para DeFi y el desarrollo de
aplicaciones descentralizadas. Por ejemplo, los contratos inteligentes de ICP
pueden mantener, recibir y enviar BTC directamente. También facilita la creación
de un token ckBTC respaldado 1:1 por BTC.

# Cómo funciona

Los contratos inteligentes que se ejecutan en ICP pueden interactuar
directamente con la red de Bitcoin sin utilizar puentes. Esto es posible porque
los nodos de ICP pueden obtener y validar los bloques de la red de Bitcoin y
luego ponerlos a disposición de los contratos inteligentes para consultar y
leer. Los contratos inteligentes también pueden firmar y enviar transacciones de
Bitcoin, lo que les permite mantener BTC directamente.

Esta integración directa de Bitcoin utiliza dos características:

- **[Threshold ECDSA](/docs/building-apps/network-features/signatures/t-ecdsa)**
  y
  **[threshold Schnorr](/docs/building-apps/network-features/signatures/t-schnorr)**:
  Un contrato inteligente puede tener una clave secreta que se almacena de
  manera segura y descentralizada utilizando criptografía de clave de cadena.
  Esta clave se puede utilizar para firmar digitalmente mensajes. ECDSA y
  Schnorr son compatibles con la cadena de bloques de Bitcoin, lo que permite
  que los contratos inteligentes firmen transacciones de Bitcoin.

- **Adaptador de Bitcoin**: ICP tiene una subred cuyos nodos participan en la
  red de Bitcoin. Estos nodos se utilizan para obtener el estado y los bloques
  de Bitcoin y enviar transacciones a la red.

A nivel de protocolo, tanto el adaptador de Bitcoin como las características de
ECDSA de clave de cadena exponen una API en el
[canister de gestión](/docs/references/system-canisters/management-canister).

Cuando un canister desea realizar una transacción de Bitcoin, se envía una
solicitud a la subred de Bitcoin que aloja un canister de Bitcoin que contiene
el estado de Bitcoin en la cadena de ICP. La solicitud se envía a la red de
Bitcoin a través del adaptador de Bitcoin y se procesa de forma asincrónica por
Bitcoin.

## ckBTC

El valor principal de los tokens de clave de cadena, como ckBTC, es que se
pueden transferir con un tiempo de finalización bajo (en cuestión de segundos) y
a una fracción del costo de una transacción en la red nativa del token (en este
caso, una transacción de BTC en Bitcoin).

## Casos de uso y aplicaciones de muestra

La integración de Bitcoin admite casos de uso básicos y avanzados, como
intercambios descentralizados o trabajar con inscripciones de Bitcoin.

El token ckBTC es adecuado para los casos de uso comunes de mantener, transferir
y negociar BTC.

Aplicaciones de muestra:

- Plataformas de financiación colectiva que aceptan BTC, como
  [Funded](https://funded.app/).

- Aplicaciones sociales que admiten el envío de criptomonedas a otros usuarios,
  como [OpenChat](https://oc.app/).

- Plataformas de comercio electrónico en línea.
  [Bitshop](https://ughim-6qaaa-aaaah-qc7qa-cai.ic0.app/) es un ejemplo.

[Ver la lista completa de ejemplos del ecosistema de Bitcoin](https://internetcomputer.org/ecosystem?tag=Bitcoin).
