# Ejemplos de Chain Fusion

<MarkdownChipRow labels={["Avanzado", "Chain Fusion"]} />

La tecnología Chain Fusion de ICP permite a los desarrolladores construir dapps
que pueden interactuar sin problemas con otras redes blockchain sin necesidad de
un intermediario, como un oráculo o un puente.

Actualmente, ICP tiene una integración directa con la red Bitcoin, una
integración RPC con Ethereum y cadenas EVM, y soporte para realizar llamadas a
otras cadenas, como Sui, a través de las funciones de  
[llamadas HTTPS](/docs/building-apps/network-features/using-http/https-outcalls/overview)
y  
[Threshold ECDSA](/docs/building-apps/network-features/signatures/t-ecdsa).

Esta página destaca herramientas y proyectos de ejemplo, tanto contribuidos por
DFINITY como por la comunidad, que muestran cómo se puede implementar la
tecnología Chain Fusion en diferentes casos de uso.

## Ejemplos de Bitcoin

[Aprende más sobre la integración con Bitcoin](/docs/building-apps/chain-fusion/bitcoin/overview).

- [Página de integración con Bitcoin](https://internetcomputer.org/bitcoin-integration):  
  Aprende más sobre la integración directa de ICP con Bitcoin.

- [ckBTC](https://github.com/dfinity/ic/tree/master/rs/bitcoin/ckbtc):  
  Repositorio de GitHub del gemelo de Bitcoin controlado por un canister en ICP,
  respaldado 1:1 con BTC en la cadena.

- [Biblioteca de Bitcoin para Internet Computer](https://github.com/Benjamin-Loison/Internet-Computer-Bitcoin-Library):  
  Biblioteca de utilidades para Motoko y Rust que facilita la integración con
  Bitcoin en ICP.

- [Wallet Bitcoin multi-subred](https://github.com/sardariuss/ic_btc_multisig):  
  Prueba de concepto que muestra la custodia de Bitcoin en múltiples subredes.

- [Bitfinity Wallet](https://wallet.bitfinity.network/):  
  Extensión de navegador y wallet multichain.

- [Loka](https://github.com/lokaverse/loka_canister):  
  Plataforma de minería de Bitcoin descentralizada y sin custodia, construida en
  ICP.

- [Canister de Ordinals](https://github.com/sardariuss/ordinals_canister):  
  Canister que permite la recuperación de Bitcoin Ordinals y sus inscripciones
  correspondientes.

- [Canister de Schnorr](https://github.com/domwoe/schnorr_canister):  
  Canister que crea firmas Schnorr compatibles con Taproot.

- [Canister de Inscripciones](https://github.com/domwoe/inscription_canister):  
  Canister utilizado para crear inscripciones de Ordinals.

- Plataformas de crowdfunding que aceptan BTC, como
  [Funded](https://funded.app/).

- Aplicaciones sociales que permiten enviar criptomonedas a otros usuarios, como
  [OpenChat](https://oc.app/).

- [Bioniq](https://bioniq.io/home/24-hours):  
  Mercado de Bitcoin Ordinals construido en ICP.

- [Bit Basel](https://bitbasel.com/):  
  Mercado de arte basado en Bitcoin Ordinals.

- Plataformas de comercio en línea como
  [Bitshop](https://ughim-6qaaa-aaaah-qc7qa-cai.ic0.app/).

[Ver la lista completa de ejemplos del ecosistema de Bitcoin](https://internetcomputer.org/ecosystem?tag=Bitcoin).

## Ejemplos de Ethereum y EVM

[Aprende más sobre la integración con Ethereum](/docs/building-apps/chain-fusion/ethereum/overview).

- [Bitfinity EVM](https://bitfinity.network):  
  Implementación de la Ethereum Virtual Machine (EVM) en ICP.

- [CCAMP](https://github.com/usherlabs/ccamp):  
  Protocolo modular y personalizable para la gestión de activos entre cadenas.

- [ChainSight](https://docs.chainsight.network/chainsight-overview/introduction):  
  Oráculo de datos cross-chain basado en llamadas HTTPS y firmas ECDSA de clave
  compartida.

- [ckETH](https://github.com/dfinity/ic/tree/master/rs/ethereum/cketh):  
  Repositorio de GitHub del gemelo de Ethereum controlado por un canister en
  ICP, respaldado 1:1 con ETH en la cadena.

- [ckNFT](https://github.com/b3hr4d/cknft):  
  Prueba de concepto para convertir NFTs ICRC-7 a ERC-1155 en redes EVM.

- [ERC20-ICP](https://github.com/dfinity/erc20-icp):  
  Smart contracts y canisters que permiten representar ICP tokens como ERC20 en
  Ethereum.

- [EVM RPC Canister](https://github.com/internet-computer-protocol/evm-rpc-canister):  
  Repositorio de GitHub del canister de EVM RPC de ICP, usado para interactuar
  con redes EVM desde el Internet Computer.

- [Ethereum Canister](https://github.com/eigerco/ethereum-canister):  
  Canister que ejecuta un cliente ligero de Ethereum (Helios).

- [EVM Utility Canister](https://github.com/icopen/evm_utils_ic):  
  Canister de utilidades para crear y analizar transacciones compatibles con
  EVM.

- [ic-solidity-bindgen](https://github.com/horizonx-tech/ic-solidity-bindgen):  
  Herramienta para generar bindings de Rust para contratos de Solidity a partir
  de ABIs para su uso en ICP.

- [ic-eth-starter](https://github.com/dfinity/ic-eth-starter):  
  Proyecto inicial avanzado para interactuar con Ethereum en ICP.

- [ic-web3-rs](https://github.com/horizonx-tech/ic-web3-rs):  
  Biblioteca de utilidades para interactuar con redes EVM.

- [Oisy](https://github.com/dfinity/oisy-wallet):  
  Wallet de Ethereum totalmente onchain, basada en navegador y asegurada con
  Internet Identity.

- [Omnic](https://github.com/rocklabs-io/omnic):  
  Protocolo de mensajería cross-chain para conectar cadenas EVM a través de ICP.

- [Orally](https://github.com/orally-network/oracle):  
  Fábrica de oráculos cross-chain basada en llamadas HTTPS y ECDSA de clave
  compartida.

- [Gitcoin Passport Client](https://github.com/vporton/passport-client-dfinity):  
  Aplicación para recuperar y almacenar puntajes de Gitcoin Passport de forma
  segura.

- [Iniciar sesión con Ethereum](https://forum.dfinity.org/t/announcing-ic-siwe-use-ethereum-wallets-to-login-to-ic/27450):  
  Usa una wallet de Ethereum para iniciar sesión en dapps de ICP.

- [Construye una plataforma de pagos Ethereum cross-chain](https://forum.dfinity.org/t/building-a-cross-chain-eth-payment-and-e-commerce-platform-on-the-internet-computer-a-step-by-step-tutorial/23938):
  Un tutorial de la comunidad para construir una plataforma de pagos y comercio
  electrónico de Ethereum en ICP.

- [EVM en ICP](https://fxa77-fiaaa-aaaae-aaana-cai.raw.ic0.app/evm/).

- Plataformas de apuestas en línea como [VaultBet](https://vault-bet.com/).

- Identidades digitales que se pueden utilizar para mantener activos
  multi-cadena como [NFID](https://nfid.one/).

[Ver la lista completa de ejemplos del ecosistema de Ethereum](https://internetcomputer.org/ecosystem?tag=Ethereum).

## Otros ecosistemas

ICP admite comunicación con otros ecosistemas a través de llamadas HTTPS y
firmas ECDSA de clave compartida. Algunos ejemplos incluyen:

- [Galactic Bridge](https://github.com/weichain/galactic-bridge-icp):  
  Puente controlado por canisters para Solana.

- [Generación de direcciones Sui](https://github.com/jennifertrin/suionicp):  
  Ejemplo de generación de direcciones Sui controladas por un canister de ICP.

- [Iniciar sesión con Solana](https://forum.dfinity.org/t/announcing-ic-siws-use-solana-wallets-to-login-to-icp/29261).
