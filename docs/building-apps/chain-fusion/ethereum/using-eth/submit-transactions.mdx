### Enviando transacciones

<MarkdownChipRow labels={["Avanzado", "Ethereum", "Tutorial"]} />

Para enviar transacciones a la red de Ethereum, primero la transacción debe ser
firmada y formateada como una transacción ETH.
[Aprende más sobre la firma de transacciones](signing-transactions.mdx).

Una vez que tengas tu transacción firmada sin procesar, puedes enviarla
programáticamente o utilizar el método RPC `eth_sendRawTransaction` del canister
EVM RPC.

### Enviar transacciones programáticamente

A continuación, se muestra un ejemplo de cómo enviar una transacción ETH sin
procesar programáticamente usando Rust:

```rust reference
https://github.com/letmejustputthishere/icp-evm-coprocessor-starter/blob/main/packages/ic-evm-utils/src/eth_send_raw_transaction.rs#L213-L230
```

### Usar el canister EVM RPC

Para enviar una transacción sin procesar con el canister EVM RPC, realiza una
llamada al método `eth_sendRawTransaction`:

```
# Configuración
NETWORK=local
IDENTITY=default
CYCLES=1000000000
WALLET=$(dfx identity get-wallet)
RPC_SOURCE=EthMainnet
RPC_CONFIG=null

# Enviar una transacción sin procesar
dfx canister call evm_rpc eth_sendRawTransaction "(variant {$RPC_SOURCE}, $RPC_CONFIG, \"0xf86c098504a817c800825208943535353535353535353535353535353535353535880de0b6b3a76400008025a028ef61340bd939bc2195fe537567866003e1a15d3c71ff63e1590620aa636276a067cbe9d8997f761aecb703304b3800ccf555c9f3dc64214b297fb1966a3b6d83\")" --with-cycles=$CYCLES --wallet=$WALLET
```

[Aprende más sobre el canister EVM RPC](/docs/building-apps/chain-fusion/ethereum/evm-rpc/evm-rpc-canister).
