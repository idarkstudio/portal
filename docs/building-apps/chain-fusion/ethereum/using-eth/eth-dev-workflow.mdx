# Flujo de trabajo para desarrolladores de ETH en ICP

<MarkdownChipRow labels={["Avanzado", "Ethereum"]} />

Los desarrolladores en ICP pueden crear canisters y dapps que interactúen con la
red principal de Ethereum, la red de prueba Sepolia y otras redes compatibles
con EVM a través de la integración de Ethereum en ICP. Para utilizar esta
integración, los desarrolladores deben implementar un flujo de trabajo
específico que realice llamadas JSON-RPC al canister RPC de EVM para consultar
información de la red y enviar transacciones a una red compatible con EVM. Los
desarrolladores también pueden integrar e interactuar con Ethereum de clave de
cadena (ckETH) desde un canister, que utiliza la implementación de tokens
ICRC-1.

## Uso de la integración de Ethereum

Para interactuar con la red de Ethereum u otra red compatible con EVM, un
desarrollador deberá utilizar una combinación de la API del canister de gestión
y los métodos RPC del canister RPC de EVM para completar los siguientes pasos:

1. [Generar una clave pública](./generating-addresses.mdx): Para firmar y enviar
   transacciones, su canister necesitará una clave pública. También necesitará
   esta clave pública para generar una dirección de billetera de Ethereum.

2. [Firmar una transacción](./signing-transactions.mdx): A continuación, una
   transacción debe ser firmada antes de poder ser enviada a la red de Ethereum
   y ejecutada. Las transacciones se firman utilizando
   [threshold ECDSA](/docs/references/t-sigs-how-it-works/), un protocolo
   novedoso como parte del conjunto de firmas de clave de cadena de ICP.

3. [Enviar una transacción](./submit-transactions.mdx): Las transacciones en
   bruto firmadas se pueden enviar utilizando el método RPC
   `eth_sendRawTransaction` del canister RPC de EVM. Se pueden encontrar
   ejemplos de código para enviar transacciones en la documentación del
   [canister RPC de EVM](/docs/building-apps/chain-fusion/ethereum/evm-rpc/evm-rpc-canister).

4. [Leer información de la red de Ethereum](/docs/building-apps/chain-fusion/ethereum/evm-rpc/evm-rpc-canister):
   Se puede consultar información de la red de Ethereum utilizando métodos RPC
   como:

   - `eth_getBlockByNumber`: Devuelve información sobre un bloque dado.

   - `eth_getTransactionCount`: Devuelve el número de transacciones para una
     dirección especificada.

   - `eth_getTransactionReceipt`: Devuelve detalles sobre una transacción
     enviada.

   - `eth_feeHistory`: Devuelve datos históricos de tarifas para estimar los
     precios de gas para las transacciones.

   - `eth_getLogs`: Devuelve los registros de un bloque o transacción
     especificada.

Cada uno de estos pasos se puede ejecutar programáticamente dentro de un
contrato inteligente que se implementa en ICP. Consulte la documentación del
[canister RPC de EVM](/docs/building-apps/chain-fusion/ethereum/evm-rpc/evm-rpc-canister)
para ver ejemplos de código para cada método RPC.

Se pueden encontrar proyectos de ejemplo adicionales en la documentación del
[canister RPC de EVM](/docs/building-apps/chain-fusion/ethereum/evm-rpc/evm-rpc-canister).

## Integración con Ethereum

La integración de Ethereum se puede incorporar en dapps con varios propósitos,
como la autenticación, como se muestra en el ejemplo de
[Iniciar sesión con Ethereum (SIWE)](https://github.com/kristoferlund/ic-siwe).
El ejemplo de SIWE muestra cómo utilizar una billetera de Ethereum para iniciar
sesión en aplicaciones de ICP. Crea una correlación 1:1 entre las direcciones de
Ethereum y los principales de ICP dentro del ámbito de la aplicación. También
garantiza que iniciar sesión con una billetera de Ethereum siempre producirá el
mismo principal independientemente del cliente utilizado.

## Uso de ckETH

Chain-key Ethereum (ckETH) es un token digital gemelo de Ethereum respaldado 1:1
con Ethereum que se encuentra en un contrato inteligente de ICP. Los tokens
ckETH cumplen con el
[estándar de tokens ICRC](/docs/defi/chain-key-tokens/cketh/overview).

Los tokens ckETH y otros tokens de clave de cadena se pueden interactuar de la
misma manera que otros tokens ICRC. No hay pasos de flujo de trabajo especiales,
parámetros o tipos de contratos inteligentes que deban utilizarse para
integrarse con tokens de clave de cadena como ckETH.

[Aprende más sobre ckETH](/docs/defi/chain-key-tokens/cketh/overview).

## Uso de tokens ckERC20

Los tokens ckERC20, como
[ckUSDC](https://dashboard.internetcomputer.org/ethereum/xevnm-gaaaa-aaaar-qafnq-cai),
pueden implementarse en ICP y respaldarse 1:1 con su moneda nativa, como USDC
para ckUSDC. Se han propuesto otros tokens ckERC20, como
[ckOCT](https://forum.dfinity.org/t/proposal-to-add-oct-as-a-new-ckerc20-token/32108)
y ckLINK.
