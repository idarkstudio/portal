# Generando una dirección de Ethereum

<MarkdownChipRow labels={["Avanzado", "Ethereum"]} />

En Ethereum, existen dos tipos de direcciones: direcciones de billetera para
almacenar activos y direcciones de contrato. Las direcciones de billetera son
cuentas públicas que pueden enviar y recibir tokens ETH. Las direcciones de
contrato se refieren a un contrato inteligente que se ha ejecutado en Ethereum y
las transacciones asociadas con ese contrato.

Las direcciones de billetera y contrato se pueden consultar utilizando el
[Canister EVM RPC](../evm-rpc/evm-rpc-canister.mdx).

## Direcciones ETH de Canister

Para crear una dirección ETH para tu canister, primero necesitarás obtener una
clave pública ECDSA asociada con tu canister. Puedes obtener esta clave llamando
al método de API `ecdsa_public_key` del canister de gestión:
