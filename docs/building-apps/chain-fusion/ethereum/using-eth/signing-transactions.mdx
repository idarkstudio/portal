# Firmando transacciones

<MarkdownChipRow labels={["Avanzado", "Ethereum", "Tutorial"]} />

Antes de que una transacción pueda enviarse a la red de Ethereum, debe ser
firmada y formateada en una transacción ETH sin procesar. Las transacciones se
firman utilizando
[ECDSA umbral](/docs/building-apps/network-features/signatures/t-ecdsa). Para
este ejemplo, se utilizará el estándar de transacción EIP-1559.

## Construcción de una transacción

Primero, se debe construir una transacción ETH EIP-1559 sin procesar que
contenga los metadatos de la transacción, como la tarifa de gas, el remitente,
el receptor y los datos de la transacción. A continuación, se muestra un ejemplo
programático de cómo construir una transacción usando Rust:

```rust reference
https://github.com/letmejustputthishere/icp-evm-coprocessor-starter/blob/main/packages/ic-evm-utils/src/eth_send_raw_transaction.rs#L45-L77
```

## Formatear, hashear y firmar una transacción

Las transacciones Ethereum EIP1559 primero se hashean con el algoritmo Keccak256
y luego se firman utilizando la clave privada. A continuación se muestra un
ejemplo escrito en Rust que demuestra cómo formatear una transacción ETH sin
procesar, hashearla con Keccak256 y firmar el hash utilizando ECDSA umbral. Este
fragmento de código realiza lo siguiente:

- Formatea la transacción.

- Hashea la transacción utilizando Keccak256.

- Firma el hash de Keccak.

- Reconstruye la transacción utilizando la firma VRS.

```rust reference
https://github.com/letmejustputthishere/chain-fusion-starter/blob/main/packages/ic-evm-utils/src/evm_signer.rs#L56-L94
```

Puedes encontrar más ejemplos sobre cómo firmar transacciones con ECDSA umbral
en la
[documentación de ECDSA umbral](/docs/building-apps/network-features/signatures/t-ecdsa).

## Enviar la transacción

Ahora que tu transacción está firmada, puedes enviarla a la red de Ethereum para
que se ejecute.

[Aprende cómo enviar transacciones en Ethereum](./submit-transactions.mdx).
