# Integración de Ethereum y EVM

<MarkdownChipRow labels={["Avanzado", "Ethereum"]} />

Los contratos inteligentes en ICP pueden interactuar directamente con la red de
Ethereum y otras redes que utilizan la Máquina Virtual de Ethereum (EVM), como
Polygon y Avalanche. Esta integración es posible gracias a las llamadas
salientes HTTPS de ICP y a las características de ECDSA de umbral, que permiten
consultar transacciones de Ethereum y que los contratos inteligentes de ICP
firmen y envíen transacciones a Ethereum.

- **[ECDSA de umbral](/docs/building-apps/network-features/signatures/t-ecdsa)**:
  Un contrato inteligente puede tener una clave secreta que se almacena de
  manera segura y descentralizada utilizando criptografía de clave de cadena.
  Los mensajes enviados por el contrato inteligente pueden ser firmados
  utilizando esta clave, lo que permite enviar transacciones firmadas a Ethereum
  desde el contrato inteligente.

- **[Llamadas salientes HTTPS](https://internetcomputer.org/https-outcalls)**:
  Para consultar información de Ethereum y otras redes EVM, se utilizan llamadas
  salientes HTTPS. Las llamadas salientes HTTPS pueden obtener información de
  fuentes externas. En esta integración, se utilizan para obtener datos de
  servicios RPC-JSON consultando transacciones, direcciones e información de
  bloques de Ethereum. Para facilitar las llamadas RPC-JSON, se ha creado y
  desplegado el canister EVM RPC en la mainnet, proporcionando un punto de API
  que los contratos inteligentes pueden utilizar.

## Canister EVM RPC

Los canisters desplegados en ICP pueden comunicarse con la cadena de bloques de
Ethereum y otras redes compatibles con EVM utilizando el canister EVM RPC. Este
canister envía solicitudes de API a servicios JSON-RPC como
[CloudFlare](https://www.cloudflare.com/en-gb/web3/),
[Alchemy](https://www.alchemy.com/), [Ankr](https://www.ankr.com/),
[BlockPI](https://blockpi.io/) o [Public Node](https://www.publicnode.com/)
utilizando
[llamadas salientes HTTPS](https://internetcomputer.org/https-outcalls).

Esto permite funcionalidades similares a las dapps tradicionales de Ethereum,
incluyendo la consulta de estados de contratos inteligentes de Ethereum y el
envío de transacciones en bruto.

Además de la cadena de bloques de Ethereum, este canister también tiene soporte
parcial para Polygon, Avalanche y otras redes EVM populares. Consulta
[ChainList.org](https://chainlist.org/?testnets=true) para obtener una lista
extensa de redes compatibles y proveedores de RPC.

Puedes
[aprender cómo utilizar el canister EVM RPC](/docs/building-apps/chain-fusion/ethereum/evm-rpc/evm-rpc-canister).

## ckETH

ICP implementa un contrato inteligente que utiliza ECDSA de umbral y
criptografía de clave de cadena para proporcionar un token
[**ckETH**](/docs/defi/chain-key-tokens/cketh/overview) (ETH de clave de cadena)
respaldado 1:1 por ETH.

El valor principal de los tokens de clave de cadena, como ckETH, es que se
pueden transferir con un tiempo de finalización bajo (en cuestión de segundos) y
a una fracción del costo de una transacción en la red nativa del token (en este
caso, una transacción ETH en Ethereum).

## Casos de uso y dapps de ejemplo

La API de ECDSA de umbral proporciona una forma para que los contratos
inteligentes firmen transacciones con sus claves secretas. El canister EVM RPC
permite que los contratos inteligentes lean la información de la red de Ethereum
y envíen transacciones firmadas.

El token ckETH es adecuado para los casos de uso comunes de mantener, transferir
y comerciar con ETH.

Aplicaciones de ejemplo:

- [EVM en ICP](https://fxa77-fiaaa-aaaae-aaana-cai.raw.ic0.app/evm/).

- [Chain Fusion starter](https://github.com/letmejustputthishere/chain-fusion-starter).

- Plataformas de apuestas en línea como [VaultBet](https://vault-bet.com/).

- Aplicaciones sociales que admiten el envío de criptomonedas a otros usuarios,
  como [OpenChat](https://oc.app/).

- Plataformas de financiamiento colectivo que aceptan ETH, como
  [Funded](https://funded.app/).

- Identidades digitales que se pueden utilizar para mantener activos
  multi-cadena como [NFID](https://nfid.one/).

[Ver la lista completa de ejemplos del ecosistema de Ethereum](https://internetcomputer.org/ecosystem?tag=Ethereum).
