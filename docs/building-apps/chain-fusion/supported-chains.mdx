# Cadenas compatibles

<MarkdownChipRow labels={["Avanzado", "Chain Fusion"]} />

Otras redes blockchain pueden integrarse con ICP si utilizan un método de
autenticación compatible con los protocolos de firma de umbral de Internet
Computer y tienen proveedores de RPC confiables que admitan IPv6.

Para algunas cadenas, DFINITY o la comunidad de ICP han construido bibliotecas o
canisters para simplificar la integración.

## Cadenas compatibles

La siguiente tabla muestra una selección de cadenas compatibles y sus
respectivos métodos de autenticación, integraciones disponibles y tokens de
clave de cadena.

:::caution

Las cadenas compatibles con EVM que no sean Ethereum no se enumeran
explícitamente, pero se admiten de la misma manera que Ethereum a través del
canister EVM RPC.

:::

- **Autenticación**: Métodos de autenticación, como esquemas de firma utilizados
  para autenticar transacciones, que son compatibles con las capacidades de
  firma de umbral de ICP.

- **Integraciones disponibles**: Las integraciones disponibles para cada cadena,
  es decir, los métodos mediante los cuales ICP puede interactuar con la cadena.

- **Activos**: Activos construidos sobre las integraciones, como tokens de clave
  de cadena.

### ¿Buscas una cadena que no está en la lista?

Lo más probable es que la cadena que deseas integrar aún sea compatible con ICP.
Consulta la documentación de la cadena que deseas integrar para averiguar qué
métodos de autenticación o esquemas de firma son compatibles.
